# ISO 5807:1985 流程图标准

> 信息处理 — 数据流程图、程序流程图和系统流程图的文档符号与约定
> 标准编号：ISO 5807:1985，2019 年重新确认（Reconfirmed），当前仍然有效

---

## 一、标准概述

ISO 5807 发布于 1985 年，是流程图领域最基础的国际标准。它定义了用于信息处理文档中的符号，涵盖三类流程图：

- 数据流程图（Data Flowchart）
- 程序流程图（Program Flowchart）
- 系统流程图（System Flowchart）

该标准面向的是**程序逻辑和数据处理**，不涉及业务流程、组织协作等现代概念。

---

### 2.3 流程线规则

ISO 5807 对流程线有明确的规则：

- 标准方向：从上到下、从左到右
- 非标准方向必须加箭头
- 流程线不应交叉，如果必须交叉，使用连接符（○）避免
- 一个符号可以有多条出口线（如判断符号），但每条线必须标注条件

### 2.4 ISO 5807 的局限性

```
ISO 5807 (1985) 的设计背景是单机程序和批处理系统：

✅ 能表达的：
  - 顺序执行
  - 条件分支（if/else、switch）
  - 循环（for、while）
  - 子程序调用
  - 数据输入/输出
  - 并行处理（基础）

❌ 不能表达的：
  - 谁来执行（没有角色/泳道概念）
  - 等待外部事件（没有事件机制）
  - 跨组织协作（没有消息传递）
  - 错误处理和补偿（没有异常流）
  - 多条件并行选择（只有全部并行或二选一）
  - 业务规则和策略（没有规则引擎概念）
  - 超时和定时触发（没有时间概念）
```

## 一、验收范围

Phase 1 的目标是**全链路最小闭环**：用户能通过 chat 与 Agent 对话，Agent 按流程执行任务，用户能审批门禁。

当前后端 7 个服务（core/platform/flow/runtime/gate/sandbox/infra）已完成编码。前端（chat/console）和客户端 SDK 尚未开始。因此验收分为两部分：

- **后端验收**（当前可执行）：通过 curl / API 调用验证后端链路
- **全链路验收**（待 sdk + chat 完成后执行）：通过 UI 验证完整用户体验

## 四、判定规则

### 后端验收

| 级别 | 条件 | 判定 |
|------|------|------|
| 通过 | B 系列 + P 系列 + G 系列 + F 系列 + R 系列 + S 系列全部 ☑ | 后端联调通过，可进入波次 4（sdk） |
| 有条件通过 | 核心项（B-01/02, P-01/02, G-01/02/05, F-01/03, R-01/02, S-01/03）全部 ☑，其余有少量失败 | 记录问题，不阻塞 sdk 开发，并行修复 |
| 不通过 | 任一核心项失败 | 定位问题，修复后重新验收 |

| 级别 | 条件 | 判定 |
|------|------|------|

## 二、阅读顺序

**首次了解 Quantalithos**:

1. `最终目的.md` §一、二、三 — 一句话定位 + 问题 + 六条叙事
2. `最终目的.md` §五 — 端到端故事(用户 Alice 的博客案例)
3. `产品矩阵.md` §二 10 产品总览
4. `六域模型.md` §二 六域总览(如果想理解技术地图)

**深入研究**:

- 研究领域建模 → `六域模型.md` §三-§八 每域一章 + §十端到端事件流
- 研究产品形态 → `产品矩阵.md` §三-§六 + §七联动生态
- 审视标准对齐 → `六域模型.md` §十二 + `架构/标准对齐全景图.md`

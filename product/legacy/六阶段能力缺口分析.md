## Phase 1 的替代方案

Phase 1 无法完整走通阶段 5（发布执行），但阶段 0-4 可以闭环：

```
Phase 1 可走通的流程：

  阶段 0 → 阶段 1 → 阶段 2 → 阶段 3 → 阶段 4
  启动      需求      方案      开发      验收

  阶段 5 发布执行：
  Phase 1 替代方案 → 用户手动部署，Agent 不参与
  Phase 2 → CI/CD 集成后 Agent 可触发部署
```

| 缺失能力 | Phase 1 替代方案 |
|---------|----------------|
| Git 集成 | Agent 在沙箱目录写文件，用户手动 git commit |
| CI/CD | Agent 运行 code_execute 执行测试，用户手动部署 |
| 原型预览 | Agent 生成 HTML，用户在浏览器中打开文件 |
| 多任务并行 | 顺序执行（T-003 完成后再执行 T-004） |
| 代码沙箱 | 无隔离，Agent 在工作目录直接执行 |
| 发布/回滚 | 用户手动操作 |

当前我想实施开发一个项目
主要是模拟一个软件开发公司  然后员工都是AI 

目标:
实现类似于openclaw的功能, 但是与他有区别, 我的目标是让新手用户也可以通过我开发的app, 通过创建机器人群聊, 发布任务后, 可以显示看到机器人的工作流

功能:  
群组主要是为了开发某个任务而组件的, 所以群聊对所有人都是即时的并且可见的  
可以拉多个群组, 每个群组是为了开发某个任务   
群组下可以某些人单独拉频道, 主要是为了讨论组内某项任务, 群聊内对频道无感知, 频道的结果可能需要反馈到群聊   
要求当用户给出需求后, 群组内成员互相协作, 最终需要向用户产出最终的交付结果  
关键节点需要设置门禁, 需要用户同意  
需要禅道这样的系统, 创建项目, 然后再项目内创建需求和bug

流程:  
可以参考 /home/aris/OpenSource/superpowers 

要求:
1. 每个员工有唯一的id, 名称可以重复  
2. 每个员工都可以被拉近群组, 组成一个开发团队, 一个员工可以被拉入多个群组  
3. 员工之间可以互相私聊, 还可以根据群组 创建群组下的频道  
4. 每个成员都是可被登陆的, 也就是说你可以登陆机器人, 看看他当前在和谁聊天  
5. 给出一个项目后, 群组内成员分工合作, 将其完成  

实现细则:
1. 需要维护一个常驻daemon服务, 提供调用agent的功能, 可以理解成多agent的管理, 最好使用rust完成  
2. 这个daemon 使用 lua 或者 python 调用 模型, 同时需要支持 mcp 和 skill 这些  
3. 前端可以通过连接 访问 daemon 服务, 获取当前的 agent 状态 信息等内容  
4. 通过前端和app可以创建 管理 与机器人的聊天 或者群聊  
5. 不仅支持我们自己开发的app与机器人聊天, 还需要扩展, 参考openclaw对mattermost telegram的支持, 但是我们是使用lua 或者 python来完成插件的 
6. 前端app 最好支持跨平台

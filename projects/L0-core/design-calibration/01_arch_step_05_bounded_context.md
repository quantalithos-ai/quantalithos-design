### 3. SOP 问题回答

1. 本仓内部有哪些子域或本地上下文？

   回答：本仓内部可分为三层语义单元：共享契约核心、领域契约包和本地索引 / 投影 / 引用。

2. 哪些是核心子域？

   回答：核心子域是共享契约核心，它承载全仓共享的基础语义、兼容规则和通用契约真相。

3. 哪些是支撑子域？

   回答：支撑子域是各领域契约包，包括 identity、conversation、work、process、governance、artifact 等契约包；它们围绕共享契约核心展开。

4. 哪些只是外部上下文的本地索引 / 投影 / 引用？

   回答：本地索引 / 投影 / 引用包括标准映射索引、事件目录引用和兼容性追溯索引；它们不拥有正文真相，只为稳定消费外部上下文提供本地视图。

5. 它们之间的上下文映射关系是什么？

   回答：共享契约核心为所有领域契约包提供统一基础；各领域契约包只依附核心，不互相拥有真相；本地索引 / 投影 / 引用只围绕外部输入和治理需要存在，不反向定义契约真相。

6. 为什么这些部分不能混成一个上下文？

   回答：因为它们的变化速率、真相归属和消费目的不同。核心需要最低变化率，领域契约包需要按领域独立演进，本地索引只承担稳定引用与治理视图，混在一起会把真相、派生和引用打成一团。

### 3. SOP 问题回答

1. 这个仓有哪些主要可选架构方案？

   回答：可比较的路径包括：当前主线的“契约来源仓 + 发布基线 / 只读快照 + 后台承接”路径、纯文档 / 草案聚合路径、工具链 / 生成物中心路径、下游自治契约路径、全同步收口路径、全异步流水线路径。在线业务服务、事件总线实现、SDK 客户端中心等已经属于边界外方向，不进入主表作为正式备选。

2. 为什么当前选择这一种？

   回答：当前主线最能同时守住契约真相、下游消费、演进兼容、数据边界和无在线运行时约束。它比纯文档路径更有真相约束，比工具链中心路径更不受生成物反向牵引，比下游自治路径更能避免 schema drift，比全同步或全异步路径更符合当前交互边界。

3. 被放弃方案的主要优点是什么？

   回答：纯文档路径成本最低；工具链中心路径工程落地直观；下游自治路径能提高局部迭代速度；全同步路径表面一致性强；全异步路径能降低入口耦合。这些优点都真实存在，但它们分别牺牲了契约真相、边界稳定、跨仓一致性或明确失败口径。

4. 为什么即便有这些优点，当前仍不采用？

   回答：因为 `L0-core` 的首要目标不是局部效率，而是给 27 仓提供稳定共享契约底座。任何会让契约真相分散、让派生产物反向成为真相、让下游各自解释共享 schema、或让同步 / 异步边界失真的路径，都不适合作为当前主线。

5. 当前选择牺牲了什么，换来了什么？

   回答：当前选择牺牲了一部分初期简洁性、局部生成效率和即时完成感，换来的是清楚的契约真相边界、稳定下游消费面、可追溯演进、可显式挂起的后台处理和不侵入相邻仓的职责边界。

### 7. 结构化中间产物

#### 7.1 方案路径比较表

| 方案路径 | 解决的问题 | 主要收益 | 主要代价 / 约束 | 当前结论 | 说明 |
|---|---|---|---|---|---|
| 契约来源仓 + 发布基线 / 只读快照 + 后台承接 | 解决跨仓契约真相、下游消费、兼容演进和变化感知需要同时成立的问题 | 真相边界清晰，下游消费稳定，派生可延后，变化可被感知，且不侵入 `L0-bus` / `L0-sdk` | 初期结构更重，需要维护发布基线、快照、追溯和挂起状态 | 采用 | 这是当前主线方案，最符合 `L0-core` 作为共享契约底座的目标。 |
| 纯文档 / 草案聚合路径 | 解决契约资料分散、旧文档难查的问题 | 成本低，迁移快，适合早期整理资料 | 缺少正式真相边界、兼容门禁和下游稳定消费面，容易继续形成多处解释 | 不采用 | 该路径只能改善可读性，不能让 `L0-core` 成为正式契约来源。 |
| 工具链 / 生成物中心路径 | 解决契约检查、生成和多语言派生的工程效率问题 | 工程落地直观，能快速支撑生成物和自动化检查 | 工具链、binding 或注册表状态容易反向成为契约真相，并污染 `L0-core` / `L0-sdk` 边界 | 不采用 | 生成和检查重要，但只能作为承接机制，不能成为本仓架构主语。 |
| 下游自治契约路径 | 解决各下游仓局部迭代速度和自主适配问题 | 下游改动快，局部阻塞少，短期协作成本低 | 共享 schema 容易漂移，跨仓语义不一致，破坏 L0 到上层的单向依赖关系 | 不采用 | 该路径牺牲平台级共享契约一致性，不适合 L0 底座。 |
| 全同步收口路径 | 解决每次契约变化都希望即时完成校验、派生、快照和下游确认的问题 | 表面一致性强，入口结果感明确 | 把不适合同步完成的校验、派生和下游消费压进入口，容易形成高耦合和伪同步完成 | 不采用 | 同步边界只适合入口判断和读取，不适合作为全部承接主线。 |
| 全异步流水线路径 | 解决同步入口复杂、长流程难以即时完成的问题 | 入口耦合低，后台扩展性好，适合长耗时处理 | 候选变更是否能进入正式边界缺少即时判断，失败口径容易延迟暴露 | 不采用 | `L0-core` 仍需要同步入口判断，不能把所有正式边界都推迟到异步流水线。 |

#### 7.2 轻量取舍对照表

| 当前方案得到什么 | 当前方案失去什么 | 取舍说明 |
|---|---|---|
| 契约真相边界清晰 | 不如纯文档路径轻量 | L0 底座需要正式真相，不能只做资料整理。 |
| 下游通过只读快照稳定消费 | 不如下游自治路径灵活 | 平台级一致性优先于单仓局部速度。 |
| 校验 / 派生可后台挂起 | 不如全同步路径有即时完成感 | 避免伪同步完成，显式暴露挂起和失败状态。 |
| 契约变化可被下游感知 | 不直接获得事件总线投递能力 | 变化感知属于契约边界，投递实现属于 `L0-bus`。 |
| 工具链作为支撑机制 | 不把生成效率作为唯一主线 | 工具链服务契约真相，不能反向定义契约真相。 |

## 5. 改动前后对比

| 维度 | 改动前 | 改动后 |
|---|---|---|
| 文档主线 | binding / wrapper / middleware / subscription / release 旧主线 | official client access layer、semantic baseline、derived view、runtime boundary、candidate evidence、compatibility 新主线 |
| 组织轴 | 按旧能力主题和语言目录展开 | 按 Rust workspace 与实现职责模块展开 |
| 协议口径 | 容易误写成 HTTP / RPC server | P0 固定为 Rust DTO + Rust client method / CLI command / event topic / operations job |
| 状态口径 | `Built`、public release 等旧口语可能混入 | `PackageCandidateStatus`、`EvidenceResult`、`EvidenceRedactionStatus` 等正式状态收敛 |
| 依赖口径 | 容易依赖服务仓源码或 bus runtime | 只允许 `core-contracts` / `bus-contracts` 编译期依赖，运行期走 port / adapter |
| 实施入口 | 旧文无法直接指导新版 P0 实现 | 正式 `03` + 校准中间产物可作为实施入口 |

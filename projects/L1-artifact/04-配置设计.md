#### 配置来源链图: L1-artifact 配置覆盖链

```text
[code defaults]
  -> [strict JSON config file]
  -> [environment variables]
  -> [entry-local selectors / current job run narrowing]
  -> [infra::config parse / validate]
  -> [ArtifactRuntimeConfig]
  -> [runtime_builder]

```

关键说明:

- entry-local 和 current job run 不是普通全局覆盖层,只作用于当前入口或当前 run。
- `domain`、`contracts` 和 `application` 不读取 raw config。
- builder 未进入 `Ready` 前,不得暴露 API / worker / jobs facade。

| 控制面 | 作用 | 对应模块 | 是否 P0 |

| source resolver / inbound consumer | 控制外部语境、方法定义、runtime signal、external content source 进入方式 | source resolvers, worker consumers | 是 |
| relay publication / topic map | 控制 relay publisher adapter 和 topic-neutral key 到 transport route 的绑定 | relay publisher adapter, worker publisher loop | 是 |
| operations job runners | 控制 publish、rebuild、refresh、reconcile、handoff 等 runner 的 batch、parallelism、timeout、retry | `jobs`, worker maintenance loop | 是 |
| handoff / target delivery | 控制 archive、observability、sync target 是否启用及 target registry | handoff adapters, handoff jobs | 是 |
| boundary / idempotency / freshness | 控制 handler/query/job 边界、retention、freshness 和 replay window | api/query handlers, idempotency/result stores, maintenance jobs | 是 |

## 4. 配置分类与边界

> 校准来源:
> - `design-calibration/04_config_step_04_categories_boundaries.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“配置类别表”“禁止配置化项表”“按配置域组织的分类边界表”和“跨分类 / 禁止项审计表”小节。

| 配置类别 | 说明 | 示例 | 是否允许热更新 | 主要风险 |
|---|---|---|---|---|
| static design boundary | 设计不变量,不是普通配置 | truth ownership、body-free、query no-write、job no-truth-repair | 不适用 | 被当成配置项会绕过架构红线 |
| startup runtime config | runtime 构造前读取并冻结 | profile、store binding、resolver binding、topic map、redaction deny list | P0 不允许 | 启动后改变会破坏 builder / UoW 一致性 |
| job-run-start config | 每次 job run 开始时冻结 | batch、parallelism、timeout、target selection、replay root | 不属于 hot update | job 中途改变会导致 report 不可复核 |
| entry-local parameters | 只影响当前入口 | config source selector、profile selector、job request source、artifact/report root | 不属于 hot update | 覆盖全局配置会绕过 typed input |
| policy-like technical knobs | 技术执行策略,不是业务政策 truth | retry、retention、page limit、timeout | startup 或 job-run-start 冻结 | 误用于改变业务边界 |
| sensitive ref config | 普通配置只保存 ref,不保存秘密材料 | credential ref、route ref、target ref、replay root ref | P0 不允许 raw secret hot update | 泄露到 config、log 或 audit |
| diagnostic / redaction config | 控制安全诊断输出和 forbidden field 扫描 | deny field refs、safe diagnostic prefix | P0 startup 冻结 | 放宽会泄露 forbidden body |
| test fixture / deterministic config | 支撑 local / CI / replay 可复现 | fake adapter、fixed clock、deterministic id、fixture set | 仅 test harness / replay 生效 | 进入非测试语义会伪造外部成功 |

| 禁止配置化项 | 原因 | 如需改变应走什么流程 |
|---|---|---|
| Artifact truth ownership | 防止相邻仓、consumer、handoff 反向定义 Artifact truth | 修改 `00/01/02/03` truth boundary |
| 外部正文排除 | 防止保存 method、content source、archive、sync、observability 等正文 | 修改需求和详细对象契约 |
| state matrix / shared rules | 防止 profile 或 env 改变合法迁移 | 修改状态矩阵和 domain tests |
| actor / capability / visibility guard | 防止配置绕过授权和可见性 | 修改安全 / visibility 设计 |
| command metadata / idempotency requirement | 防止 accepted mutation 无法 replay | 修改协议 envelope 和 idempotency contract |
| accepted trace / audit / relay / stored result | 防止 accepted truth 无法追溯或 duplicate replay | 修改 accepted flow 和持久化契约 |
| relay payload snapshot truth source | 防止 publisher 从 current truth 现查现造 payload | 修改 relay / payload contract |
| query no-write | 防止 query 修复 projection/reference/truth | 修改 query protocol 和 flow |
| job no-truth-repair | 防止 rebuild/refresh/reconcile/handoff 成为隐式 command | 修改 job flow 和 ownership |
| raw secret / raw endpoint / raw payload output | 防止敏感材料进入配置、日志、报告或 artifact | 修改 security / redaction design |
| fake adapter semantic shortcut | 防止 fake 跳过正式 version、state、receipt、marker 边界 | 修改 fake adapter tests 和 service flow |

## 5. 配置来源、优先级与冲突处理

> 校准来源:
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“配置来源优先级表”“冲突处理表”“按配置域组织的来源覆盖表”和“来源优先级停审记录”小节。

普通配置来源优先级固定为:

```text
code defaults < strict JSON config file < environment variables
```

entry-local parameters 不参与全局覆盖,只影响当前 entry 或当前 job。test fixture / deterministic override 只允许 local / CI test harness 使用。P0 不支持 config center 或 admin override。

| 来源 | 优先级 | 适用配置 | 冲突处理 | 不可用时策略 |
|---|---|---|---|---|
| code defaults | 1 | local-dev / ci-test 默认值、safe boundary、fake/disabled baseline | 被 file / env 覆盖 | 默认值本身也必须通过 validator |
| config file | 2 | startup runtime config、store/adapter refs、topic map、boundary、retention、job defaults、feature flags | 覆盖 defaults;重复 key / alias key fail-fast | 指定但不可读 / 解析失败则 fail-fast |
| environment variables | 3 | profile selector、config path、有限 runtime refs、CI override | 覆盖 file / defaults;存在但非法 fail-fast | 缺失时退回低优先级;存在但非法不 fallback |
| secret / credential refs | 引用值可由普通来源提供 | credential ref、route ref、target ref、replay root ref | ref 冲突按普通来源优先级;raw value 一律 reject | ref 形态非法 fail-fast |
| entry-local parameters | 局部 | config source selector、profile selector、job request source、artifact/report root、dry-run selector | 只影响当前 entry;不得覆盖 startup invariant | 缺失必填 entry 参数则 reject 当前入口 |
| current job run local inputs | 局部 | current scope/current batch/current target/current replay root/current output root | 只影响当前 run,且只能在 formal 允许范围内收窄 | 非法 current run 输入 reject |
| test fixture / deterministic override | test-only | fake adapter output、fixture refs、fixed clock/id | 只在 test harness / replay profile 生效 | fixture 缺失 test fail-fast |
| config center | P1/P2 only | future remote config source | P0 启用视为 unsupported | validation reject |
| admin override | P1/P2 only | future operator override | P0 启用视为 unsupported | validation reject |

| 冲突场景 | 处理规则 | 是否阻断启动 / 操作 |
|---|---|---|
| 同一 key 出现在不同普通来源 | 高优先级覆盖低优先级 | 否,除非高优先级值非法 |
| 高优先级值类型 / 格式 / 范围非法 | fail-fast,不得回退低优先级 | 是 |
| config file 内重复 key | 视为配置歧义 | 是 |
| 同一语义出现多个 alias key | 视为配置歧义 | 是 |
| 必填 startup config 缺失 | startup fail-fast | 是 |
| 必填 current job run config 缺失 | current job reject | 阻断当前 job |
| 必填 entry-local 参数缺失 | current entry reject | 阻断当前入口 |
| enabled feature 缺 target / topic / adapter ref | fail-fast 或 current job reject | 是 |
| ordinary source 提供 raw secret / token / password | reject config | 是 |
| ordinary source 提供 forbidden body allowlist | reject config / design violation | 是 |
| env 试图关闭 static design boundary | reject config | 是 |
| config center / admin override in P0 | unsupported source | 是 |
| test fixture in non-test profile | reject profile | 是 |

## 6. 环境、部署 profile 与配置矩阵

> 校准来源:
> - `design-calibration/04_config_step_06_environment_profiles_matrix.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“profile 矩阵”“adapter mode 语义表”“profile 与作用域边界表”和“跨 profile 审计表”小节。

P0 正式 profile 只有四个: `local-dev`、`ci-test`、`integration-like`、`operations-replay`。`staging-like` / `production-like` 只作为 future direction 记录在 §13 / §14。

| Profile | 用途 | 来源组合 | 默认 adapter mode | 敏感配置口径 | 说明 |
|---|---|---|---|---|---|
| `local-dev` | 本地功能开发与入口联调 | defaults + local strict JSON + optional env + entry-local selector | fake / disabled / in-memory | fake refs 或无 secret;raw secret 禁止 | 默认可启动,不代表正式验收 |
| `ci-test` | deterministic contract / domain / service / fake integration tests | defaults + test config + CI env + fixture | deterministic fake / in-memory | fixture ref;raw secret 禁止 | 所有结果 run-scoped、可复现 |
| `integration-like` | 跨入口、controlled seam、adapter unavailable / degraded、topic completeness、handoff failure 映射 | config file + env refs + entry-local selector | controlled / real-like seam through ports | credential / endpoint / target refs only | 验证接缝和 failure mapping,不要求生产 endpoint |
| `operations-replay` | outbox、projection、reference refresh、reconciliation、handoff 的 replay 和恢复验证 | replay config + env refs + current job run inputs | replay-backed / controlled / fake | de-identified replay root ref only | 验证恢复、重跑、partial failure 和 report digest |

| Profile | Stores | Resolvers / consumers | Relay publisher | Handoff targets | Clock / id | Fixtures / replay |
|---|---|---|---|---|---|---|
| `local-dev` | in-memory | fake / disabled | fake publisher + local route refs | fake targets | system / local-sequence | none |
| `ci-test` | in-memory isolated per run | deterministic fake / fixture-only | fake publisher with asserted topic map | fake targets with injected failures | deterministic fixed | fixture set required |
| `integration-like` | in-memory or durable-like test store | controlled / real-like seam | controlled publisher / route map | controlled target refs | deterministic or controlled runtime clock | no generic fixture fallback |
| `operations-replay` | replay state store / fixture refs | replay snapshot / controlled resolvers | pending relay replay / fake publisher | replay or controlled target refs | replay clock / deterministic id | replay root required |

| Adapter mode | 含义 | 允许 profile |
|---|---|---|
| `fake` | 不访问真实外部依赖,但保持正式 port 语义 | `local-dev`, `ci-test` |
| `disabled` | 当前能力显式关闭,调用会 reject 或 skip formal optional path | `local-dev`, `ci-test`, `integration-like` |
| `controlled` | 通过 controlled seam 或模拟 unavailable/degraded 进行集成验证 | `integration-like`, `operations-replay` |
| `replay-backed` | 从去标识化历史状态或 artifact 根恢复运行语境 | `operations-replay` |
| `future-real-like` | future staging / production hardening candidate | 仅 future |

## 8. 敏感配置与密钥管理

> 校准来源:
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“敏感级别归一规则”“敏感配置读取链图”“敏感配置表”“P0 profile 敏感配置处理矩阵”“禁止输出与持久化边界表”和“读取 / 轮换 / 审计承接表”小节。

敏感级别统一为 `public`、`internal`、`sensitive`、`secret`。普通 JSON / env / entry-local / current job run 输入只能保存 opaque ref,不能保存 raw secret material 或 raw body。

| 敏感级别 | 含义 | 示例 | 处理要求 |
|---|---|---|---|
| `public` | 可公开,无敏感语义 | feature label、公开 profile 名 | 可进入公开示例 |
| `internal` | 内部运行配置,不应对外公开 | batch size、timeout、safe diagnostic prefix | 可进入内部配置文件 |
| `sensitive` | 暴露会泄露拓扑、目标或历史证据位置的 opaque ref | store ref、route ref、target ref、replay root ref | 只能保存 opaque ref,不得输出 full value |
| `secret` | 真实秘密材料 | password、private key、raw token、credential body | 不得进入普通配置、日志、报告、audit、trace |

#### 敏感配置读取图: opaque refs 到 runtime assembly

```text
[defaults / file / env / selectors]
  -> [opaque refs only]
  -> [infra::config parse / validate]
  -> [redacted config identity + validation issue refs]
  -> [runtime builder / adapter registry]
  -> [application ports]

[future secret provider]
  -> [adapter-internal credential resolution only]
  -> [never exposed to contracts / domain / application]
```

关键说明:

- ordinary source 只允许提供 opaque ref,不允许提供 raw secret 或 raw body。
- 若未来引入 secret provider,也只能在 infra adapter 内部解析。

| 配置族 | 级别 | 存储方式 | 轮换方式 | 禁止项 |
|---|---|---|---|---|
| `stores.*.configRef` | `sensitive` | 只保存 `store:*` opaque ref | 新 ref + restart | raw DSN / credential |
| `sourceResolvers.adapterRef` | `sensitive` | 只保存 resolver adapter ref | 新 ref + restart | raw endpoint / token / external body |
| `relay.publisherAdapterRef` / `transportTopicBindings` | `sensitive` | adapter ref + route ref | 新 ref / 新 route map + restart | raw topic credential |
| `handoff.*Targets` | `sensitive` | target ref list | 新 target set + restart 或 new run | target credential / package body |
| `testFixtures.replayArtifactRootRef` | `sensitive` | replay root opaque ref | 每次 run 单独提供 | raw historical body |
| `redaction.*` | `internal` | deny refs + prefix + safety bool | 新配置 + restart | 放空 deny list、放宽高基数标签 |
| future secret material | `secret` | 不进入普通配置 | provider-side only | 任何普通 source 明文承载 |

| 输出面 | 允许输出 | 禁止输出 |
|---|---|---|
| log / error | operation、profile、issue ref、safe diagnostic ref | full sensitive ref、secret、raw endpoint、raw body |
| audit | actor、scope、redacted old/new digest、reason、validation result | raw config、raw secret、full sensitive ref |
| trace / metric | low-cardinality kind / state / result | target ref、route ref、secret、body |
| report / marker / artifact | marker refs、failure refs、redacted digest | package body、sync body、credential、raw replay body |

#### 配置加载流程图: L1-artifact 配置加载与生效

```text
[entry-local selector chooses profile/config source]
  -> [code defaults]
  -> [selected strict JSON config file]
  -> [environment overrides]
  -> [source merge with conflict detection]
  -> [strict JSON parse]
  -> [type / enum / range / ref-shape validation]
  -> [cross-field validation]
  -> [sensitive / forbidden body validation]
  -> [ArtifactRuntimeConfig::from_validated_refs(...)]
  -> [ArtifactRuntimeBuilderState::for_config(...)]
  -> [store registry + adapter registry + availability markers]
  -> [api / worker / jobs facade exposure when Ready]
```

关键说明:

- 运行时只接受严格 JSON;JSONC 只允许文档示例。
- entry-local selector 只决定当前入口使用哪个 profile / config source / local output root。
- current job run 只能基于已冻结 runtime 做 run-local 收窄,不能回写 startup config。

| 配置域 | 加载时机 | 主要校验 | 生效方式 | 失败策略 |
|---|---|---|---|---|
| runtime | startup / current entry selector | known profile、strictValidation=true | startup 冻结 | startup fail-fast / current entry reject |
| stores | startup | required groups、known kind、configRef shape | startup 冻结 | fail-fast |
| sourceResolvers | startup | adapter ref、mode、disposition | startup 冻结 | fail-fast |
| inboundConsumers | startup | sourceMode、namespace list、schema version | startup 冻结 | fail-fast |
| relay | startup / current job run 收窄 | adapter ref、batch、retry ref、topic completeness | startup default;current run 收窄 | fail-fast / current job reject |
| jobs | startup / current job run 收窄 | batch、parallelism、timeout、retry ref | startup default;current run 收窄 | fail-fast / current job reject |
| handoff | startup / current job run 收窄 | target refs、feature/topic relation | startup target registry;current run 选择 | fail-fast / current job reject |
| boundary | startup | 正整数和 timeout 范围 | startup 冻结 | fail-fast |
| idempotency | startup | retention 窗口关系 | startup 冻结 | fail-fast |
| projection/reference | startup / current job run 收窄 | stale threshold、batch、optional event relation | startup default;current run 收窄 | fail-fast / current job reject |
| redaction | startup | deny list 非空、prefix 合法、高基数标签保持 false | startup 冻结 | fail-fast |
| clockId | startup / test harness | adapter ref、profile compatibility | startup 冻结 | fail-fast |
| testFixtures | test harness / replay run start | fixture ref、timestamp、replay root 必填性 | test harness / current run 冻结 | test fail-fast / current job reject |

| 生效方式 | P0 口径 | 适用配置 | 失败处理 |
|---|---|---|---|
| startup | runtime builder 前加载并冻结 | runtime、stores、sourceResolvers、relay、boundary、redaction 等核心配置 | builder `Failed`,不暴露 facade |
| current entry | 只影响当前入口 | profile selector、config source selector、job request source、artifact/report root | current entry reject |
| current job run | 在 job body 前冻结 | current batch/current target/current replay root/current output root | current job reject |
| test harness | fake runtime 组装前 | fixture set、fixed clock、deterministic id | test fail-fast |
| reload / hot | P0 unsupported | 无 | validation reject |

## 10. 配置变更、审计与回滚

> 校准来源:
> - `design-calibration/04_config_step_10_change_audit_rollback.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“变更 actor 与评审层级”“配置变更表”“审计记录规则”“回滚规则矩阵”和“敏感配置变更附加规则”小节。

P0 允许 startup config artifact、current entry selector、current job run local inputs、test fixture/replay refs 的正式变更。raw secret 注入、redaction 放松、reload/hot request、truth/state/visibility invariant override 不属于普通 config change。

| Actor / role ref | 允许范围 | 不允许范围 | 审计要求 |
|---|---|---|---|
| `operator_ref` | 提交 startup config artifact、执行 restart / rollback | 绕过 validator、注入 raw secret、覆盖 static design boundary | actor、reason、change request、old/new digest、validation result |
| `release_automation_ref` | 应用已评审 config artifact、记录 deployment/run digest | 自动批准 critical 变更、伪造 validation pass | release run ref、config digest、validation issue refs |
| `authorized_job_runner_ref` | 提交 current job run 的 scope / batch / target / replay root / output root | 覆盖 startup invariant、写 raw target credential | job run id、input digest、target digest、validation result |
| `entry_caller_ref` | 提交 current entry 的 selector / request source / local output root | 修改持久 runtime config | entry ref、selector digest、issue ref |
| `test_harness_ref` | 提交 fixture set、fixed clock/id、replay fixture | 进入非 test harness runtime | test run ref、fixture digest、profile ref |
| `design_change_ref` | 对 critical boundary 触发正式设计变更 | 当作普通 config change 直接生效 | design baseline commit、review ref |

| 评审层级 | 适用变更 | 要求 |
|---|---|---|
| `low` | batch/page/time limit 收窄、entry-local selector、dry-run 开关 | 可由 operator/release automation/entry caller 执行;仍需审计 |
| `medium` | 普通 profile 切换、fixture refs、clock/id refs、non-sensitive defaults | 至少需要 reviewer ref 或 release approval ref |
| `high` | store refs、resolver/publisher refs、topic bindings、handoff targets、retention、replay root、redaction deny list | 必须评审、审计、rollback plan |
| `critical` | raw secret 入普通配置、redaction 放松、reload/hot request、static boundary override | P0 直接 reject 或要求 formal design change |

| 生效方式 | 成功判定 | 回滚方式 | 不允许的回滚 |
|---|---|---|---|
| startup | config validation pass;builder `Ready` | restore previous validated config digest and restart | hot patch、skip validator、fallback invalid env |
| current job run | run-local validation pass;run context frozen | start new job with previous valid input or corrected input | mutate old report to pretend success |
| current entry | selector/path/root validation pass | caller rerun with previous selector | 持久化覆盖 global runtime config |
| test harness | fixture/replay validation pass | restore previous fixture/root and rerun test | leak fixture into non-test runtime |
| rejected critical change | validation rejects before activation | no runtime rollback;record rejection issue | emergency bypass activation |

审计记录只允许使用 product-neutral refs,例如 `change_request_ref`、`actor_ref`、`reason_ref`、`config_section`、`profile_ref`、`activation_kind`、`old/new digest`、`validation_result`、`validation_issue_ref`、`rollback_ref`、`safe_diagnostic_ref`。不得记录 raw config、raw secret、full sensitive ref、endpoint、route credential 或 external body。

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源:
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“策略术语定义”“失效模式表”“按配置域组织的失败策略表”“告警规则表”和“测试切口表”小节。

| 策略 | 本项目含义 | 适用范围 | 不适用范围 |
|---|---|---|---|
| `fail-fast` | 在 startup / entry / job-start / test 早期直接失败 | startup config、job input、entry selector、fixture、required adapter binding | 已提交 truth 或 stored result 的事后改写 |
| `fail-closed` | 安全边界不明确时拒绝继续 | raw secret/body、unsafe redaction、static boundary override | 普通低风险数值收窄 |
| `degraded` | 显式返回 stale / unavailable / unresolved surface,且 no-write | query view / reference unavailable、runtime resolver unavailable | startup config 非法 |
| `delayed` | 因临时依赖不可用而推迟处理 | inbound consumer unresolved、retryable resolver / handoff / publish path | 非法配置 |
| `failed marker` | 通过正式 marker / report 记录运行期失败 | relay publish、reference refresh、handoff prepare/deliver | startup parse/type/range failure |

| 失效模式 | 系统行为 | 是否告警 | 备注 |
|---|---|---|---|
| strict JSON parse failed | startup fail-fast;builder `Failed`;不暴露 facade | 是 | JSONC / 注释 / trailing comma 视为非法 |
| unknown field / missing required / invalid type/range | startup fail-fast;entry / current job reject | 是 | 高优先级非法值不得 fallback |
| raw secret / raw body / unsafe redaction config | fail-closed;validation reject | 是 | 不允许宽松继续 |
| required store / resolver / publisher / clock / id binding invalid | startup fail-fast | 是 | required adapter slot 未闭合 |
| current job target / batch / replay root invalid | current job reject | 是 | 不进入 job body |
| current entry selector invalid | current entry reject | 可选 | 不改变 global runtime |
| query path resolver/projection/reference unavailable | degraded / unavailable;no write | 是/聚合 | query 不得顺手 repair |
| inbound consumer resolver unavailable | delayed receipt 或 failed marker;no guessed truth write | 是 | consumer 不得悄悄成功 |
| relay publish failed | failed / retryable marker;truth unchanged | 是 | 不回滚 accepted truth |
| handoff target unavailable / delivery failed | failed / retryable handoff record;truth unchanged | 是 | 不保存 package/sync/observability body |
| config digest drift | startup fail-fast 或 release gate block | 是 | previous validated digest 才可 rollback |
| config center / admin override / hot reload / online LKG request | validation reject | 是 | P0 unsupported |

### 读前说明 · 验收标准标准生产流程

`06-验收标准` 不是从“我想验什么”开始写,而是从 `02/03/05` 已明确的目标、边界、红线、主流程结果和测试门禁反推验收门禁。

建议按以下流程产出:
1. **先收输入**
   - 读取 `02-概要设计.md`、`03-详细设计.md`、`05-测试方案.md`
   - 抽取: 目标/非目标、主要部分边界、主流程关键结果、实现红线、高风险验收点、最小可运行闭环、05 中的强测试门禁
2. **再识别验收对象**
   - 分清功能结果、边界结果、状态结果、对外交互结果、恢复结果、投影结果
3. **按主要部分分组**
   - 每个主要部分分别列: 必须满足什么 / 绝不能出现什么 / 哪些是一票否决
4. **明确通过/不通过条件**
   - 每条验收项必须写清通过条件、失败条件、失败意味着哪条边界被破坏
5. **最后形成门禁清单**
   - 单列一票否决项、可延期优化项、风险接受项与接受人

> 先按“主要部分 + 不可破坏边界”组织,再落成功能门禁和非功能门禁,不要只写口号式验收条目。

## 1. 验收背景与范围

### 1.1 验收背景

本次验收针对 `L1-conversation` 的第一批核心设计主线展开。当前 `02-概要设计.md`、`03-详细设计.md` 与 `05-测试方案.md` 已经明确:
- `L1-conversation` 是协作对话真相仓,不是前端 UI 仓
- Conversation / Turn / participant 构成正式对话真相层
- Turn 必须 append-only,任何编辑都只能通过 supersede 形成新记录
- `work / governance / artifact / process / identity` 的输入只能通过 event→turn 接缝进入可见层
- StreamEvents 只是实时映射层,不是正式对话真相本体
- summary / history / bridge-facing view / search document 都是只读投影,不反写真相

因此,本次验收的目的不是笼统判断“能不能聊天”,而是判断 conversation 的空间边界、历史真相、事件接缝、实时推送和只读投影是否真的成立,是否可作为后续阶段的稳定基线。

### 1.2 验收范围 / 非范围

| 项 | 是否纳入 | 说明 |
|---|---|---|
| 对话空间与参与者部分 | 是 | group / channel / dm / thread、participant、visibility、archive、lock |
| Turn 事实流部分 | 是 | user/member/system/gate/artifact/progress turn 与 supersede |
| 事件转对话接缝部分 | 是 | work / governance / artifact / process / identity 事件输入 |
| 实时推送与 AG-UI 映射部分 | 是 | StreamEvents、last_event_id、补发与续传 |
| 检索与只读投影部分 | 是 | summary / history / bridge-facing view / search |
| chat / console 前端视觉细节 | 否 | 不在本次仓级验收范围内 |
| bridges 外部协议适配正文 | 否 | 只验 conversation 提供的只读视图与流输出,不验外部桥接内部实现 |
| Gate decision / Artifact 正文 / Project / Process 真相内部逻辑 | 否 | 只验 conversation 的消费边界,不验上游仓内部正文实现 |

| SupersedeTurn | 编辑或修正只能新增 supersede Turn,旧 Turn 必须保留且可追溯 | supersede 链 / history compare | [] |
| AppendSystemTurnFromEvent(gate) | `governance.gate.raised/decided` 必须正确翻译为 gate turn | 事件日志 / turn 记录 / summary 变化 | [] |

| StreamConversationEvents | 新 Turn 或关键状态变化必须生成可消费的实时流事件 | stream log / consumer trace | [] |

| 门禁项 | 要求 | 证据 | 结论 |

## 8. 缺陷分级与放行规则

| 缺陷级别 | 是否允许放行 | 说明 |
|---|---|---|
| S | 否 | Turn append-only 被破坏 / projection 反写真相 / event 污染外域边界 / participant 权限边界失效 |
| A | 视情况 | 主线可跑但 stream / projection / idempotency 不稳 |
| B | 可带着走 | 非关键桥接视图、低优先级查询或次要展示行为异常 |

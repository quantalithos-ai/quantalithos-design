## 1. 本步目标

基于 Step 2 的仓边界、Step 7 的核心能力闭环和 Step 9 的功能需求,用需求层硬规则钉住 `L1-conversation` 的对话真相边界。本步不写实现校验逻辑、接口约束、数据库约束、状态机编码、字段清单、事件 schema 或具体异常码。

## 3. SOP 问题回答

### 3.1 哪些不变量必须始终成立？

Conversation 的不变量集中在五个方面:对话事实必须有明确对话空间和参与范围;对话事实必须以追加方式形成历史;对话消费必须受授权视野约束;跨域事实显化不得接管原始真相;对话历史必须能支撑追溯和复盘。

### 3.2 哪些行为必须禁止？

必须禁止把 Conversation 退化为 Chat UI 缓存、Workspace 视图状态、Bridges 外部平台副本、Runtime 临时上下文、Governance 决策记录、Artifact 正文仓或 Identity 生命周期仓。也必须禁止通过查询、消费、维护、跨域显化等动作隐式创造或篡改对话业务事实。

### 3.3 哪些状态变化必须显式发生,不能隐式发生？

对话空间、参与范围、可见范围、对话事实追加、跨域引用显化和维护性辅助结果变化都必须是显式变化。任何读取、消费、检索、投影、索引或外部同步动作都不能隐式改变业务事实。

### 3.4 哪些边界不能被打穿？

不能打穿的边界包括:Chat UI 展示边界、Workspace 聚合边界、Bridges 外部协议边界、Runtime 推理边界、Governance 决策边界、Artifact 正文边界、Identity 成员生命周期边界、Observability / Archive 横切边界。

### 3.5 哪些操作必须附带治理、审计或引用条件？

治理事实进入对话视野时必须保留治理结论引用,但不接管治理决策。产物、项目、成员等跨域事实进入对话视野时必须保留来源引用。对话事实、参与范围、可见范围和维护性辅助结果的关键变化必须可追溯。

## 5. 改动前后对比

| 项 | 改动前 | 改动后 | 原因 |
|---|---|---|---|
| 规则表达 | 条件 / 结果式,夹杂事件名和对象值 | 按不变量、禁止行为、显式变化、边界约束、治理约束、审计约束表达 | 对齐需求规范 §4.10 |
| Turn 不可变 | 写成原记录不可 UPDATE | 写成对话事实必须以追加方式形成历史,不得覆盖已有业务事实 | 避免实现术语 |
| 权限 / 可见性 | 写成不可读私聊 / group | 写成授权视野消费不变量 | 规则不绑定具体形态 |
| 跨域事实 | 写成特定事件转特定 Turn | 写成引用显化,原始真相仍归相邻仓 | 防止 Conversation 接管相邻仓 |
| 维护行为 | 旧文档未单独约束 | 明确维护辅助结果不得改变业务事实 | 支撑外围增强能力不串线 |

| BR-CONV-004 | 不变量 | 跨域事实进入对话视野时只能成为引用型可见记录,原始业务真相仍归属来源仓。 | 跨域事实显化 |

| BR-CONV-006 | 禁止行为 | 不得把 Chat UI 展示状态视为 Conversation 真相。 | Conversation / Chat 边界 |
| BR-CONV-007 | 禁止行为 | 不得把 Workspace 个人或项目聚合视图视为 Conversation 真相。 | Conversation / Workspace 边界 |
| BR-CONV-008 | 禁止行为 | 不得由 Conversation 直接承担外部聊天平台协议生命周期。 | Conversation / Bridges 边界 |
| BR-CONV-009 | 禁止行为 | 不得由 Conversation 执行 LLM 推理、agent loop 或工具调用。 | Conversation / Runtime 边界 |
| BR-CONV-010 | 禁止行为 | 不得由 Conversation 裁决 Gate、Policy 或 Approval 的业务结论。 | Conversation / Governance 边界 |
| BR-CONV-011 | 禁止行为 | 不得由 Conversation 保存或拥有 Artifact 正文、版本或证据链真相。 | Conversation / Artifact 边界 |

### 7.3 规则类型结论

| 规则类型 | 本步使用情况 | 说明 |
|---|---|---|
| 不变量 | 已使用 | 用于保护 Conversation 作为对话真相仓的核心成立条件 |
| 禁止行为 | 已使用 | 用于防止 Chat、Workspace、Bridges、Runtime、Governance、Artifact、Identity 职责回流 |
| 显式变化 | 已使用 | 用于防止读取、消费、投影、检索等动作隐式改变业务事实 |
| 边界约束 | 已使用 | 用于保护跨仓真相边界和输出使用方边界 |
| 治理约束 | 已使用 | 用于约束治理事实显化不能替代治理结论 |
| 审计约束 | 已使用 | 用于约束对话事实和维护辅助动作必须可追溯 |

## 2. 本次配置设计目标与范围

> 校准来源:

```text
EstablishGlobalMember
  -> MaintainRoleCapabilitySummary
  -> PublishIdentityOutbox
  -> RebuildIdentityProjection
  -> ReadMemberSummary
```

| 目标 | 说明 | 交付给下游的结果 |

## 3. 配置控制面总览

> 校准来源:
> - `design-calibration/04_config_step_03_control_plane.md`

配置只能由 `identity-infra` 的 config loader / runtime builder 读取。`identity-application` 只接收已注入的 repository、port、facade 或 typed run parameter;`identity-domain` 和 `identity-contracts` 不读取 raw config。

#### 配置来源链图: L1-identity 配置覆盖链

```text
[code defaults]
  -> [strict JSON config file]
  -> [environment variables]
  -> [opaque refs / safe selectors]
  -> [entry-local selector / job input where allowed]
  -> [test fixture / deterministic override where allowed]

        |
        v

[infra config parse / validate]
  -> [validated config snapshot]
  -> [runtime builder / composition root]
  -> [store registry + adapter registry + injected ports]
  -> [application facades]
  -> [api / worker / jobs entries]
```

| 控制面 | 作用 | 对应模块 | P0 |
|---|---|---|---|
| profile / runtime assembly | 选择 profile、adapter policy 和 facade 装配方式 | infra config, runtime builder, entries | 是 |
| store / transaction carrier | 选择 truth/outbox/projection/report/idempotency store 和 UoW 绑定 | persistence, repositories, UoW | 是 |
| actor context / entry metadata | 校验 trusted context、trace、idempotency metadata | api/worker/jobs entry validators | 是 |
| role and capability source | 绑定 role/capability safe summary 来源和 fingerprint guard | role resolver, summary maintenance | 是 |
| bus / outbox publication | 绑定 topic-neutral route、publisher adapter、publish knobs | outbox repo, publisher port, publish job | 是 |
| projection / report / reference | 绑定 read model、checkpoint、rebuild、reference/report stores | projection/query/jobs | 是 |
| external refs / handoff | 绑定 artifact、memory/archive、governance、work source、handoff adapters | resolver and handoff adapters | P1 默认 disabled |
| operations jobs | 绑定 publish/rebuild/refresh/reconcile/handoff/retry runner knobs | jobs entry and services | 是 |
| audit / redline / observability | 绑定 audit sink、redaction profile、safe diagnostic 和 redline guard | audit, trace, metrics | 是 |
| deterministic test / fixture | 绑定 fake adapters、clock/id、fixture seed | test harness, fake runtime | 是 |

## 4. 配置分类与禁止配置化边界

> 校准来源:
> - `design-calibration/04_config_step_04_categories_boundaries.md`

配置分为 startup runtime config、job-run-start config、entry-local parameters、technical knobs、sensitive ref config、diagnostic/redaction config、test fixture/deterministic config 和 feature/peripheral enablement。static design boundary 不是配置项。

| 配置类别 | 说明 | 示例 | 是否允许热更新 | 主要风险 |
|---|---|---|---|---|
| static design boundary | 不可被配置覆盖的设计不变量 | truth ownership、state matrix、query no-write | 不适用 | 被当配置会绕过详细设计 |
| startup runtime config | runtime 暴露 facade 前读取并冻结 | profile、store、adapter、topic、redline | P0 不允许 | 启动后改变破坏一致性 |
| job-run-start config | 每次 job run 开始时冻结 | batch、timeout、retry、scope、report refs | 不属于 hot update | job report 和 replay 不可复核 |
| entry-local parameters | 只影响当前 entry | actor marker、page cursor、run id、dry-run selector | 当前入口 | 越权覆盖全局配置 |
| policy-like technical knobs | 技术执行策略,不是领域规则 | retry、retention、batch、timeout | startup 或 job-run-start | 误改 lifecycle / visibility |
| sensitive ref config | 只保存 ref,不保存材料本体 | store ref、endpoint ref、sink ref | P0 不支持 raw hot update | 泄露敏感目标或 credential |
| diagnostic / redaction config | 控制安全诊断输出 | redaction profile、safe labels | startup | 泄露 forbidden body |
| test fixture / deterministic config | 支撑 local/CI 可复现 | fake adapter、fixed clock、seed ref | test/local only | 污染 integration-like |
| feature / peripheral enablement | 控制外围能力是否启用 | optional export、external smoke | startup | 控制核心 accepted path |

| 禁止配置化项 | 原因 | 如需改变应走什么流程 |
|---|---|---|
| identity 内部认证实现 | 身份入口安全由上游 API layer 承担 | 修改入口安全架构和 `03` inbound contract |
| query / consumer 自动创建 `GlobalMember` | 创建必须通过显式 command | 修改 protocol、flow 和验收红线 |
| `GlobalMemberRef` 释放、复用或由配置生成 | ref identity 是 truth invariant | 修改 object/id generation contract |
| `GlobalLifecycleState` 状态矩阵 | 状态机是 domain 不变量 | 修改 domain object / state matrix |
| high-risk lifecycle guard / `GovernanceBasisSummary` 校验 | 高风险动作必须有正式 basis | 修改 lifecycle flow 和 resolver contract |
| RoleDefinition / CapabilityDefinition body 进入 identity | 外部 method-library 拥有定义正文 | 修改数据所有权 |
| Project / WorkItem / ProjectMember truth 进入 identity | work 拥有项目参与真相 | 修改跨仓 ownership |
| memory/archive body、artifact/evidence body 进入 identity | identity 只保存 refs / markers | 修改对应外部系统边界 |
| raw request/event/job/source/adapter/receipt body 输出 | 防止泄露 forbidden material | 修改 security / redaction design |
| command / consumer / callback / job idempotency requirement | 防止 duplicate mutation | 修改 envelope、repository 和 flow |
| stored replay surface | duplicate replay 必须返回 stored public surface | 修改 stored result/report contract |
| accepted same-UoW transaction order | truth、trace/audit、outbox、stale、stored result 必须同事务 | 修改 transaction contract |
| repository expected_version / cursor source | concurrency source 不是配置值 | 修改 repository / cursor contract |
| outbox publisher 创造业务事件 | publisher 不是业务决策点 | 修改 outbox event contract |
| query 写 truth、audit、projection、reference、outbox 或 report | query 是 visibility-first read surface | 修改 query protocol |
| maintenance job 修复 core truth | job 只维护 derived/reference/report/handoff material | 修改 operations job flow |
| non-core sibling repo 作为 Cargo dependency | 协作通过 port/event/handoff | 修改架构依赖裁剪 |
| fake / controlled / disabled adapter 默认成功 | fake 不能替代业务语义 | 修改 fake parity contract tests |

## 5. 配置来源、优先级与冲突处理

> 校准来源:
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`

P0 普通配置来源优先级固定为 `code defaults < config file < environment variables`。opaque refs 遵守普通来源优先级,但 raw secret/body 不进入普通来源链。entry-local parameters 不覆盖全局配置,只影响当前 entry 或 current job run。test fixture / deterministic override 只在 test-scoped profile 和 test harness 中生效。

| 来源 | 优先级 | 适用配置 | 冲突处理 | 不可用时策略 |
|---|---:|---|---|---|
| static design boundary | 0 | truth、state、query、outbox、idempotency 红线 | 不参与覆盖 | 不适用 |
| code defaults | 1 | 安全默认值、P0 fake/disabled baseline | 被 file 覆盖 | 缺失视为设计缺口 |
| config file | 2 | profile、store refs、adapter mode、topic refs、job defaults | 被 env 覆盖;重复 key fail-fast | required missing fail-fast |
| environment variables | 3 | profile selector、non-sensitive override、opaque refs | 覆盖 file;非法值 fail-fast | required missing 按配置项策略 |
| opaque refs | follows ordinary source | credential/endpoint/target/report refs | raw material reject | ref malformed fail-fast/reject |
| entry-local parameters | local only | run id、page cursor、dry-run selector、current job input | 只影响当前入口/run | invalid reject current entry/run |
| test fixture / deterministic override | test only | fake source、fixed clock/id、seed refs | 只允许 local-dev / ci-test | 越界 fail-fast |
| config center / admin override | P0 unsupported | 无 | P0 出现即 reject | future 先回写 `03/04` |

| 冲突场景 | 处理规则 | 是否阻断 |
|---|---|---|
| config file 重复 key 或 alias key | 配置意图歧义 | startup fail-fast |
| env 提供非法高优先级值 | 不 fallback 低优先级 | fail-fast / reject |
| ordinary source 提供 raw secret/body | validation reject | fail-closed |
| fixture 出现在 integration-like | profile validation reject | fail-fast |
| entry-local 覆盖 startup store / adapter / redline | reject current entry/run | 阻断当前入口/run |
| publisher enabled 但 topic map 缺失 | publisher 不可安全发布 | startup fail-fast |
| redline guard 被关闭 | critical rejected | startup fail-fast |

## 6. 环境、部署 profile 与配置矩阵

> 校准来源:
> - `design-calibration/04_config_step_06_environment_profiles_matrix.md`

P0 profile 固定为 `local-dev`、`ci-test`、`integration-like`、`operations-replay`。`staging-like` 和 `production-like` 只是 P1/P2 方向,不作为 P0 must-pass profile。`fake`、`controlled`、`endpoint`、`disabled` 是 adapter mode,不是 profile。

| 环境 / profile | 用途 | 配置来源 | 外部依赖 | 敏感配置处理 | 差异说明 |
|---|---|---|---|---|---|
| `local-dev` | 本地开发、手动 smoke、快速检查 command/query/job 主链 | defaults + optional local file/env | in-memory stores、fake adapters、local audit sink | fake refs or absent | 不作为 release evidence |
| `ci-test` | CI 自动化、contract、repository、outbox、projection、redline tests | defaults + test config + CI-safe env + fixture | isolated in-memory、deterministic fake、fixed clock/id | fixture refs;redacted evidence | P0 自动化基础证据 |
| `integration-like` | controlled seam、topic completeness、failure mapping、no fake fallback | config file + env refs + entry selector | controlled / real-like adapter seam | credential/endpoint/target refs only | 不要求生产 endpoint |
| `operations-replay` | outbox、projection、reference refresh、reconciliation、handoff、stored replay | replay config + env refs + job input | de-identified historical refs、fake/controlled adapters | report/input root refs;raw body forbidden | 验证恢复、重跑和 report |
| `staging-like` | P1 dry-run / release candidate | deployment config + env refs + future provider refs | future durable store、real-like bus/resolvers | provider refs only | 不阻塞 P0 |
| `production-like` | P1/P2 production operations | deployment / operations material | approved production dependencies | approved provider refs only | 具体 runbook 留 `09` |

| Profile | Store | Role source | Publisher | External refs | Audit | Clock / id |
|---|---|---|---|---|---|---|
| `local-dev` | in-memory | fake fixture | fake | disabled/fake | local/captured | system or deterministic |
| `ci-test` | isolated in-memory | deterministic fixture | fake with asserted topic map | fake/disabled by suite | captured | fixed deterministic |
| `integration-like` | in-memory or durable-like | controlled | controlled publisher | controlled or disabled | controlled | controlled/deterministic |
| `operations-replay` | replay state store | replay snapshot | pending outbox replay | replay refs or disabled | report sink | replay run clock |
| `staging-like` | future durable | future endpoint | future real-like route | future endpoints | future observability | runtime |
| `production-like` | future production durable | approved endpoint | production topic map | approved endpoints | production observability | production provider |

## 8. 敏感配置与密钥管理

> 校准来源:
> - `design-calibration/04_config_step_08_sensitive_secrets.md`

普通 config file、environment variables、entry-local parameters、job input 和 test fixture 只能保存 opaque refs 或 safe selectors,不得保存 raw credential material、raw endpoint material、external body、adapter response body、role/capability body、memory body、archive package、artifact/evidence body 或 historical replay body。

| 配置项 | 敏感级别 | 存储方式 | 是否可明文 | 轮换方式 | 审计要求 |
|---|---|---|---|---|---|
| `store.dsn_ref` | sensitive | ordinary source 保存 durable store ref | 不可保存 raw DSN / credential | new ref + restart | key、source kind、profile、redacted digest |
| `role_catalog.snapshot_ref` | sensitive-adjacent | 保存 protected snapshot ref | 不可保存 role/capability body | restart | source mode、fingerprint、digest |
| `role_catalog.fixture_ref` | test-internal | local/CI fixture ref | 不可保存 fixture body | test rerun | fixture digest;non-test reject |
| `bus.endpoint_ref` | sensitive | publisher endpoint ref | 不可保存 transport credential | restart | publisher mode、adapter slot、digest |
| `bus.topic_map_ref` | sensitive-adjacent when real | topic-neutral map ref | 不可保存 transport secret or payload body | restart | map digest、coverage result |
| `operations.replay.report_root_ref` | sensitive-adjacent | replay config/job input ref | 不可保存 raw report body | new job run | run id、root digest |
| `operations.replay.input_root_ref` | sensitive-adjacent | replay config/job input ref | 不可保存 historical raw body | new job run | run id、root digest、redaction marker |
| `external_refs.*.endpoint_ref` | sensitive | endpoint mode refs | 不可保存 upstream credential/body | restart | adapter family、mode、digest |
| `external_refs.trace_handoff.target_ref` | sensitive | handoff target ref | 不可保存 target credential/package body | restart or new job run | target digest、job run id |
| `audit.sink_ref` | sensitive | audit/trace sink ref | 不可保存 sink credential | restart | sink mode、digest、compensation status |
| `audit.redaction_profile` | internal safety-critical | profile name | 可保存 name;不可保存 matched raw values | restart | old/new profile digest |
| `redline.*` | internal safety-critical | fixed true guards | bool 可见;false 不允许 | 不可放宽 | rejected attempt audit |
| `fixture.seed_ref` | test-internal | test seed ref | 不可保存 raw seed body | test rerun | fixture digest |

| 输出面 | 允许输出 | 禁止输出 |
|---|---|---|
| config parse / validation error | key path、source kind、profile、validation issue ref | raw value、full sensitive ref、credential、external body |
| log / public error | operation kind、adapter slot、safe failure class、issue ref | endpoint credential、adapter raw response、fake private fixture map |
| audit / trace | actor ref、operation ref、redacted digest、safe metadata | raw config、external body、raw credential material |
| metrics | low-cardinality operation/profile/mode/failure class | full ref、actor id、member id、request digest |
| job report / evidence | run id、counts、safe refs、redacted digests | raw historical input、target credential、raw report body |

## 9. 配置加载、校验与生效机制

> 校准来源:
> - `design-calibration/04_config_step_09_loading_validation_activation.md`

运行时配置只接受严格 JSON。JSONC 注释只允许出现在文档示例,不得进入 runtime parser。

```text
[code defaults]
  -> [optional strict JSON config file]
  -> [environment variable overrides]
  -> [entry-local selector / job input where allowed]
  -> [source merge with conflict detection]
  -> [strict JSON parse]
  -> [known-field validation]
  -> [type / enum / range / ref-shape validation]
  -> [cross-field validation]
  -> [sensitive / forbidden material validation]
  -> [activation validation: no reload / hot in P0]
  -> [validated config snapshot]
  -> [runtime builder]
  -> [application facades]
  -> [api / worker / jobs entries]
```

| 配置项 / 配置组 | 加载时机 | 校验方式 | 生效方式 | 失败策略 |
|---|---|---|---|---|
| `profile.*` | startup;entry selector local | enum、known profile、test override compatibility | startup freeze;entry local only | fail-fast / reject entry |
| `store.*` | startup | mode、required refs、migration baseline、transaction/idempotency guard | runtime builder store registry | fail-fast |
| `actor_context.*` | startup + per-entry metadata | bool invariants、trusted profile、trace/idempotency presence | entry validators | fail-fast / reject entry |
| `role_catalog.*` | startup/test harness | source mode、snapshot/fixture refs、fingerprint true、unknown reject-write | resolver adapter | fail-fast |
| `bus.*` | startup | publisher mode、endpoint refs、topic map coverage | publisher adapter + route binding | fail-fast |
| `outbox.*` | startup;batch may be run-local | non-empty store、positive batch/attempts、failure mode fixed | outbox repo + frozen job params | fail-fast / reject job |
| `projection.*` | startup;batch/checkpoint may be run-local | non-empty names、positive batch、not-ready enum | projection repo + query guard | fail-fast / reject job |
| `operations.*` | startup/job-run-start | run id required、replay refs by profile、retry compatibility | jobs entry guard + frozen params | reject job |
| `external_refs.*` | startup/job-run-start target refs | mode enum、explicit disabled、endpoint required when enabled | adapter availability markers | fail-fast / fail-closed |
| `audit.*` | startup | sink mode, endpoint ref when required, compensation true, redaction profile | audit/trace hooks | fail-fast |
| `redline.*` | startup/static | all true;false forbidden | runtime redline guard | fail-fast |
| `fixture.*` | startup/test harness | mode enum、seed ref、profile compatibility | Clock/Id/fake runtime | test fail-fast |
| activation controls | startup validation | reload/hot/config center/admin override unsupported | no P0 activation | validation reject |

Key cross-field rules:

- `profile.allow_test_override=true` only in `local-dev` / `ci-test`.
- durable `store.mode` requires `store.dsn_ref`; raw store material is rejected.
- `store.transaction_mode` must be `single-uow`; idempotency must stay enabled.
- role `fake` requires fixture and test/local profile; controlled/endpoint requires protected source ref.
- publisher enabled requires `bus.topic_map_ref` covering all enabled identity outbound event kinds.
- `outbox.publish.failure_mode` must be `mark-failed-no-rollback`.
- query not-ready strategy must be `return-not-ready`; query cannot rebuild or write repair.
- operations-replay requires run id plus report/input root refs.
- endpoint mode requires endpoint ref; explicit disabled is allowed only where profile and flow permit.
- all redline guards must remain true.
- static invariant override keys are validation errors.

## 10. 配置变更、审计与回滚

> 校准来源:
> - `design-calibration/04_config_step_10_change_audit_rollback.md`

P0 不支持 config center、admin override、runtime reload 或 hot update。startup 配置通过重新 validate 后 restart 生效;job-run-start 只影响 new job run;entry-local 只影响 current entry;test fixture 只影响 current test harness / fake runtime run。

| 变更类型 | 发起方 | 评审要求 | 生效方式 | 审计记录 | 回滚方式 |
|---|---|---|---|---|---|
| profile / adapter policy | operator / release automation | medium;future production high | startup + restart;entry local only | old/new digest、profile、validation result | previous validated config + restart |
| store mode / store ref | operator / release automation | high | startup + restart | store slot、old/new ref digest、migration result | previous approved store ref + restart |
| transaction / idempotency guard | any source | critical if relaxing | invalid never activates | rejected issue ref | no runtime rollback |
| actor context requirements | operator / release automation | high if relaxing | startup + restart | rule digest、trace/idempotency requirement | restore previous guard |
| role source mode / snapshot ref | operator / release automation | high | startup + restart | source mode、ref digest、fingerprint result | restore source ref;accepted truth unchanged |
| role fixture ref | test harness | medium;non-test critical reject | test harness / local startup | fixture digest、profile、test run | restore fixture and rerun |
| bus publisher / endpoint / topic map | operator / release automation | high | startup + restart | mode、route map digest、coverage result | restore config;pending outbox unchanged |
| outbox batch / attempts / backoff | operator / job runner | low to medium | startup or job-run-start | job kind、run id、numeric class | rerun with previous input |
| outbox failure mode | any source | critical if changed | invalid never activates | rejected issue ref | no runtime rollback |
| projection checkpoint / rebuild batch | operator / job runner | medium | startup or job-run-start | checkpoint digest、job run id | new job run with previous input |
| operations replay roots | job runner / release automation | high | job-run-start | report/input root digest、run id | new run;stored reports immutable |
| external resolver mode / endpoint refs | operator / release automation | high when enabled | startup + restart | family、mode、old/new digest | restore resolver ref;no fake fallback |
| trace handoff target | operator / job runner | high | startup or job-run-start | target digest、job run id | new run with previous target |
| audit sink / redaction profile | operator / release automation | high;unsafe relax critical | startup + restart | sink/profile digest、compensation status | restore previous sink/profile |
| redline guards | any source | critical if false | invalid never activates | rejected issue ref | no runtime rollback |
| fixture clock/id/seed | test harness | medium;non-test critical reject | test harness | fixture digest、clock/id mode | restore and rerun |
| raw secret/body, reload/hot, static override | any source | critical reject | invalid never activates | forbidden class、issue ref | formal design change if needed |

Audit records may include change ref、actor ref、reason ref、config section、profile、activation kind、redacted digest、validation result、issue ref、rollback ref and run/release ref. They must not include full config body、full sensitive ref、credential material、external body or adapter response body.

Rollback can only restore a previous validated config/input/fixture and restart or rerun. It must not rewrite accepted truth、stored job report、outbox material、projection truth or duplicate replay surface.

| idempotency disabled | duplicate replay 不可靠 | fail-fast | 是 | idempotency false rejected |
| write entry lacks trace/idempotency | accepted flow 不可审计/重放 | reject before mutation | 可选 | metadata negative |
| role source unavailable during command | role/capability 不可信 | command rejected or dependency unavailable;no accepted side effects | 是 | resolver unavailable no mutation |
| publisher enabled but topic missing | outbound route 不闭合 | fail-fast | 是 | topic completeness |

| projection query not ready | read summary unavailable | return not-ready/degraded;no write/rebuild | 可聚合 | query no-write |
| operations replay refs missing | replay cannot be audited | reject current run | 是 | replay roots required |
| external resolver explicit disabled | optional capability unavailable | formal disabled/unavailable surface;no fake success | 否/信息 | disabled no fake success |
| resolver unavailable during query | read incomplete | query degraded/unavailable;no write | 可聚合 | degraded no repository write |
| resolver unavailable during consumer/callback | event cannot resolve | delayed/quarantined/failed by formal flow | 是 | no accepted marker |
| governance basis unavailable for high-risk action | action basis 不可信 | fail-closed | 是 | basis unavailable |
| audit sink runtime unavailable | external audit cannot write | formal compensation/local marker;core audit not disabled | 是 | compensation test |
| config center/admin override/hot reload present | P0 unsupported | validation reject | 是 | unsupported source rejected |
| runtime builder partial assembly | facade half-available risk | builder failed;no facade | 是 | partial builder no facade |

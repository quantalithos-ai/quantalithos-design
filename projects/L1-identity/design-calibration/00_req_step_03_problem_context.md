## 3. SOP 问题回答

| 问题 | 回答 |
|---|---|
| 当前业务背景是什么 | Quantalithos 把 AI 员工建模为长期存在、有职业、有能力、有记忆、有生涯的产品一等公民,因此平台必须能稳定回答“员工是谁”。 |
| 当前主要痛点是什么 | 如果没有独立身份真相源,同一个 AI 员工会被项目成员、运行实例、对话显示、认证主体、memory 引用和外部记录分散定义。 |
| 问题能否量化 | 当前不以运行量化指标定义问题;可以明确影响范围覆盖 work、conversation、process、governance、runtime、workspace、archive、observability 和 SDK。 |
| 哪些是业务问题 | 管理者、项目负责人、审计者和相邻系统无法统一判断一个 AI 员工是谁、是否可用、具备什么身份侧能力、有哪些生涯与记忆引用。 |
| 哪些是技术问题 | 需求层若不先区分 truth、snapshot、ref 和 forbidden body,后续对象契约、接口、事件和测试都会把相邻仓事实写入 identity。 |
| 哪些不是本步问题 | P95、容量、数据库、event schema、RPC 名称、状态机实现和代码目录不是 Step 3 的问题定义。 |

## 5. 改动前后对比

| 项 | 改动前 | 改动后 | 原因 |
|---|---|---|---|
| 问题主线 | 成员、角色、能力、事件和存储都需要管理 | 平台级 AI 员工身份缺少统一真相源 | 聚焦需求成立理由 |
| 痛点表达 | 功能缺失和实现缺口混写 | 主语断裂、边界断裂、消费断裂 | 便于后续能力闭环推导 |
| 影响范围 | 以旧接口和对象为中心 | 以相邻仓消费身份锚点为中心 | 与多仓协作事实一致 |
| 量化指标 | 倾向继承旧 P95 / 容量 | 当前不量化,后移非功能与验收 | 避免伪基线 |
| 技术问题 | 直接落到 DB / event / API | 落到 truth / snapshot / ref / forbidden body 边界 | 为后续可落码性铺垫 |

## 7. 结构化中间产物

### 7.1 业务背景

Quantalithos 的产品叙事要求 AI 员工像真实员工一样跨项目长期存在,并拥有身份、职业、能力、记忆和生涯轨迹。随着平台进入多项目、多成员、多仓协作,成员身份必须能被稳定引用和审计,因此需要把身份主题独立收束为 `L1-identity` 的仓级需求。

### 7.2 需求断裂

| 断裂点 | 具体表现 | 需求层必须给出的答案 |
|---|---|---|
| 主语断裂 | 同一个 AI 员工可能被项目、对话、runtime 或外部记录以不同方式引用 | 谁拥有稳定、不可复用的成员身份锚点 |
| 边界断裂 | 角色、项目成员、记忆、审计和运行信息都可能被误写进 identity | 哪些数据是 identity truth,哪些只是引用,哪些禁止保存正文 |
| 生命周期断裂 | 暂停、退役、墓碑化可能散落在项目、runtime 或 UI | 谁拥有全局成员可用性和高风险处置边界 |
| 角色能力断裂 | 方法定义、能力摘要、证据和绩效可能混在一起 | identity 只应保存哪些身份侧摘要和来源 |
| 消费断裂 | 下游仓需要成员状态和摘要,但不应绕过身份真相边界 | identity 对外提供哪些能力级消费面和追溯面 |

### 7.3 业务问题 vs 技术问题

| 类型 | 内容 |
|---|---|
| 业务问题 | 平台需要统一回答“这个 AI 员工是谁、是否可用、是什么职业和能力、有哪些生涯和记忆引用”,否则管理者无法稳定管理 AI 员工队伍。 |
| 技术问题 | 若需求层不先区分 GlobalMember / ProjectMember、RoleDefinition / identity role summary、memory body / memory ref、runtime instance / member identity,后续对象契约、接口、事件和测试都会无法 1:1 落码。 |

### 7.4 影响范围

| 受影响对象 | 问题未闭口时的后果 |
|---|---|
| `L1-work` | ProjectMember 可能替代 GlobalMember,导致跨项目身份断裂 |
| `L1-process` | activity / actor 只能使用 opaque ref,追溯能力下降 |
| `L1-conversation` | 成员显示和参与者上下文可能各自维护副本 |
| `L1-governance` | 高风险处置和责任链缺少稳定成员引用 |
| `L2-runtime` / `L2-member-service` | 运行状态可能反向定义身份状态 |
| `L4-archive` / memory | 正文、向量和归档 package 可能泄漏入 identity |
| `L1-workspace` / L5 | 聚合视图可能把自身展示状态误当身份 truth |

### 读前说明 · 测试方案标准生产流程

`05-测试方案` 不是从“想到哪些 case 就列哪些 case”开始写,而是从 `02/03` 已冻结的结构、状态机、交互边界和高风险接缝反推测试方案。

建议按以下流程产出:
1. **先收输入**
   - 读取 `00-需求文档.md`、`01-架构设计.md`、`02-概要设计.md`、`03-详细设计.md`
   - 抽取:主要部分、主流程、状态机、非法转换、协议、异常流、最小可运行闭环
2. **再识别测试对象**
   - 分清对象级、函数级、流程级、边界级、协议级测试对象
3. **按主要部分分组**
   - 每个主要部分先列: 必测对象 / 必测函数 / 必测状态流 / 必测异常流
4. **再按测试层级细化**
   - 单元测试 / 集成测试 / 事件链测试 / 恢复测试 / 投影一致性测试 / 端到端主线测试
5. **最后补执行方案**
   - 测试数据、环境依赖、串行执行顺序、CI 门禁、证据归档路径

> 先按“主要部分 + 风险边界”组织,再按测试层级展开,不要反过来只按技术类型罗列测试。

## 1. 测试目标与范围

### 1.1 测试目标

本轮测试的目标不是单纯证明 member-images“能存模板”,而是系统验证 `L2-member-images` 是否真正满足“成员镜像资产层 / persona-image 供给层”的设计要求,尤其要证明以下几点成立:
- MemberImage / ImageRoleBinding / ImageVersion 构成正式镜像模板真相层
- `MemberImage ≠ Member`、`ImageRoleBinding ≠ identity role truth` 两条核心边界成立
- persona / prompt / style 种子装配只表达默认交互起点,且 `ImagePersona ≠ live runtime persona state`、`default prompt/style ≠ conversation history`
- toolset / capability refs / policy overlay 只做装配,且 `ImageToolset ≠ capability contract truth`
- memory/workspace seeds 只表达初始化材料,且 `MemorySeed ≠ live memory store`、`WorkspaceSeed ≠ active workspace truth`
- version / derivation / publish / retire / instantiate 构成正式镜像演进与交付主线,且 `ImageVersion / Derivation ≠ member lifecycle`
- instantiate bundle 必须可被 member/runtime 稳定消费,同时不反向改写镜像真相

### 1.2 测试范围 / 非范围

| 范围项 | 类型 | 优先级 | 说明 |
|---|---|---|---|
| 镜像定义与身份适配部分 | image definition 对象 | P0 | MemberImage、ImageMetadata、ImageRoleBinding、ImageUsageScope、ImageStatus |
| Persona 与交互种子装配部分 | persona seed 对象 | P0 | ImagePersona、PromptSeed、InteractionStyle、StarterBehaviorBundle |
| 工具、能力与策略覆盖装配部分 | capability / overlay 对象 | P0 | ImageToolset、CapabilityRef、PolicyOverlay、ProviderPreference、RestrictionEntry |
| 记忆与工作区初始化材料部分 | seed bundle 对象 | P0 | MemorySeed、WorkspaceSeed、StarterFileRef、StarterMaterialBundle、SeedIntegrityDigest |
| 版本、派生与实例化出口部分 | rollout / instantiate 对象 | P0 | ImageVersion、ImageDerivation、ImagePublishRecord、InstantiateBundle、InstantiateTicket |
| member 正式实例真相、runtime live state、conversation history、本地 memory store | 非范围 | P2 | 只验镜像如何提供模板和 seed bundle,不验下游运行态全部实现 |
| identity role truth / capability contract / governance policy source truth | 非范围 | P2 | 只验 image 如何消费这些来源,不验上游仓全部实现 |
| UI catalog 视觉展示细节 | 非范围 | P2 | 只验只读 catalog/summary 结果,不验具体界面表现 |

## 2. 测试策略与分层

| 层级 | 目标 | 责任 | 典型内容 | 通过标准 |
|---|---|---|---|---|
| 单元测试 | 验证对象成员函数与局部不变量 | domain / policy owner | `role_binding.validate_role_binding_boundary`、`seed.validate_persona_seed_boundary`、`CapabilityRef::validate_refs`、`memory_seed.validate_seed_boundary`、`image.validate_instantiable_state` | 边界与不变量符合设计 |
| 集成测试 | 验证 service + repo + storage + projection + publisher 联动 | backend / domain owner | `CreateImage`、`BuildPersonaBundle`、`ResolveImageToolset`、`BuildWorkspaceSeed`、`PublishImage`、`DeriveImage`、`BuildInstantiateBundle`、`CreateInstantiateTicket` | definition、persona、capability、seed、instantiate 五条主线同时成立 |
| 事件链测试 | 验证上下游接缝链 | integration / platform owner | identity role → image binding、method/hub/gov → toolset/overlay、image bundle → member/runtime、catalog/summary → UI/console | 输入输出语义一致 |
| 恢复专项测试 | 验证 role drift、capability 越权、starter refs 缺失、retired image 实例化、lineage 断裂等异常链 | architecture / QA | role invalid、capability denied、digest mismatch、retired instantiate、derive gap | 真相不丢失、错误被正确阻断或留证 |
| 投影一致性测试 | 验证 catalog / summary / lineage / instantiate result 与主记录一致 | backend / QA | catalog rebuild、summary rebuild、lineage rebuild、instantiate result rebuild | 投影只读且与主线一致 |
| 端到端主线测试 | 验证最小镜像资产闭环 | QA / owner | define → assemble → publish → derive → instantiate | 镜像闭环跑通 |

## 3. 需求追溯与覆盖矩阵

| 需求/规则 | 测试场景 | 测试层级 | 自动化 | 证据 |
|---|---|---|---|---|
| `MemberImage ≠ Member` | 镜像模板不得混入 member 实例状态 | 单元 + 集成测试 | 是 | model review / payload compare |
| `ImageRoleBinding ≠ identity role truth` | role binding 只引用 role truth,不复制不改写 | 单元 + 事件链测试 | 是 | role binding trace |
| `ImagePersona ≠ live runtime persona state` | persona seed 只作为默认起点,不回收运行时人格状态 | 单元 + 集成测试 | 是 | seed/state compare |
| `default prompt/style ≠ conversation history` | prompt/style 不能从对话历史反向生成 | 单元 + 事件链测试 | 是 | prompt/history separation |
| `ImageToolset ≠ capability contract truth` | toolset 只装配 capability refs,不能自造 contract | 单元 + 集成测试 | 是 | capability refs / negative flow |
| `MemorySeed ≠ live memory store` | memory seed 只提供初始化材料 | 单元 + 集成测试 | 是 | memory seed / live state compare |
| `WorkspaceSeed ≠ active workspace truth` | workspace seed 只表达 starter bundle | 单元 + 集成测试 | 是 | workspace seed / runtime compare |
| `ImageVersion / Derivation ≠ member lifecycle` | 派生和版本链不等于成员实例生命周期 | 单元 + 集成测试 | 是 | lineage / ticket compare |
| instantiate 只消费 image truth | BuildInstantiateBundle 不反写镜像主记录 | 集成 + 端到端测试 | 是 | instantiate trace / bundle compare |

## 6. 核心测试场景

| 场景 ID | 场景 | 前置条件 | 步骤摘要 | 预期结果 |
|---|---|---|---|---|
| TC-001 | CreateImage 成功创建镜像草稿 | role_ref 合法 + metadata 完整 | CreateImage | MemberImage 创建成功 |
| TC-002 | role binding 非法时阻断镜像草稿 | role_ref 缺失或非法 | CreateImage | 返回 `ROLE_BINDING_INVALID` |
| TC-003 | BuildPersonaBundle 成功装配 persona/prompt/style | image 存在 + prompt/style 合法 | BuildPersonaBundle | persona bundle 创建成功 |
| TC-004 | conversation history 不得反向污染 persona seed | history 材料存在 | negative flow | seed/state 分离成立 |
| TC-005 | ResolveImageToolset 成功装配 capability refs | capability refs 合法 + overlay 合法 | ResolveImageToolset | ImageToolset 创建成功 |
| TC-006 | capability 越权时阻断装配 | ref 指向未授权 capability | ResolveImageToolset | 返回 `CAPABILITY_REF_NOT_ALLOWED` |
| TC-007 | BuildWorkspaceSeed 成功创建 starter bundle 与 digest | starter refs 完整 | BuildWorkspaceSeed | StarterMaterialBundle / SeedIntegrityDigest 创建成功 |
| TC-008 | starter refs 缺失或 digest 失配时阻断 seed bundle | refs 缺失或完整性失败 | BuildWorkspaceSeed | 返回 `SEED_INTEGRITY_MISMATCH` |
| TC-009 | PublishImage 仅在 persona/toolset/seed bundle 齐备时成功 | image draft 完整 | PublishImage | state=published + publish record 创建成功 |
| TC-010 | DeriveImage 成功建立父子镜像 lineage | parent image published | DeriveImage | ImageDerivation 创建成功 |
| TC-011 | lineage 断裂时阻断派生或发布 | parent refs 不完整 | DeriveImage / PublishImage | 返回 lineage 错误 |
| TC-012 | BuildInstantiateBundle 成功生成实例化输出材料包 | image published + 未 retired | BuildInstantiateBundle | InstantiateBundle 创建成功 |
| TC-013 | retired image 不得继续实例化 | image status=retired | CreateInstantiateTicket | 返回 `IMAGE_RETIRED` |
| TC-014 | instantiate 只消费 image truth,不反写镜像主记录 | instantiate request 合法 | BuildInstantiateBundle | bundle 成功且 image truth 不变 |

## 10. 缺陷管理与异常升级

| 严重级别 | 定义 | 处理要求 |
|---|---|---|
| S | image 替代 member 真相 / capability 越权装配成功 / live state 回写 seed truth / retired image 继续实例化 |
| A | 主线可跑但 lineage、bundle 完整性、catalog summary 或 instantiate 稳定性不稳 |
| B | 非关键视图、低优先级 style / summary 展示异常 |

## 11. 回归策略与残余风险

### 11.1 回归策略
- 每次改动 image / role binding,都必须回归模板真相与 role 适配主线
- 每次改动 persona/prompt/style,都必须回归 persona seed 与 conversation history 边界主线
- 每次改动 toolset / overlay,都必须回归 capability refs 与越权阻断主线
- 每次改动 memory/workspace seed,都必须回归 seed/live state 边界与 digest 主线
- 每次改动 version / derivation / instantiate,都必须回归 lineage、retire、ticket 与 bundle 输出主线

### 11.2 残余风险
| 风险 | 影响 | 接受人 |
|---|---|---|
| 多组织 / 多场景镜像树继续膨胀 | 测试矩阵需扩充 | TL / 架构 |
| policy overlay 与 capability strategy 后续细化 | capability/policy 验收需增加更多样本 | member-images / governance / hub |
| workspace seed 与 starter refs 后续复杂化 | digest / seed bundle 验收需扩充 | runtime / artifact |

## 4. 禁止依赖表

| 禁止依赖 | 禁止原因 | 正确协作方式 |
|---|---|---|
| `L2-member-images -> L3-method-library` 源码级 | 方法库 00 §6.5 明文禁止;消费关系≠编译依赖 | 运行期能力边界 / 构建输入快照(pinned ref) |
| `L2-member-images -> L2-runtime / L2-tools / L2-member` 源码级 | 装配的是**发布产物**,不是链接其业务实现 | component release ref + 版本 pin |
| `L2-member-images -> L2-member-service` 任意方向源码级 | 供给关系走 manifest / ref;编排真相不进本仓 | manifest / variant / ref 查询边界(pending) |
| `L2-member-service -> L2-member-images` 源码级 | 同上,消费方向也只走 ref | 同上 |
| 本仓 -> registry / CI / evidence tool 产品绑定进领域层 | 后端产品真相不归本仓;违反配置绑定边界 | adapter + 配置设计(04)绑定 |
| 本仓 -> governance / identity / sandbox truth 写入 | 越权;本仓是静态资产仓 | ref / event / 交接语义 |
| 镜像内置 secret / credential | 供应链安全红线(旧 MI5 方向保留待确权) | 运行期由 member-service / secret owner 注入 |

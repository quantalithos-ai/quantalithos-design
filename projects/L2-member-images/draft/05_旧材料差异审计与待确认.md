## 4. 污染回流防线

- 旧 README / 旧 00~06 中的固定 Role 数量、100%、99.9%、90 天、1 年、20 分钟等数字一律不得未经 authority 进入新正式文档;发现回流即重开受影响 Step。nightly 不是污染数字,它由 Accepted ADR-0005 明确锁定,必须在 00 正确承接。
- 旧文档的"角色权限矩阵、SLA 表、supervisord、GitHub Actions"等实现 / 授权口径不得作为需求层结论回流。
- 兄弟仓(member / member-service)旧文档中的对本仓期望(如 StartMember P95)只能作为 pending 输入线索,不得写成本仓已承诺指标。

普通来源形成唯一全局覆盖链；entry-local、job-run-start 和 `deterministic_fixture.*` 不属于全局覆盖链。普通 fake / placeholder 与 `integration-like` 的 controlled seam 场景选择也不是全局覆盖层。

```text

                                      |

                                      v

                                      |
```

关键说明：

- builder 暴露 facade 前必须完成本地配置校验；外部 availability 仍是 seam marker。

|---|---|---|---|
| runtime / profile assembly | 选择 profile、配置身份与装配组合 | `profile`、`config_identity` | local / fake / blocked 组合可判定 |
| local truth / maintenance stores | 绑定 logical owner、history、outbox、projection、idempotency | `truth_store_binding`、`maintenance_store_binding`、`idempotency_result_binding` | in-memory / fake，不锁产品 |
| qualification / host seam | 绑定 resolver、Member / Images / Runtime / Sandbox，以及 carrier availability marker | `qualification_resolvers`、各 `*_binding` | Member / Images / Runtime / Sandbox 使用 opaque ref；carrier 仅 disabled / blocked / availability marker，不能装配 carrier adapter |
| lifecycle / session / health | 装配注册、信号、session 与健康入口 | `registration_session`、`health_assessment` | 不把进程存活或心跳当 Host Health truth |
| publication / handoff | 装配外围发布与反馈接缝 | `publication`、`handoff_feedback` | disabled / unknown，不推导 delivered / accepted |
| operation jobs | 冻结已提交工作的批次、并行、重试和未知项处理 | `operation_jobs` | 不创建授权、decision、generation 或新 effect key |
| safe boundary / diagnostics | 约束 safe view、redaction 和诊断输出 | `safe_read_boundary`、`security_redaction` | body-free、deny-by-default、低基数 |

依赖分类保持不变：`L0-sdk` 仅是待精确收口的 compile seam；store、container、RPC、Member、Images、Runtime、Sandbox 和 provider 是 runtime / ref / adapter / fake seam；Core / Bus 是 event / ref seam。运行期协作不转换为源码依赖。

## 4. 配置分类与边界

> 校准来源：
> - `design-calibration/04_config_step_04_categories_boundaries.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置分类表”“更新时机边界表”“禁止配置化项表”“按配置域组织的分类边界表”和“跨分类 / 禁止项审计表”小节，了解冻结边界与拒绝规则。

| 配置类别 | 含义 | 典型内容 | P0 生效边界 |
|---|---|---|---|
| `static-design-boundary` | 设计不变量，非普通配置 | 主语、owner、state、UoW、Query no-write、Job no-authorization | 只经正式设计与版本变更 |
| `startup-runtime` | builder 前解析并冻结 | profile、stores、resolvers、bindings、targets、redaction、clock / ID | cold restart |
| `job-run-start` | 每个 job run 开始时冻结 | batch、parallelism、timeout、retry、health threshold、target snapshot | new job run |
| `entry-local` | 只影响当前入口 | source / profile selector、request source、dry-run、受限诊断 | current entry |
| `policy-like-technical` | 技术旋钮，不是治理策略 | retry、timeout、batch、retention、page limit | startup 或 new run |
| `sensitive-ref` | 普通配置中的 opaque 引用 | credential、endpoint、destination、`deterministic_fixture` / replay ref | startup 冻结；不含 body |
| `diagnostic-redaction` | 限制安全输出 | forbidden classes、label allowlist、safe diagnostic mode | startup 冻结，只可收紧 |
| `test-fixture-deterministic` | 仅支持 `ci-test` / `operations-replay` 的可复现测试 / replay | fake、in-memory、fixed clock / ID、seed | `ci-test` test entry / `operations-replay` replay run |
| `feature-peripheral` | 控制外围能力装配 | publisher、handoff、derived projection、可选诊断 | startup 冻结，不得关闭核心 accepted path |

P0 不支持 `reload`、`hot`、config center、admin override、online last-known-good 或动态 adapter replacement。startup 配置变更必须 cold restart；job 参数只在新 run 冻结；entry-local 只作用于当前调用。

| 禁止配置化项 | 禁止原因 | 如需改变 |
|---|---|---|
| `ProjectMemberRef` 执行主语、`GlobalMemberRef` 身份锚 | 不得以 endpoint、backend ID 或配置值替代正式范围 | 回写 `00/01/02/03` 与 ADR |
| Host Truth owner、第二写源、state matrix、generation fence | 不得重新定义宿主事实或合法迁移 | 回写 owner / state 设计 |
| expected revision、UoW ordering、rollback、command metadata、幂等与 stored replay | 不得关闭并发、提交和重放保护 | 回写详细设计 |
| Query no-write、Job no-authorization、history / material / outbox / audit | 查询和维护不能成为隐式 command 或删除已提交事实 | 回写协议 / flow |
| outbox snapshot 来源与四层 handoff 语义 | 不得现查现造 payload 或把 submitted 升格为 accepted | 回写 object / handoff contract |
| forbidden body、raw secret、manifest、endpoint secret、redaction 下限 | 安全和正文排除不可放宽 | 安全设计变更 |
| Identity、Work、Member、Images、Runtime、Sandbox、Governance 等外部 truth | 本仓只能消费 ref / safe summary / marker | 由对应 owner 变更 |
| event kind、schema、topic-neutral key 与依赖分类 | transport 不得改写公共语义或依赖方向 | 回写 contracts / ADR |

未闭合 seam 只允许 `placeholder`、`disabled`、`blocked`、`unknown`、`degraded` 或 `fail-closed`。fake、availability、timeout、receipt 和局部 assembly 都不是 ready / healthy / delivered / observed / accepted 的证据。

## 5. 配置来源、优先级与冲突处理

> 校准来源：
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“来源优先级表”“配置域来源覆盖表”“冲突处理表”“来源解析图”和“跨来源冲突审计表”小节，了解普通来源、局部来源和敏感引用如何隔离。

普通配置的全局优先级唯一固定为：

```text
code defaults < strict JSON file < environment variables
```

该顺序只用于同一 key 的普通来源覆盖。`entry-local`、`job-run-start` 和 `deterministic_fixture.*` 是作用域受限的输入，不参与全局覆盖，也不能重写已装配的 store、adapter、安全边界、actor、scope、metadata、state 或 handoff 层级。`deterministic_fixture.*` 仅可由 `ci-test` / `operations-replay` 入口使用；`local-dev` 只使用普通 fake / placeholder，`integration-like` 只使用 controlled adapter seam。P0 不读取 config center，也不接受 admin override。

| 来源 | 优先级 / 作用域 | 允许内容 | 冲突处理 | 不可用时策略 |
|---|---|---|---|---|
| code defaults | 普通来源最低 | P0 profile、in-memory / fake、safe redaction、外围 disabled、确定性默认 | 可被 file / env 覆盖；默认仍须校验 | 关键项无安全默认时 fail-fast |
| strict JSON file | 普通来源中间 | startup binding、logical store、adapter ref、feature、job 默认 | 覆盖 defaults；重复 key / alias fail-fast | 文件不可读或解析失败 fail-fast |
| environment variables | 普通来源最高 | profile selector、config path、有限 ref、CI selector | 覆盖 file / defaults；最终值非法不得回退 | 缺失使用较低来源；存在但非法 fail-fast |
| opaque secret / credential reference | 引用遵循普通来源；材料不在链中 | credential、endpoint、destination、DSN、`deterministic_fixture` / replay ref | ref 按普通优先级；raw body 一律拒绝 | ref 形态非法或 provider 不可用时 blocked / fail-closed |
| entry-local parameters | 当前入口局部 | config / profile selector、request source、dry-run、受限输出选择 | 不覆盖全局配置；冲突只拒绝当前 entry | 必填参数缺失拒绝当前入口 |
| job-run-start parameters | 当前 job run 局部 | batch、parallelism、timeout、retry、health threshold、target snapshot | 与 job request 不一致时拒绝当前 run | 当前 job rejected，不污染全局配置 |
| deterministic fixture / replay input | 仅 `ci-test`、`operations-replay` 的 test/replay 入口 | fixed clock / ID、脱敏 replay ref、deterministic seed | 只作用于 test harness / replay run；`local-dev` 不启用该配置域，`integration-like` 只走 controlled adapter seam | fixture 缺失或越界 fail-fast |
| config center | P1/P2 方向；P0 unsupported | 未来 remote source | P0 视为 unsupported source | fail-fast，不隐式读取 |
| admin override | P1/P2 方向；P0 unsupported | 未来有审计的 operator change | P0 视为 unsupported source | fail-fast，不隐式读取 |

### 5.1 局部入口参数边界

入口参数只提供当前调用所需的选择或请求来源；它们不得替代 public protocol metadata，也不得成为第二套配置 schema。job request 的 actor、scope、run、idempotency、trace 和 target 等 metadata 仍来自正式 envelope / request contract，不由环境变量或命令行同义参数注入。

| 局部输入 | 允许作用 | 禁止作用 | 失败结果 |
|---|---|---|---|
| config source selector | 选择当前 config file / discovery source | 改变普通优先级、跳过 validator | 当前 entry rejected |
| profile selector | 选择一个已支持 profile | 改变主语、owner、state 或安全边界 | 当前 entry rejected |
| job request source | 在 file 与 stdin 中二选一读取完整 request | 通过 env 传递完整 request body | 当前 job rejected |
| job-run-start technical values | 在安全范围内收窄 batch、parallelism、timeout、retry | 覆盖 store、target owner、generation、idempotency 或 authorization | 当前 run rejected |
| dry-run / diagnostic selector | 只做 validation / safe diagnostics | 绕过安全检查或写入 mutation | 当前 entry rejected 或保持只读 |
| deterministic fixture / replay input | 仅在 `ci-test` / `operations-replay` 注入脱敏、可复现的 fake 或历史引用 | 进入 `local-dev`、`integration-like`、future profile，或读取生产秘密 / 外部正文 | test / replay fail-fast |

### 5.2 冲突与不可用处理

| 场景 | 处理规则 | 阻断范围 |
|---|---|---|
| 同一 key 出现在 defaults、file、env | env 覆盖 file，file 覆盖 defaults；保留脱敏来源摘要 | 最终值合法时不阻断 |
| 文件内重复 key | 视为歧义，不采用“最后值” | 阻断启动 |
| alias key 与 canonical key 并存 | 视为 schema 冲突，要求迁移或删除 alias | 阻断启动 |
| 高优先级值类型、格式或范围非法 | 不回退低优先级，直接 fail-fast | 启动或当前 job / entry |
| 必填 startup 配置缺失 | 不使用旧缓存或 sibling 状态猜测 | 阻断启动 |
| 必填 job / entry 参数缺失 | 不用全局默认掩盖请求缺口 | 仅阻断当前 job / entry |
| file 与 stdin 同时提供 | 必须二选一；不一致直接拒绝 | 当前 entry |
| feature disabled 且 target 缺失 | 保持 disabled，记录安全 issue | 不阻断核心装配 |
| feature enabled 且 target / adapter 缺失 | 不自动切换为 fake positive | 启动或当前 job blocked |
| ordinary source 提供 raw secret、body 或 endpoint secret | 直接拒绝配置 | 阻断启动 / 操作 |
| env 试图关闭 metadata、redaction、幂等或 body-free | 视为禁止配置项冲突 | 阻断启动 |
| test fixture 出现在不允许 profile | 拒绝 profile | 阻断启动 |
| enabled publication 缺 event family / target | 不生成 publication ready | 启动或发布 job blocked |
| retention 小于 redelivery / retry / commit-unknown 所需窗口 | cross-field validation fail-fast | 阻断启动 |

来源解析成功只表示形成候选输入；它不表示外部 adapter、成员注册、镜像验证、Runtime session、Sandbox 隔离或 handoff 已完成。`MSVC-UP-001~008` 的 exact contract 继续以 pending / blocked / placeholder 方式承接。

### 7.6 配置项与详细设计绑定规则

配置项是 `infra/config.rs` 的输入，不成为 domain 字段。`infra/runtime_builder.rs` 必须将已校验的 logical binding、typed ref、availability 和技术参数注入既有 Port / adapter / entry seam；application、domain、contracts 不读取 raw config。

| 配置项族 | 绑定方向 | 不得发生的转换 |
|---|---|---|
| truth / maintenance / idempotency binding | logical owner → repository / UoW / result seam | 不把 maintenance store 变成 Host Truth，不合并 owner |
| ref-bearing binding refs (`member_binding.binding_ref`、`images_binding.binding_ref`、`runtime_session_binding.binding_ref`、`sandbox_binding.binding_ref`) | opaque ref → typed adapter seam | 不解析对端 endpoint、manifest、credential 或外部正文；carrier marker 不在此集合 |
| publication / handoff target | target ref → publisher / feedback seam | 不将 target ref 转为 event schema，也不由 receipt 推导 accepted |
| `operation_jobs.*` | run-local typed parameters → job runner | 不创建 authorization、decision、generation 或新 effect key |
| safe / security | validated boundary → query / logger / diagnostic hook | 不允许放宽 body-free、deny list 或 label allowlist |
| clock / ID | injected mode → `ClockPort` / `IdGeneratorPort` | handler / domain 不自行读取系统时间或拼 ID |

数字默认值只用于 P0 安全、确定性和 run-local 可复核性，不构成吞吐、延迟、SLO、容量或生产运维承诺。未闭合上游合同只通过 opaque ref、`placeholder`、`blocked`、`unknown` 或 `disabled` 表达。

## 8. 敏感配置与密钥管理

> 校准来源：
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“敏感配置总表”“Profile 敏感处理矩阵”“禁止输出与访问规则”“读取、轮换和撤销规则”“敏感配置停审记录”和“跨敏感配置泄露风险审计表”小节，了解 opaque ref 与真实 secret material 的边界。

配置敏感级别统一为 `public`、`internal`、`sensitive`、`secret`。本仓普通配置只允许保存必要的 opaque reference；真实密码、token、private key、证书私钥、DSN body、credential body、endpoint secret、manifest 和外部正文不进入普通配置或本仓业务输出面。

| 敏感级别 | 含义 | 本仓示例 | 处理要求 |
|---|---|---|---|
| `public` | 不带安全或拓扑秘密的公开标签 | profile 名、operation kind | 可进入配置和受控文档 |
| `internal` | 内部运行参数，暴露会影响运维判断 | batch、timeout、safe diagnostic label | 只进入内部配置和脱敏诊断 |
| `sensitive` | ref 本身可能暴露拓扑、运营或安全信息 | adapter ref、target ref、DSN ref、fixture / replay ref | 只保留 opaque ref；不输出 full value；变更需留痕 |
| `secret` | ref 指向的真实秘密材料 | password、raw token、private key、credential body | 不得写入普通 JSON、env、CLI、代码、日志、错误、审计、trace、report 或 artifact；仅由未来获批密钥设施在受控运行期提供 |

### 8.1 敏感配置处理表

| 配置项族 | 敏感级别 | 存储方式 | 是否可明文 | P0 轮换方式 | 审计 / 输出上限 | 未闭合 owner 处理 |
|---|---|---|---|---|---|---|
| `member_binding.binding_ref`、`images_binding.binding_ref` | sensitive | validated config 中的 opaque ref | ref 可受控保存；body 否 | ref 变更后 cold restart | 类别、availability、redacted digest | `MSVC-UP-002/003` 保持 blocked |
| `runtime_session_binding.binding_ref` | sensitive | opaque ref | endpoint / session body 否 | ref 变更后 cold restart | binding 类别、issue ref | `MSVC-UP-001` placeholder / blocked |
| `sandbox_binding.binding_ref` | sensitive | opaque ref | policy / credential body 否 | ref 变更后 cold restart | binding 类别、failure marker ref | `MSVC-UP-004/005` fail-closed；carrier 仅有 public availability marker，不进入本表 |
| `registration_session.launch_credential_ref` | sensitive | opaque credential ref | raw credential 否 | 外部 owner 更新 ref；P0 restart | category、rotation / issue ref、digest | `MSVC-UP-006` pending；高风险 fail-closed |
| `publication.target_ref`、`handoff_feedback.target_ref` | sensitive | opaque destination ref | endpoint、token、receipt body 否 | ref 变更后 restart 或 new run | target category、marker ref、digest | `MSVC-UP-007` pending |
| `deterministic_fixture.source_ref`、replay ref | sensitive | 脱敏 fixture / history ref | fixture / history body 否 | test-entry 或 replay run 更换 | profile、类别、run-scoped digest | 非 test / replay profile 拒绝 |
| future store / provider / observability refs | sensitive | approved provider ref（future） | secret material 否 | future provider-specific rotation | provider category、digest、safe issue | P1/P2；先 ADR 与 `03` 回写 |

### 8.2 Profile 敏感处理矩阵

| Profile | 允许输入 | 禁止输入 | 读取 / 轮换边界 | 不可用策略 |
|---|---|---|---|---|
| `local-dev` | fake ref、placeholder ref、in-memory ref、缺省 disabled | raw secret、真实 credential body、真实 endpoint secret | builder 只接 ref 或 marker；变更后重启 | disabled / blocked |
| `ci-test` | deterministic fixture ref、fake adapter ref、fixed clock / ID ref | CI 环境中的 raw secret、生产 target、raw fixture body | 每 run 隔离；test harness 注入 | test setup fail-fast |
| `integration-like` | controlled / real-like adapter、credential、destination opaque ref，以及 controlled seam 场景选择 / 故障注入 | 未审计 raw material、外部正文、manifest、`deterministic_fixture.*` | startup 绑定；不支持 hot rotate | enabled target fail-closed |
| `operations-replay` | 脱敏 state、outbox、report、replay ref | raw historical body、生产 credential | run-start 冻结；不得改写原始事实 | job rejected / blocked |
| `staging-like` | future approved provider ref | 普通 JSON / env / CLI 中 raw secret、fixture positive | future 运维轮换 | P1 blocked until provider contract |
| `production-like` | approved provider ref only | raw secret、full ref in output、fixture positive | future audited rotation / revoke | fail-closed |

#### 敏感配置读取图：opaque ref 到受控使用方

```text
[opaque ref from validated config]
              |
              v
[infra controlled resolver / provider seam]
              |
       +------+------+
       |             |
 [typed handle]  [unavailable]
       |             |
       v             v
 [adapter call]  [blocked / fail-closed]
       |
       v
 [redacted result or safe marker]
```

关键说明：

- `infra/config.rs` 只检查 ref 的 canonical 形态、profile 允许性和 forbidden-body；不把 provider 返回的秘密材料放入 `ValidatedMemberServiceConfig`。
- `infra/runtime_builder.rs` 只向 adapter 注入 typed handle、availability 或 placeholder；`domain`、`contracts`、application、API、worker 和 job report 不读取 secret body。
- P0 轮换路径是提交新 opaque ref、重新 parse / validate、再 cold restart；in-flight run 不被热替换。
- ref 撤销或 provider 不可用时，新的 launch、Sandbox bind、publication 或 handoff 使用 fail-closed / blocked；既有 local history、material、outbox 和 marker 不被删除或改写。

### 8.3 禁止输出与访问规则

| 表面 | 允许内容 | 禁止内容 |
|---|---|---|
| 配置文件 / env | profile、类别、经批准的 opaque ref | password、token、private key、certificate body、DSN body |
| domain / contracts | safe ref、redacted marker、availability | credential body、endpoint secret、manifest、外部正文 |
| 日志 / metric | profile、operation kind、disposition、safe issue code | ref 原文、URL query、header、body、高基数 id |
| error / API response | body-free code、safe reason、correlation ref | provider response body、secret、含 body 的 stack |
| history / audit | 类别、脱敏摘要、actor / reason ref、结果 | secret material、external body、manifest、credential body |
| trace / report / artifact | redacted config identity、字段类别、run-scoped ref | raw config snapshot、full sensitive ref、完整 endpoint 或历史 body |

访问方只能得到最小权限的 typed handle 或 safe summary。`sensitive` ref 的 full value 不得拼入 error、日志、trace、report 或 artifact；`secret` material 永远不作为本仓函数、DTO 或配置字段流转。provider exact API、权限模型和 audit sink 不由本仓定义；任何无法确认脱敏的路径都按 fail-closed 处理。

## 9. 配置加载、校验与生效机制

> 校准来源：
> - `design-calibration/04_config_step_09_loading_validation_activation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置加载流程图”“配置组加载表”“按配置域组织的加载 / 校验 / 组装表”“必须通过的 cross-field 规则”“生效方式矩阵”和“配置域停审记录”小节，了解配置如何在 builder 前闭合。

运行配置文件必须是严格 JSON。加载器先按 §5 合并普通来源，再执行 canonical key、重复 key / alias、JSON parse、类型、范围、ref-shape、交叉字段和 forbidden-body 校验。JSONC 仅是 §7.8 的文档注释示例，运行时必须拒绝注释、尾逗号和未知字段。

#### 配置加载流程图：L2-member-service 配置加载与校验

```text
[code defaults]
      |
      v
[optional strict JSON file]
      |
      v
[environment overrides]
      |
      v
[canonical / duplicate / alias check]
      |
      v
[strict JSON parse]
      |
      v
[type / enum / range / ref-shape validation]
      |
      v
[cross-field + profile + forbidden-body validation]
      |
      v
[ValidatedMemberServiceConfig]
      |
      v
[runtime_builder: stores + UoW + ports + adapters]
      |
      v
[availability: enabled / disabled / blocked / unknown]

```

关键说明：

- builder 在所有必需 local binding 通过前不得暴露 application facade、API、worker 或 jobs facade。
- `entry-local` 与 job request 只在入口参数阶段收窄，不成为全局覆盖层；`deterministic_fixture.*` 只在 `ci-test` / `operations-replay` 生效，`local-dev` 不启用该配置域，`integration-like` 只使用 controlled seam 场景选择 / 故障注入。
- adapter availability 只表示接缝状态，不是 ready、healthy、delivered、observed 或 accepted 的证明。
- P0 没有 reload / hot 路径；配置变化只能通过 cold restart、new job run、current entry 或 test rerun 生效。

| 配置组 | 加载时机 | 主要校验 | 组装目标 | 失败策略 |
|---|---|---|---|---|
| `profile`、`config_identity` | startup | object、支持的 profile / schema、canonical label | `ValidatedMemberServiceConfig.profile` | startup fail-fast |
| `truth_store_binding` | startup | 五个 logical owner 完整且不重叠 | logical repositories + UoW | 缺失或混淆 fail-fast |
| `maintenance_store_binding` | startup | history / material / outbox / projection binding | maintenance repositories | history/material/outbox 缺失 fail-fast；projection 可 degraded |
| `idempotency_result_binding` | startup | reservation 与 stored-result 完整 | idempotency / result ports | mutation entry rejected，不静默重跑 |
| `qualification_resolvers` | startup | family、mode、placeholder / fake / blocked 状态 | typed qualification ports | unresolved 保持 blocked |
| Member / Images / Runtime bindings | startup | availability 与 optional opaque ref shape | adapter registry | enabled 缺 ref 或 unavailable 时 blocked / fail-fast |
| Sandbox binding | startup | opaque ref shape、profile compatibility 与隔离安全条件 | Sandbox bind / release port seam | 高风险动作 fail-closed；不以 host fallback 替代 |
| carrier availability marker | startup | 仅校验 availability enum；不接受 carrier ref、release schema 或 contract body | handoff 的 carrier availability marker seam | unavailable => handoff blocked / gap；不装配 carrier adapter |
| registration / health | startup；threshold 可 new job run | mode、credential ref、正整数阈值 | registration / health entries | invalid reject；signal 不可用为 unknown |
| publication / handoff | startup | enabled 与 event / target ref 条件 | publisher / feedback registry | disabled 可启动；enabled 缺 ref fail-fast / blocked |
| `operation_jobs` | startup；run 参数可 new job run | 正整数、非负 retry、profile compatibility | frozen job parameters | 当前 job rejected |
| safe read / security | startup | body-free、repair=false、deny list、低基数 labels | query / logging / diagnostics | startup fail-closed |
| `clock_id` / deterministic fixture | startup；`deterministic_fixture.*` 仅为 `ci-test` test-entry 或 `operations-replay` replay job-run-start | mode、profile compatibility、脱敏 ref | Clock / ID ports / test seed | startup / test/replay fail-fast |

### 9.1 必须通过的交叉字段校验

| 校验组 | 规则 | 失败结果 |
|---|---|---|
| profile × deterministic fixture | 仅 `ci-test` / `operations-replay` 可启用 `deterministic_fixture.*`；`local-dev` 和 `integration-like` 不得启用 | startup fail-fast |
| profile × availability | fake、placeholder、blocked 不能被标成 ready | config reject |
| logical owner 完整性 | 每个 truth owner 恰有一个 logical binding；maintenance / projection 不得替代 truth | startup fail-fast |
| enabled ref-bearing binding | enabled / controlled / real-like 的 ref-bearing binding 必须有 opaque ref；null 仅可用于 disabled / blocked placeholder；carrier availability marker 单独校验且没有 ref 条件 | startup fail-fast 或 action blocked |
| publication | enabled 必须有 event-family 与 target 的待确认 ref；本仓不补 transport schema | startup fail-fast / publication blocked |
| handoff feedback | enabled 必须有 target ref；反馈未知保持 unknown | startup fail-fast / job rejected |
| retention / replay | reservation、retry、redelivery、commit-unknown 和 report 窗口相容；具体产品数值待后续确认 | startup fail-fast |
| batch × page | job batch 为正且不得超过 safe read 上限；job input 只能收窄 | startup fail-fast / job rejected |
| redaction safety | 核心 forbidden classes 不可删除；metric label 仅低基数字段 | startup fail-fast |
| safe body | `body_mode` 必须为 `body-free`，`query_write_repair` 必须为 `false` | config reject |
| raw forbidden material | 任意来源含 secret、credential body、external body、manifest 或 endpoint secret 即拒绝 | source rejected |
| invariant override | 试图改写主语、owner、state、metadata、幂等、outbox 或 handoff 层级即拒绝 | source rejected |

### 9.2 生效方式矩阵

| 生效方式 | P0 适用项 | 生效边界 | 失败处理 |
|---|---|---|---|
| `static` | 主语、owner、state、generation、UoW、Query no-write、Job no-authorization、四层 handoff | 不是可覆盖配置 | 出现 override key 直接 reject |
| `startup` | profile、stores、bindings、targets、redaction、publication、clock / ID | builder 前冻结；变更需 cold restart | 无效则不暴露 facade |
| `job-run-start` | batch、parallelism、retry、timeout、health threshold、target snapshot | 新 run 冻结；不改变 global config | 当前 job rejected |
| `entry-local` | source / profile selector、request source、dry-run、受限诊断 | 仅当前 entry | 当前 entry rejected |
| `test-entry` / replay run | `ci-test` deterministic fixture、`operations-replay` replay fixture、fixed clock / ID、failure injection | test harness / replay run；`integration-like` 场景注入必须走 controlled adapter seam，且不得启用 `deterministic_fixture.*` | test fail-fast / replay rejected |
| `reload` / `hot` | P0 无 | 不提供在线替换或 LKG | key、flag 或调用意图均 rejected；未来先回写 `03` |

`ValidatedMemberServiceConfig` 是配置与装配之间的唯一 typed 边界。它只承载已验证的配置语义、opaque ref 和安全 marker；不承载 raw secret、外部正文、manifest、policy body、Runtime outcome 或成员主体 truth。`runtime_builder` 按既有详细设计顺序注入 store、UoW、result、resolver、adapter、clock / ID、publisher、handoff 和入口参数。

## 10. 配置变更、审计与回滚

> 校准来源：
> - `design-calibration/04_config_step_10_change_audit_rollback.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“发起边界与评审分级”“配置变更控制表”“未来变更记录的安全字段规则”“回滚规则矩阵”“敏感配置变更附加规则”和“跨变更审计与回滚审计表”小节，了解变更作用域和撤回边界。

本文只规定配置变更的语义和最小安全留痕，不拥有 Governance / Identity 的审批 truth，也不指定工单、审批、配置交付、审计、secret provider 或 artifact 产品。P0 变更必须先通过外部授权边界和本节校验，再按 activation kind 生效。

| 变更输入面 | 允许作用域 | 不允许范围 | 最低安全前提 |
|---|---|---|---|
| 受控 startup 配置 | 已声明的 startup section | 直接写 Host Truth、绕过 validator、注入 raw secret | 外部授权语境、strict validation、cold restart |
| job-run-start input | operation jobs、允许的 health / target snapshot、replay source | 覆盖 store、binding、redaction、主语、metadata、state | 入口授权和 metadata 已另行验证 |
| entry-local selector | 当前 profile / source / request selector、受限诊断 | 持久化全局配置、伪造 job metadata、改变 static boundary | 只影响当前 entry |
| deterministic fixture / replay input | fake seed、fixed clock / ID、脱敏 replay ref | 进入 `local-dev` / `integration-like` 或 future profile、写真实 secret / body | profile guard、fixture 校验 |
| 设计变更入口 | static boundary 或新能力 | 作为普通 P0 config 直接激活 | 先重开拥有真相源的正式设计 |

| 风险级别 | 典型范围 | 要求 |
|---|---|---|
| `low` | 安全收窄的 batch、timeout、page 上限、局部 selector | validator 通过，记录安全变更元数据，仅当前 scope 生效 |
| `medium` | P0 profile、fake / placeholder mode、健康阈值、deterministic fixture ref | 受控评审或 `ci-test` / `operations-replay` context，profile compatibility 验证 |
| `high` | logical store、resolver、Member / Images / Runtime / Sandbox ref-bearing binding、credential ref、publication / handoff target、retention、redaction | change / reason / rollback reference、完整 validation、cold restart 或 new run |
| `forbidden` | raw secret / body、redaction 放宽、body-free 放宽、Query repair、hot/reload、remote/admin source、fake 升格 ready、truth/state/owner override | P0 validation reject；若需求成立先走设计变更 |

### 10.1 变更控制与回滚矩阵

| 变更族 | 生效方式 | 安全留痕最小内容 | 回滚方式 | 明确禁止 |
|---|---|---|---|---|
| profile / identity | startup + cold restart | profile、section、old/new redacted digest、validation outcome | 恢复先前已验证 artifact 后 restart | 未验证 artifact、跳过 validator |
| truth / maintenance / idempotency binding | startup + cold restart | logical slot、old/new ref digest、change / reason ref | 恢复先前批准 binding；失败时不暴露 facade | 自动 fallback 成另一个 owner |
| resolver / ref-bearing lifecycle binding | startup + cold restart | family、availability、ref digest、issue ref | 恢复先前 binding 或保持 blocked | fake positive fallback |
| carrier availability marker | startup + cold restart | availability、section、change / reason ref | 恢复先前 marker 或保持 blocked | 不引入 carrier ref、release schema 或 adapter |
| registration / health | startup；threshold 可 new run | mode、threshold class、credential ref digest | restart 或以先前有效输入新建 job | 把 heartbeat 当 healthy |
| publication / handoff | startup 或 new run | enabled、event / target category、digest、feedback mode | 恢复先前配置；local truth 不回滚 | receipt 推导 accepted |
| operation job parameters | startup 或 new run | job kind、numeric class、run-local flag、validation | 以先前有效输入创建新 run | 改写既有 report / stored result |
| safe read / redaction | startup + cold restart | section、deny / label digest、reason / review ref | 只恢复已批准且不更宽的安全配置 | 放宽 deny list 或 Query repair |
| clock / ID / deterministic fixture | startup / test entry / replay run | profile、mode、fixture digest、test/replay marker | 恢复 ref 并 rerun | fixture 进入 `local-dev`、`integration-like` 或生产语义 |
| forbidden change | 不激活 | safe issue class、section、source category | 无运行回滚；必要时重开设计 | emergency flag、静默接受 |

### 10.2 审计输出上限

未来实现的变更记录只能包含：外部 `change_reference`、`initiator_reference`、`reason_reference`、配置 section、profile、activation kind、redacted old / new config digest、ref category / digest、validation outcome、safe issue ref 和 rollback reference。上述字段均应为 opaque 或脱敏关联；不得记录完整配置文件、full sensitive ref、endpoint、DSN、token、credential body、外部审批正文或 provider response body。

敏感 ref 只允许 ref 变更和受控 rotation；P0 通过 restart 或 new job run 生效。既有 Host Truth、history、material、outbox、handoff marker 和 stored result 不因配置回滚而被修改、删除或重放为另一语义。配置漂移、过期 artifact 或未验证 rollback target 均必须拒绝。

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源：
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“策略术语定义”“配置失效模式表”“按配置域组织的失败策略表”“生效方式到失效策略矩阵”“告警与安全记录规则”“测试切口表”和“跨失效策略审计表”小节，了解配置错误与运行期依赖失败如何分层。

本项目使用以下失效语义：

| 策略 | 含义 | 适用范围 |
|---|---|---|
| `fail-fast` | 在输入或构造阶段立即拒绝，不暴露半成品 facade | startup、job-run-start、entry-local、test-entry |
| `fail-closed` | 安全、隔离、授权或静态边界不明确时拒绝危险动作 | raw body、credential、Sandbox、主语、owner、redaction、生产 fake |
| `blocked` | 上游合同或必需接缝未闭合，保持等待 / 阻塞 marker | Member、Images、Runtime、Sandbox 的正向 seam；carrier availability 不足时的 handoff 交接 |
| `degraded` | 继续提供有限 safe surface，并显式暴露 stale / unavailable | Query projection / reference、非核心运行期 resolver |
| `delayed` | 暂时不可用，保持待处理，等待 retry / new run | consumer、outbox scan、可重试 adapter |
| `failed marker` | 已提交动作、发布、交接或 job 的失败 / 人工处理标记 | outbox、handoff、cleanup、reconciliation、export |

非法配置与运行期外部不可用不能混为“降级成功”。P0 禁止 silent fallback、低优先级 fallback、online LKG、config center、admin override 和 hot reload。

| 失效模式 | 影响 | 系统行为 | 告警 | 测试切口 |
|---|---|---|---|---|
| required startup config missing | 无法确定 store / binding / runtime | builder `Failed`，不暴露 facade | 是 | 每个 required domain 缺失 |
| strict JSON、unknown field、duplicate / alias | 配置不可信或语义歧义 | fail-fast | 是 | 注释、尾逗号、未知项、重复项 |
| invalid type / enum / range / ref shape | 无法形成 typed config | startup fail-fast，job / entry reject | 是 | 类型、范围、ref 形态 |
| 高优先级 env 非法 | 错误值可能掩盖低来源 | fail-fast，不 fallback | 是 | env vs file / default |
| raw secret / body / manifest / endpoint secret | 发生泄露或越界 | fail-closed，配置不激活 | 是 / 安全 | forbidden-body scanner |
| redaction deny list 空或不安全 | 输出边界失守 | builder `Failed` / fail-closed | 是 / 安全 | 空列表、高基数标签 |
| static boundary override | 主语、owner、state、query/no-write 被改写 | 配置拒绝 | 是 / 安全 | invariant key reject |
| `deterministic_fixture.*` 出现在 `local-dev`、`integration-like` 或 future profile | 环境隔离失效 | fail-closed | 是 / 安全 | profile guard |
| required Member / Images / Runtime / Sandbox seam unavailable | 宿主无法安全正向装配 | fail-fast 或 `Blocked`，不得 Ready | 是 | availability / blocker mapping |
| Identity / Work qualification unavailable | 执行主语或身份无法验证 | command rejected / blocked；query degraded；不写 accepted truth | 是 / 聚合 | resolver unavailable |
| runtime session contract pending | 不能形成 Runtime association | session blocked / unknown；不创建 Runtime run | 是 | `MSVC-UP-001` placeholder |
| Sandbox binding 不明或不可用 | 隔离边界不明 | 高风险动作 fail-closed；local attempt 可保留 | 是 / 安全 | no host fallback |
| carrier availability unavailable | carrier 交接未完成 | 保留 local marker，产生 blocked / gap / unknown；不装配 carrier adapter，不回滚 local truth | 是 | carrier marker / handoff mapping |
| publisher / handoff feedback unavailable | 外部发布或反馈不可用 | 保留 submitted 与 local marker，产生 delayed / failed / gap / unknown | 是 | 不回滚 local truth |
| projection / reference store unavailable | safe read 不完整 | query degraded / unavailable，严格 no-write | 可聚合 | repository write audit |
| external GRC disabled | 外围 export 不执行 | export disabled / rejected；核心 Host Truth 不受阻断 | 否 / 信息 | core vs export comparison |
| job batch / timeout / retry / replay input invalid | 当前 run 不可复核 | job rejected；既有 report 不改写 | 是 | run input validation |
| retention / replay window conflict | duplicate replay 不可靠 | startup fail-fast | 是 | cross-field retention |
| config digest drift / artifact expired | 与批准基线不一致 | release / startup fail-fast，需重新验证 | 是 | expected vs actual digest |
| rollback target unvalidated | 回滚可能引入坏配置 | rollback rejected | 是 | invalid rollback target |
| fixture / replay root 缺失或未脱敏 | 重放不可复核或可能泄露 | ci-test fail-fast / replay rejected | 是 / 安全 | replay guard |
| clock / ID port unavailable | mutation 缺少稳定时间 / ID | startup fail-fast 或 UoW 前 mutation reject | 是 | missing port |
| partial runtime builder assembly | 可能暴露半可用服务 | builder `Failed`，facade 不暴露 | 是 | partial assembly |

### 11.1 按配置阶段与运行期接缝分层

| 配置域 / 接缝 | 配置阶段失败 | 运行期失败 | 对外 / job 表面 |
|---|---|---|---|
| profile / identity | fail-fast | 不适用 | runtime failed，无 facade |
| truth stores | fail-fast | required store 不可用阻断 mutation；read 可按 safe surface degraded | command rejected；query degraded |
| maintenance / idempotency | history / outbox / reservation 缺失 fail-fast | maintenance delayed / failed marker；mutation 不静默重跑 | local truth 不回滚 |
| resolvers | family / mode / ref invalid fail-fast | command blocked；query degraded；consumer delayed | 不推导 ready |
| Member / Images | enabled 缺 ref 或 profile 不兼容 fail-fast | register / supply unavailable => launch blocked | 不声明注册或镜像验证 |
| Runtime binding | ref / availability invalid fail-closed | session unavailable => blocked / unknown | 不创建 Runtime run |
| Sandbox binding | ref / isolation safety invalid fail-closed | bind / release => blocked / gap / failed marker | 不 host fallback |
| carrier availability marker | marker invalid / unknown fail-closed | carrier unavailable => handoff blocked / gap / failed marker | 不推导 carrier ready / release success |
| registration / health | mode / credential / threshold invalid reject | stale / unavailable => health unknown / stale | 不等于 healthy |
| publication / handoff | enabled 缺 event / target fail-fast | submitted 保留，后续为 unknown / gap / failed marker | 不推导 delivered / accepted |
| jobs | kind / limit / profile invalid fail-fast | target / lease / store unavailable => delayed / partial / failed report | Job 不拥有 authorization |
| safe read / redaction | fail-closed | sink unavailable 时不输出敏感面 | body-free remains fixed |

### 11.2 告警与安全记录字段

告警、日志、指标、trace 和未来 report 只能使用安全低基数字段，例如 profile、section、binding kind、operation kind、disposition、safe issue ref、blocker ID、redacted digest、local record ref 和 failure class。禁止 raw config、full sensitive ref、secret、URL query、header、payload、manifest、provider response body 或外部正文。

配置错误不得被标记为健康；fake、placeholder、availability、receipt、timeout、adapter `Ok` 或 submitted marker 不得升级为 ready、healthy、delivered、observed 或 accepted。Query 的 degraded surface 不得触发修复写入；publication / handoff 失败只写 marker / report，不回滚 Host Truth。

| 无已发布、可迁移的历史 schema | 本文 P0 初版 schema | 当前无迁移项 | 不适用 | 旧 README / `05/06` 不导入；后续已发布 key 按本章生命周期演进 | 不适用 |

| 状态 | 含义 | loader 行为 | 审计 / 下游要求 |
|---|---|---|---|
| `active` | 当前正式配置项 | 正常 parse / type / cross-field validation | 正常测试、验收和运维承接 |
| `introduced` | 新增但未成为默认能力 | 仅显式允许 profile / feature 可用，默认不启用 | 补 schema、测试、验收、实施、运维输入 |
| `deprecated` | 有替代项且处兼容窗口 | 按明确映射处理并生成 redacted warning / issue；不覆盖更高优先级新 key | 记录窗口、使用 evidence、rollback |
| `rejected` | P0 明确不支持或不安全 | validation reject | negative test / acceptance veto |
| `removed` | 兼容窗口结束 | unknown / removed field reject | removal evidence / release note |
| `design-change-required` | 会改变 `03` 代码契约或安全边界 | 不进入当前 runtime schema | 先重开 `03/04` 设计 |

| 新配置引入步骤 | 必须完成的闭环 | 不满足时 |
|---|---|---|
| 动机 / 边界 | 回指需求、架构、详细设计或运维问题；确认不触及 static invariant | 记入风险或标记 design-change-required |
| 代码影响 | 检查 runtime field、builder binding、constructor、Port、DTO、error、flow | 有影响先回写 `03` |
| schema / source / profile | 填齐十列；明确 defaults/file/env/entry/job 和 profile | 不完整不得实施 |
| validation / activation | parse、type、range、cross-field、ref/body/static-boundary 和生效方式 | 未闭合不得启用 |
| sensitive / rollback / failure | 级别、no-output、评审、审计、previous validated rollback、failure strategy | 缺任一项不得启用 |
| downstream / evidence | 同步 `05/06/07/09` 输入和未来 evidence 语义 | 未同步不得 release |

| 阶段 | 未来 loader 行为 | 下游同步 | 退出条件 |
|---|---|---|---|
| 宣告废弃 | old key 可接受但生成 redacted warning；new key 优先且冲突可判定 | `05` 负例 / warning；`06` 门禁；`07/09` 操作输入 | 映射、窗口、rollback 已记录 |
| 兼容窗口 | 只允许明确 old→new 映射；禁止 silent fallback 和 raw value 输出 | P0 profile 迁移测试与运维提示 | evidence 表明旧 key 不再使用 |
| 强制迁移 | old key validation reject；只接受 new key | negative gate、实施 / 运维更新 | profile artifact 已迁移 |
| 移除 | old key 作为 unknown / removed reject | release note、evidence index、rollback review | rollback 不再依赖旧 key |

以下能力仅是未来演进候选：`staging-like` / `production-like` profile、durable store、真实 Bus / topic、secret provider / KMS、remote config center、admin override、runtime hot reload、online last-known-good、provider health、产品告警阈值和供应商专属重试策略。任何一项进入实现范围前，都必须补齐 owner、产品中立或产品特定 schema、`03` 回写、validation、activation、audit、rollback、failure、测试、验收、实施和运维承接。

以下行为永远不提供兼容窗口：raw secret / credential body / external body / manifest、删除核心 redaction deny class、放宽 body-free 或 Query no-write、改变主语 / owner / state / generation / UoW / 幂等、P0 remote / admin / hot / LKG、使 `deterministic_fixture.*` 进入 `local-dev`、`integration-like` 或 future profile、high-cardinality telemetry 和 outbox payload 从 current truth 重建。

当前 P0 没有 `待回写` 或 `阻塞待确认` 的配置结论。下表中的 blocker 不阻止本版配置语义定稿，但会阻止相应真实正向集成、产品化或下游证据闭环；未确认前必须保持 pending / blocked / placeholder / unknown / fail-closed。

|---|---|---|---|
| `MSVC-UP-001` Runtime session / execution handoff exact surface 未闭合 | session 关联、feedback mapper、真实集成 | `runtime_session_binding` 只用 placeholder / blocked；不定义 run / outcome | `L2-runtime` / 双侧合同 |

### 14.1 待确认前统一处理规则

| 未闭合类型 | 正式 P0 处理 |
|---|---|
| sibling exact schema / route / feedback | typed opaque ref、placeholder、blocked、unknown；不 shadow 对端 schema |
| 产品和基础设施选型 | in-memory / fake / disabled / product-neutral ref；不写产品字段、endpoint 或 DSN |
| secret provider / credential owner | opaque ref；raw material 不入配置、日志、错误、审计、trace、report 或 artifact |
| remote / admin / hot / LKG | P0 unsupported / reject；若进入范围先回写 `03` 和受影响 `04` Step |
| 下游文档和 evidence | 只写输入语义；不生成 run_id、artifact、report、verdict、signoff 或 readiness |
| 任何 static invariant 变更 | design-change-required；回到拥有 truth 的正式文档和 ADR |

### 14.2 详细设计回写判定

| 配置结论 | 是否影响 `03` | 处理状态 |
|---|---|---|
| `infra/config.rs` → `ValidatedMemberServiceConfig` → `runtime_builder`，其他层不读 raw config | 否 | 无回写；承接既有 §13 |
| strict JSON、defaults < file < env、opaque ref、restart / new run / entry 生效 | 否 | 无回写 |
| static owner / state / UoW / idempotency / Query no-write / handoff 不可覆盖 | 否 | 无回写；承接既有 redline |
| future runtime field、adapter constructor、Port、DTO、error、flow、profile enum、provider health、remote / hot / LKG | 是 | future design-change-required；先回写 `03` |

正式 `04` 的 P0 结论可以在上述 blocker 存在时保持 fail-closed 定稿，但不得把任何 blocker 的正向路径写成 ready。未来若把 blocker 解除为真实实现，必须由对应 owner 提供正式合同并重新审计 §5–§13。

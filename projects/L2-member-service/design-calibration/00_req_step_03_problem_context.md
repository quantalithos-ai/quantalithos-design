## 3. SOP 问题回答

1. 当前业务背景是什么？

   回答：Quantalithos 的产品叙事要求 AI 员工作为长期存在的个体真实运行——用户创建项目、分配成员后,成员必须以受控运行实体形态持续工作。上游已分别停审身份(identity)、分配(work)、运行循环(runtime)、隔离执行(sandbox)、工具(tools)与治理(governance)的真相边界,Layer 3 并行窗口开启;三个成员运行面项目中,本仓承接"宿主与编排控制面"一侧。当前讨论本仓,是为了补上"已成立的成员与分配事实如何变成受控宿主实例"这一层空白。

2. 当前的主要痛点或机会点是什么？

   回答：三个核心问题——(a) 宿主真相无 owner:runtime 已显式拒绝拥有 member host lifecycle,sandbox 已显式把 MemberExecutionHost / SandboxBinding 装配 truth 划给本仓,但本仓自身没有当前有效的需求基线承接;(b) 边界塌陷风险:没有统一宿主控制面,work / 产品入口会直连容器 API、runtime 会自管宿主、sandbox 会被旁路,形成多套宿主语义;(c) 旧文档失效:旧 00~03/05/06 生成于五仓并行草案期,与后停审的 runtime / sandbox 结论脱节,且携带无 authority 的性能数字与实现口径。

3. 这些问题能否量化？

   回答：结构性可量化的是"缺口计数":上游两份停审文档共 3 处显式把宿主真相指向本仓(runtime NG-L2R-008、sandbox §2 非职责表、sandbox §6 使用方表),而本仓无一份当前有效文档承接。旧文档中的性能数字(P95 < 5s 等)无 workload authority,不作为量化依据。

4. 哪些是业务问题,哪些是技术问题？

   回答：见 §7 二分表。

## 7. 结构化中间产物

### 业务背景(正式 §3.1 候选)

Quantalithos 要求 AI 员工作为有身份的个体长期真实运行。平台上游已经停审了成员身份、项目分配、受控运行循环、工具契约、治理裁决与隔离执行的真相边界,Layer 3 成员运行面并行窗口随之开启。当前讨论 `L2-member-service`,是为了在这些已成立事实之上,收束"成员如何获得并保持一个受控执行宿主"的仓级需求空白。

### 现状与问题表(正式 §3.2 候选)

| 问题 | 当前表现 | 影响范围 / 后果 |
|---|---|---|
| 宿主真相无有效 owner 基线 | `L2-runtime` 以 `NG-L2R-008` 显式排除 member host lifecycle;`L4-sandbox` 在 §2 非职责表与 §6 使用方表两处把 MemberExecutionHost / SandboxBinding 装配 truth / session / worker / health / callback material 划归本仓;但本仓没有一份承接这些指派的当前有效需求文档 | 上游合同的对端悬空;Layer 3 窗口内 member / member-images 也无法引用稳定的宿主边界 |
| 宿主编排语义存在塌陷风险 | 缺统一控制面时,分配事实到运行实体的路径会被下游各自补齐:业务域直连容器 API、runtime 自管宿主、sandbox 交接被旁路、镜像映射被 hardcode | 多套宿主语义并存,启停 / 健康 / 恢复不可归责,审计与隔离红线失效 |
| 旧文档基线失效 | 旧 README / 00~03/05/06 生成于 2026-05 五仓并行草案期,早于 runtime / sandbox 停审,携带无 authority 的性能数字、技术栈与实现组件口径 | 直接继承会把过时边界与伪量化写回正式链;必须 full-restart |

### 业务问题 vs 技术问题(正式 §3.3 候选)

| 类型 | 内容 |
|---|---|
| 业务问题 | 平台缺少"成员分配事实如何变成可用、可恢复、可审计的运行实体"的正式需求收束;AI 员工的持续在岗、故障恢复与下线交代无法被产品叙事兑现。 |
| 技术问题 | 宿主实例生命周期、装配输入组织、注册与会话、心跳健康分层、SandboxBinding 装配与隔离交接、恢复与清理、宿主侧反馈交接的唯一 owner 与失败语义未按当前上游合同闭合;host failure / session failure / runtime failure / isolation failure 若不先在需求层分层,后续设计与实现会在 runtime / sandbox / member 之间反复串线。 |

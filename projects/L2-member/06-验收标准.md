### 读前说明 · 验收标准标准生产流程

`06-验收标准` 不是从“我想验什么”开始写,而是从 `02/03/05` 已明确的目标、边界、红线、主流程结果和测试门禁反推验收门禁。

建议按以下流程产出:
1. **先收输入**
   - 读取 `02-概要设计.md`、`03-详细设计.md`、`05-测试方案.md`
   - 抽取: 目标/非目标、主要部分边界、主流程关键结果、实现红线、高风险验收点、最小可运行闭环、05 中的强测试门禁
2. **再识别验收对象**
   - 分清功能结果、边界结果、状态结果、对外交互结果、恢复结果、投影结果
3. **按主要部分分组**
   - 每个主要部分分别列: 必须满足什么 / 绝不能出现什么 / 哪些是一票否决
4. **明确通过/不通过条件**
   - 每条验收项必须写清通过条件、失败条件、失败意味着哪条边界被破坏
5. **最后形成门禁清单**
   - 单列一票否决项、可延期优化项、风险接受项与接受人

> 先按“主要部分 + 不可破坏边界”组织,再落成功能门禁和非功能门禁,不要只写口号式验收条目。

## 1. 验收背景与范围

### 1.1 验收背景

本次验收针对 `L2-member` 的第一批核心设计主线展开。当前 `02-概要设计.md`、`03-详细设计.md` 与 `05-测试方案.md` 已经明确:
- `L2-member` 是 AI 成员运行态主体、对外交互接口与能力出口的真相层,不是 identity、runtime、member-service 或 conversation 的附属层
- MemberRuntimePersona / ExposedCapability / ExecutionActorBinding 是正式真相或正式接缝对象
- `persona ≠ static identity`、`visible summary ≠ persona truth`、`execution actor binding ≠ ExecutionInstance truth` 三条核心边界必须成立
- exposed capability 必须经过 member 裁剪,不能等于 capability catalog 全量
- visible summary / profile / conversation material 都是只读外显层
- member-service 只能消费 execution-facing member context,不能反向覆盖成员主体真相

因此,本次验收的目的不是笼统判断“能不能展示一个成员”,而是判断 member 的主体真相、能力出口、执行接缝与可见外显层是否真的成立,是否可作为后续运行链和入口层的稳定基线。

### 1.2 验收范围 / 非范围

| 项 | 是否纳入 | 说明 |
|---|---|---|
| 成员主体与运行态画像部分 | 是 | persona / mode / availability / behavior profile |
| 成员对外交互接口部分 | 是 | endpoint / inbound interaction / reply/action contract |
| 成员能力暴露与行为出口部分 | 是 | exposed capability / outlet / visible capability |
| 成员与执行主线接缝部分 | 是 | execution actor binding / execution-facing member context |
| 成员可见摘要与下游消费接缝部分 | 是 | visible summary / profile / conversation material / UI material |
| runtime / member-service / tools / capability-hub 内部实现细节 | 否 | 只验 member 与它们的接缝,不验下游内部实现 |
| conversation / UI 前端组件表现 | 否 | 只验 visible material,不验 UI 像素级行为 |
| identity 静态身份正文逻辑 | 否 | 只验其作为输入真相被消费的边界 |

## 8. 缺陷分级与放行规则

| 缺陷级别 | 是否允许放行 | 说明 |
|---|---|---|
| S | 否 | persona 退化成 static identity / execution actor binding 替代 execution truth / visible summary 反写真相 / capability 越权暴露 |
| A | 视情况 | 主线可跑但 outlet / summary / binding / downstream consume 语义不稳 |
| B | 可带着走 | 非关键 profile 材料或低优先级外显查询异常 |

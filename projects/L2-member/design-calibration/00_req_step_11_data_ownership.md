### 5.6 Snapshot / ref 约束(候选正文)

所有快照必须带来源、freshness 与 scope;所有引用由对应 owner 解析,解析失败、stale、conflict 或 owner unknown 必须显式呈现,不得由 member 生成第二真相。派生视图可延迟、可重建,不得成为写源。

### 5.7 禁止保存正文汇总

member 不得把以下内容持久化为本仓 truth或作为 raw body 透明转发:入站事件正文、运行结果正文、隐藏推理 / private reasoning、secret / token / credential / raw headers、工具与方法定义正文、对话正文、Artifact / Evidence 正文、完整交互日志与高基数原始内容。入站正文只可在正式授权范围内瞬时受控检查;跨边界正确形态是 typed ref、safe snapshot、受控安全语境、结论分类、redacted marker 或 body-free 材料。

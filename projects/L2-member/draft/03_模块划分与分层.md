## 1. 业务主要组成部分(候选,8 个)

对照 L1-governance 的组成部分粒度(每个组成部分 = 一类内聚职责 + 明确"不承担什么"):

| # | 组成部分 | 核心职责 | 不承担什么 | 承接功能 |
|---|---|---|---|---|
| 1 | `Member truth core` | 保护 member 域 truth(presence、筛选结论、投递 / 出站决定、attempt / gap)、不变量、trace / audit / outbox 成立边界 | 不定义相邻仓 truth,不保存 forbidden body | 横切;FR-001/002 落点 |
| 2 | `Presence and host collaboration` | 启动语境受理、运行态主体建立、presence 状态机、对 member-service 的注册 / 存活面 | 不拥有身份生命周期、编排裁决、凭据签发 | FR-L2M-001~003 |
| 3 | `Inbound subscription and screening` | 订阅范围决定、入站事件筛选(含注入类预筛)、筛选结论与处置记录 | 不拥有 bus delivery、policy truth;不做语义理解(那是推理) | FR-L2M-004/005/007 |
| 4 | `Runtime delivery and IPC mediation` | 向 Runtime entry 的受控投递;member 侧 IPC 受理 / 关联 / 背压;容器内安全边界 | 不拥有 run / decision truth;不锁 IPC 载体 | FR-L2M-006/008/009 |
| 5 | `Outbound interaction and publication` | 出站交互决定、body-free 材料准备、bus 发布尝试与 attempt / gap、出站审计 | 不拥有 outcome / delivery / conversation / artifact truth | FR-L2M-010~012 |
| 6 | `Member summary and capability outlet` | 成员可见摘要投影、能力出口安全视图(派生、可重建) | 不成为写源;不复制 tools / method 正文 | FR-L2M-013/014 |
| 7 | `External context mirror support` | 承载外部引用与 safe snapshot(identity 锚点、policy 结果、tools / method ref、Runtime safe view)及 stale / unresolved marker | 不保存外部正文,不替代来源仓生命周期 | 支撑 2/3/5/6 |
| 8 | `Safe material and maintenance` | member 域 body-free 观测 / 审计材料输出、投影重建、对账 | 不生成新业务事实,不修复 truth,不拥有 observed truth | FR-L2M-015、E01~E03 |

与旧 B1-B6 的对照(仅审计用):B1 Identity ≈ 2 的一部分(但身份 truth 外置);B2 Subscriber ≈ 3;B3 Publisher ≈ 5;B4 External RPC ≈ 2 的宿主协作面;B5 Attention ≈ 3 的筛选(规则 truth 外置);B6 IPC Bridge ≈ 4。旧划分缺失的:truth core(1)、mirror support(7)、summary / capability outlet(6)、safe material(8)——这正是旧文档"只有管道、没有 truth 归属"的结构性缺陷。

### 1.1 组成部分交互方向(候选)

```text
+====================================================================+
|                      L2-member component flow                      |
+====================================================================+
| Presence and host collaboration                                     |
|       | establishes member runtime presence                         |
|       v                                                             |
| Inbound subscription and screening                                  |
|       | screened, source-anchored inbound context                   |
|       v                                                             |
| Runtime delivery and IPC mediation  <---> (L2-runtime entry seam)   |
|       | committed runtime safe material                             |
|       v                                                             |
| Outbound interaction and publication                                |
|                                                                     |
| Member truth core  <---- 上述四者的 truth / trace / outbox 收口     |
|       ^                                                             |
| Member summary and capability outlet <---- 派生,只读               |
| External context mirror support ------> 支撑 2/3/4/6 的外部输入    |
| Safe material and maintenance --------> 只消费已提交事实           |
+====================================================================+
```

图示说明:
- 纵向主线是"在场 → 入站 → 投递 → 出站"的语义依附关系,不是运行时固定时序(入站与出站在运行中并发存在)。
- 6/7/8 是支撑 / 派生组成部分,失效只导致 degraded,不使 1~5 整体失效。

## 2. 实现分层(候选,对照 L1-governance §4 六层)

| 分层 | member 内职责 | 边界 |
|---|---|---|
| Inbound / Operations | bus 事件到达、宿主请求、Runtime IPC 请求、维护 job trigger 进入系统 | 不做业务判定,不直接写 truth |
| Application Services | 编排筛选 / 投递 / 出站 / presence 用例,事务、幂等、domain 调用、outbox | 不替代 domain invariant |
| Domain Model and Policies | presence 状态机、筛选结论对象、投递 / 出站决定对象、correlation 不变量、screening guard | 不直接读配置或外部正文;guard 只消费 mirror 层的 safe snapshot |
| Ports and External Seams | bus subscribe/publish port、member-service host port、runtime entry / IPC port、identity / policy / tools / method resolver port | 不让外部 truth 进入本仓;seam 未闭口时 blocked / degraded |
| Persistence / Projection | 保存 member truth、trace、audit、snapshot、摘要 / 能力出口投影 | projection 不反写真相 |
| Outbox and Handoff | 出站发布、safe material 交接、attempt / gap 记录 | 发布失败不回滚 truth |

组成部分 → 代码主体映射草图(对照 governance 的 code subject map 写法):

```text
| Runtime delivery and IPC mediation-> delivery service / ipc port  |

| Member summary and capability outlet -> projection / outlet view  |

+==================================================================+
```

## 4. 状态组方向(候选,正式化归 02 Step 9)

| 状态组 | 承载对象 | 主线状态候选 |
|---|---|---|
| Presence | `MemberPresence` | starting / ready / degraded / draining / terminated / unknown |
| Screening | `ScreeningConclusion` | passed / downgraded / blocked / pending |
| Delivery | `DeliveryDecision` | submitted / accepted-by-runtime / rejected / waiting / unknown |
| Outbound | `OutboundDecision` + `PublicationAttempt` | decided / prepared / attempted / gap / feedback-linked |
| Derived | Summary / Outlet / Snapshot | fresh / stale / rebuilding / unresolved |

禁止迁移红线(候选):screening passed ≠ runtime accepted;delivery submitted ≠ outcome 成立;publication attempted ≠ delivered / observed;host 不可达 ≠ terminated;任何 unknown 不得自动升级为成功态;派生视图不得写核心 truth。

## 5. 裁剪与推进顺序建议(供正式 07 参考,不构成计划承诺)

- 最小闭环 = 组成部分 1~5(truth core + presence + inbound + delivery + outbound):这是"成员在场并能安全听说"的存在性下限。
- 6(summary / outlet)与 8(safe material)可裁剪后置;7(mirror support)随 2/3/4 按需最小化引入。
- 所有 seam(host、runtime entry、policy、bus route)在对应 blocker(`L2M-UP-001~007`,见 01 §7)闭口前只实现 blocked-aware / fake 语义,不声明 integration readiness。

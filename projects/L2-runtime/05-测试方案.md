| 类型 | 测试表达 | Package rule | Truth boundary |

### 1.4 Truth 与 phase 约束

- Choice/Guarded/Candidate/AttemptRecorded/Submitted 都不等于 executed。
- Governance/Capability safe view 不等于 Runtime 创建 approval、Policy 或 exposure truth。
- `Prepared`、`CommitPending`、`CommitUnknown` 不等于 physically `Committed` 或 resumable。
- local outcome、handoff attempt、ACK、publish receipt、projection、report 彼此分层；任何后项都不逆写前项。
- planned/fake/blocked/not-run/static mapping 不得升级为 pass、positive qualified、evidence、accepted 或 ready。

5. 验证 strict configuration 的 12/153/39、13x5、7x6、V0~V12、snapshot capture、cold replacement 与 failure posture。

### 4.1 测试分层图：风险前移与独立 qualification

```text
            [G3 per-slot positive qualification]
                    currently 13/13 blocked
                              |
             [G2 integration candidate]
                    independent manifest/run
                              |
        [local_e2e: 5 same-run aggregates only]
                              |
 [entry_worker_job] [fault_replay_consistency] [config/security]
                              |
       [contract_protocol] [service_semantics]
                              |
                  [unit_state]
```

关键说明：

- 风险在拥有 oracle 的最早层被发现；E2E 不补偿 unit/service/contract 缺口。
- raw case 只归一个 owning suite；companion 可以交叉断言，但不能复制 TC/EV ownership。
- G2/G3 不合并进 G1 的 177 分母，也不能借用 TestFake 形成 positive evidence。

### 4.2 分层职责

| Layer / suite direction | 主要 oracle | Substitute | 阻断语义 |
|---|---|---|---|
| pure/unit/state | construction、invariant、legal/illegal edge、deterministic selector | fixed clock/ID/digest | P0 mismatch blocks |
| contract/protocol | schema、visibility/no-write、snapshot、Port finite mapping | finite fake/spy/logical Port | protocol/owner/phase mismatch blocks |
| service semantics | result/state/write set/call order/UoW/fence | fault-capable repositories + finite external fakes | orchestration/atomicity mismatch blocks |
| entry/worker/job | authority-before-existence、receipt-before-ACK、lease/page/cursor | facade/consumer/runner harness | entry/ACK/lease violations block |
| fault/replay | pre/post-commit window、same/different digest、CAS、unknown reconcile | ordered failpoint and two-actor harness | flake/unknown mishandling blocks |
| config/security/static | strict parse/build/profile、dependency/source/redaction/status truth | raw duplicate-aware parser input and canaries | any VF/boundary gap blocks |
| local E2E aggregate | same-run child reference completeness | no new execution | child missing/non-pass blocks aggregate |
| G2/G3 | real subject, owner contract, non-TestFake profile, independent oracle | fake prohibited as subject | missing prerequisite stays blocked |

### 4.3 Common oracle and status rules

Every applicable raw case asserts typed result/state, local write journal, Port call journal, history/outbox, replay/collision and phase-specific failure. A process exit code alone is never the oracle. `passed` is allowed only when all declared variants and assertions pass, redaction/cleanup are clean, and exact denominator/source checks hold.

`blocked_dependency` is valid for an external positive lane, not for a required G1 local case. Empty selector、skip、ignore、missing case、flake、timeout、infra failure、cleanup residue、invalid artifact and cancelled run cannot become pass. Retry always creates a new fixed run and preserves the first result.

### 6.1 Common execution model

```text
[current design source + deterministic fixture manifest]
                         |
                         v
              [one owning raw TC]
        valid / negative / boundary / replay / fault
                         |
          +--------------+--------------+
          v                             v
 [typed result + state]       [write/call/phase journals]
          +--------------+--------------+
                         v
              [raw case artifact slot]
                         |
              same fixed run refs only
                         v
              [optional local aggregate]
```

Every raw case follows this implementation template:

1. Build exact typed fixture、fixed clock、typed ID queues、config snapshot ref/digest and finite Port/fault scripts from §7.
2. Invoke only the row's owning domain/service/entry surface; all companion surfaces are journaled, not allowed to steal ownership.
3. Execute every declared `valid / negative / boundary / replay / collision / fault / unknown` variant. A case ID contains variant results; variants do not inflate TC/EV identity.
4. Assert typed result/state, allowed write set, no forbidden write, Port call order/count/digest, history/outbox, idempotency and phase posture.
5. Same identity + same digest must replay exact stored result; same identity + different digest must conflict/quarantine. `Unknown` retains fence/reconcile and prohibits ordinary new submission.
6. Emit failed/blocked/infra/invalid truth without omission. A controlled negative `Blocked/Unknown` may pass only when that exact fail-closed oracle and zero bypass hold.

### 11.3 Lifecycle and transition rules

```text
[Observed]
    |
    +--> [ClassifiedIncident] --> [ResolvedIncident]
    |             |
    |             +-- product impact found --> [Triaged]
    v
[TriagePending] --> [Triaged] --> [FixPlanned] --> [FixCandidate]
                                                        |
                                                        v
                                                [RetestPending]
                                                   /        \
                                                  v          v
                                          [RetestFailed] [RetestPassed]
                                                  |          |
                                                  v          v
                                             [Reopened] [ClosureReview] --> [Closed]

[DependencyBlocked] -- authority-bearing owner fact --> [TriagePending]
```

1. `Observed` 不是 severity 或 product verdict。
2. `infra_error` 进入 `ClassifiedIncident`，没有新 valid run 不得转为 `RetestPassed`。
3. `DependencyBlocked` 只能由正式 owner fact 变更重开；时间、retry、fake 或 ping 不构成 edge。

5. 关闭后复现进入 `Reopened` 并链接旧 closure，不删除历史。
6. Chat approval、commit existence 或没有分母证明的 green exit code 都不是 closure evidence。

### 13.3 Shared scalar, enum and digest rules

All evidence DTOs belong to test tooling. They do not enter Runtime public/domain contracts and cannot become business truth.

| Name | Exact type/value rule |
|---|---|
| `schema_version` | exact `l2-runtime.test-artifact.v1` |
| `run_id` | 1~160 ASCII `[A-Za-z0-9._-]`; not `latest` |
| identity fields | exact canonical `case_id/evidence_id/suite_id/check_id`; unknown invalid |
| `SafeToken` | 1~256 ASCII `[A-Za-z0-9._:/@+-]`; no whitespace/newline/NUL |
| `SafeRef` | 1~512 UTF-8; no newline/NUL/control; reject rather than truncate |
| `RelativeArtifactPath` | 1~1024 normalized UTF-8 path under same run root; no escape |
| `ArtifactDigest` | `sha256:<64 lowercase hex>` |
| `SemanticDigestRef` | 1~256 ASCII `[A-Za-z0-9:._-]`; opaque domain/config digest |
| `ArtifactStatus` | `passed/failed/blocked_dependency/not_evaluated/infra_error/invalid_execution/invalid_artifact/cancelled` |
| `AssertionStatus` | `passed/failed/not_evaluated` |
| `RedactionStatus` | `clean/failed/not_evaluated` |
| `DerivationStatus` | `derived/ineligible_failed/ineligible_blocked/ineligible_infra_error/ineligible_invalid` |
| `ReviewStatus` | `not_started/pending/reviewed/disputed` |
| `WorkspaceStatus` | `clean/dirty/unknown`; never proves immutable revision |
| timestamps/counters | RFC3339 UTC metadata; nonnegative finite integers with named unit |

Unknown enum values, duplicate JSON object keys, overflow and invalid characters cause `invalid_artifact`; writers never truncate. Digest algorithm:

1. Encode JSON as UTF-8 and canonicalize using RFC 8785 JCS.
2. Reject non-finite numbers, duplicate keys and unpaired Unicode surrogates before hashing.
3. Remove only root `artifact_digest`, canonicalize the remainder, SHA-256 hash, encode lowercase `sha256:*`.
4. Preserve semantic array order; explicitly set-like arrays are lexicographically sorted by writer.
5. Hash exact stored redacted log bytes; store digest + byte length in suite report.
6. Digest proves byte integrity only, never semantic pass/delivery/Observed/approval/readiness.

```text
                     v

```

1. Selection input is an authority-bearing source ref, owner fact or defect impact, not a filename alone.
2. The 177-row registry determines TC/EV/owning suite; EV prefix never determines ownership.
3. Minimum selector is the union of changed/original cases, all directly relevant semantic variants, adjacent phase cases and required checks.
4. Multiple changes use set union. Any unresolved impact escalates to full 177; uncertainty never justifies shrinking.
5. Aggregate cases derive only after all child raw results exist in the same new run.
6. G2/G3 use separate manifest/run and cannot enter G1 177 or reuse fake evidence.

Every regression includes `SRC=check_source_manifest.sh` and `DEN=check_test_denominators.sh`. Additional short names are `DEP`, `MAT`, `FAKE`, `TRUTH`, `REDACT`, `PAIR`, `NOSTATIC`, each resolving to the exact §9 check script; a future selector must store full IDs, not abbreviations.

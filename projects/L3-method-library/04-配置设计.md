#### 配置来源链图: L3-method-library 配置覆盖链

```text
[code defaults]
  -> [config file]
  -> [environment variables]
  -> [secret refs]
  -> [test fixture / controlled override]
  -> [config center / admin override watch]
```

该图只表达配置来源类型和覆盖候选,最终优先级、冲突处理和不可用策略由 §5 收口。`config center / admin override` 当前仅为 P1/P2 watch,不得进入 P0 来源链,不得承诺动态生效、热更新或管理端覆盖能力。

#### 配置进入系统的装配入口

```text
load raw config
  -> validate family
  -> resolve slots
  -> assemble ports
  -> entry precheck
```

配置进入系统时必须先完成 raw config 读取、类型 / 族级校验、slot 解析、port bundle 装配和 entry readiness 检查。配置不得绕过 application port、entry facade、domain invariant 或 public schema。

| infra | 可读取 raw config、secret ref、adapter binding 和 product-neutral handle。 | 不得把 raw value 泄露给 contract/domain,不得从 raw adapter error 合成 formal marker。 |
| application | 只接收 typed setting、runtime summary、availability marker 和 safe config issue。 | 不得直接读取 raw secret、raw endpoint、raw body 或部署命令。 |
| entry | 只做 readiness、facade dispatch 和启动前阻断。 | 不得直接访问 repository、domain 或 raw adapter。 |
| contracts / domain | 不读取 config。 | 不得让配置改变 DTO schema、domain invariant、state transition 或 marker source。 |

| 控制面 | 覆盖内容 | 边界 |

## 4. 配置分类与边界

> 校准来源：
> - `design-calibration/04_config_step_04_categories_boundaries.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“结构化中间产物”“回填草稿”“待确认事项”“03 影响判定”和“stop-review”小节。

本章定义配置类别、更新时机和禁止配置化边界。配置类别用于组织后续来源、profile、配置项、敏感配置、加载校验和失效策略;禁止配置化边界用于防止配置开关改变 `03-详细设计.md` 已固定的对象、状态、事务、marker、body-free 和 public schema 语义。

| 配置类别 | 说明 | 示例 | 是否允许热更新 | 主要风险 |
|---|---|---|---|---|
| static design boundary | 设计期不变量,不是运行配置项。 | truth owner、state transition、public DTO schema、transaction boundary。 | 否 | 被误降级成开关会破坏 `03` 契约。 |
| startup runtime config | 启动时读取并验证的运行配置。 | runtime profile、adapter slot、target binding。 | 否 | 缺失或错误应 fail-fast / unavailable。 |
| job-run-start config | job / runner 每轮开始前读取的执行策略。 | lease、batch、retry、retention handle。 | 否,仅下一轮生效 | 错误配置可能导致延迟、重复调度或不可用。 |
| entry-local parameters | entry 层 readiness / dispatch 相关本地参数。 | entry exposure、readiness precheck。 | 否 | 不得绕过 facade 或直接触达 domain / adapter。 |
| sensitive ref config | 只承载 secret 引用,不承载 raw secret。 | DSN ref、token ref、cert ref、endpoint ref。 | 否 | 明文泄露、日志泄露、错误输出泄露。 |
| policy-like technical knobs | 技术策略值,不改变业务语义。 | page/body limit、freshness threshold、retry interval。 | 否,或按 job-run-start | 被误用为业务规则或状态迁移开关。 |
| diagnostic / redaction config | safe diagnostic 和 redaction 输出边界。 | redaction rule、safe issue category。 | 否 | 放宽后可能泄露 raw value 或 body。 |
| test fixture / deterministic config | 测试或本地 deterministic 控制。 | fake adapter、in-memory store、controlled override。 | 仅测试 / 本地 | 旧测试材料污染正式配置。 |
| feature / peripheral enablement watch | P1/P2 外围能力候选。 | config center、admin override、vendor-specific adapter。 | watch_only | 误写成 P0 会引入动态契约缺口。 |

| 更新时机 | 允许范围 | 禁止越界 |
|---|---|---|
| design-time | static design boundary。 | 不得作为 runtime config 修改。 |
| startup / cold update | runtime assembly、adapter binding、secret ref、diagnostics baseline。 | 不得承诺核心 hot runtime update。 |
| job-run-start | job runner / retry / lease / retention / batch 策略。 | 不得改变 mutation、truth repair 或 replay 语义。 |
| entry-local | readiness、entry exposure、facade dispatch 前检查。 | 不得直接访问 repository、domain 或 raw adapter。 |
| watch | pass_with_watch / watch_only 项。 | 不得写成已闭口能力或 P0 正式配置。 |

| 禁止配置化项 | 原因 | 如需改变应走什么流程 |
|---|---|---|
| truth owner | truth 所有权由需求、架构和详细设计决定。 | 回 `00/01/03` owning source。 |
| state transition | 状态迁移属于 domain / application contract。 | 回 `03-详细设计.md` owning Step。 |
| query no-write | query 不能 repair、backfill 或 hidden write。 | 回 `03` 并重新设计 query flow。 |
| stored replay / no-rerun | duplicate replay 和 no-rerun 是一致性契约。 | 回 `03` concurrency / idempotency owning Step。 |
| transaction boundary | UoW、expected version、commit ordering 不得被配置修改。 | 回 `03` persistence / transaction owning Step。 |
| marker source | marker 必须来自 formal mapper / resolver / summary。 | 回 `03` marker / mapper owning Step。 |
| body-free rule | external body、payload body、raw endpoint、raw error 不得落入配置或持久化。 | 回 `03` body-free / redaction owning Step。 |
| public DTO schema | public surface 不能由配置改变。 | 回 `03` protocol contract owning Step。 |

| watch 项 | 当前处理 | 后续触发 |
|---|---|---|
| inbound source binding | pass_with_watch。§3 / §4 只承认配置影响,不新增 formal binding。 | 若后续配置项需要 inbound carrier、constructor、port、DTO、marker 或 flow,回 `03`。 |
| config center / admin override | watch_only。不得进入 P0 来源链,不得承诺动态生效或热更新。 | 若后续要求产品、动态 override、admin 权限或 runtime 契约,回架构 / `03`。 |

## 5. 配置来源、优先级与冲突处理

> 校准来源：
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“结构化中间产物”“回填草稿”“待确认事项”“03 影响判定”和“stop-review”小节。

本章定义配置来源链、逐配置域来源覆盖、冲突处理和不可用策略。来源优先级只处理配置材料如何进入 runtime assembly,不得用于覆盖 §4 的禁止配置化边界,也不得把旧 `05/06/07` 的测试、验收或实施材料反向写成当前配置真相源。

| 来源层 | 适用范围 | 优先级关系 | 关键限制 |
|---|---|---|---|
| code defaults | profile、adapter、policy、diagnostic 的安全默认方向。 | 普通来源最低。 | 默认值不能掩盖显式非法配置。 |
| config file | startup runtime config、job defaults、adapter binding refs、safe diagnostics selector。 | 高于 code defaults。 | 重复 key 必须 fail-fast,不得依赖 parser 隐式覆盖。 |
| environment variables | 环境级覆盖、profile 选择、safe ref 选择。 | 高于 config file。 | 高优先级非法值必须 fail-fast / reject,不得 silent fallback 到低优先级。 |
| secret / credential refs | credential ref、endpoint ref、destination ref、target ref。 | 不参与普通 raw value 覆盖链。 | 只承载 safe ref;raw secret、token、private key、cert body、external body 禁入。 |
| entry-local / job-run input | 当前 entry、query、job、target、scope、selector 的局部选择。 | 只在当前 entry / job / selector 内生效。 | 不覆盖全局配置、不改变 forbidden boundary。 |
| test fixture / deterministic override | local / CI / controlled harness 的 fake seed、fixed clock/id、fake adapter output。 | 只限测试 / 本地 profile。 | 不得进入 staging-like / production-like。 |
| config center / admin override | P1/P2 watch-only 方向。 | 不进入 P0 来源链。 | 不承诺 remote config、hot reload、live override、operator 权限或 rollback contract。 |

| 配置域 | 允许来源 | 禁止来源 / 冲突 | 不可用策略 |
|---|---|---|---|
| runtime profile and entry readiness | entry-local selector、env、config file、defaults、test fixture in test profile。 | raw secret、P0 config center/admin override、hot runtime override、static boundary override。 | 未指定可走 default;显式非法 profile 或 readiness 不满足时 startup fail-fast / entry precheck fail-fast。 |
| repository and material store binding | env、config file、defaults、durable credential / endpoint ref、test fixture in test profile。 | query-time override、transaction boundary override、stored replay disable、production fixture。 | required selected store missing 时 startup fail-fast;adapter unavailable 映射为 startup fail-fast 或 unavailable runtime surface。 |
| external source and resolver binding | entry-local source selector where allowed、env、config file、defaults、secret / endpoint ref、test fake source。 | raw external body、raw adapter response、marker synthesis config、P0 admin override。 | required source / ref missing 时 startup fail-fast 或 current operation rejected;resolver unavailable 依 `03` flow。 |
| inbound source binding | env、config file、defaults、secret ref、test event source。 | command emulation source、raw payload allowlist、inbound truth repair、unclosed formal carrier。 | required transport / idempotency channel missing 倾向 startup fail-fast;unsupported / unavailable source -> rejected intake 或 safe unavailable。 |
| publisher and handoff target binding | job target selector where allowed、env、config file、defaults、secret / destination ref、test fake publisher。 | delivery-proves-truth config、event schema config、raw bus credential。 | enabled target missing 时 startup fail-fast 或 job rejected;unavailable target -> handoff failed / pending / report issue,不回滚 truth。 |

## 8. 敏感配置与密钥管理

> 校准来源：
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“结构化中间产物”“回填草稿”“待确认事项”“03 影响判定”和“stop-review”小节。

本章只处理 sensitive ref、credential ref、target ref、route ref、replay artifact root ref、redaction safety 等配置侧敏感边界。普通配置、环境变量和 entry-local 参数只能承载 opaque ref 或 safe selector,不得承载 password、private key、token、cert body、raw DSN、raw credential、endpoint body、route secret、external payload body 或 provider response body。

| 敏感级别 | 含义 | 可出现位置 | 禁止输出 |
|---|---|---|---|
| `public` | 可公开的非敏感枚举或布尔配置。 | 文档、配置文件、validation issue。 | 不适用。 |
| `internal` | 安全关键但非 secret 的内部配置。 | 配置文件、审计摘要、redacted issue。 | raw matched value、高基数字段、unsafe diagnostic。 |
| `sensitive` | credential、target、route、store、artifact 等 opaque ref。 | 普通配置可保存 ref;日志 / 审计只保存 redacted digest。 | full ref、endpoint、route、credential body、external body。 |
| `secret` | 真实秘密材料。 | 普通配置、本文示例、日志、错误、审计、trace、report 均不得出现。 | 全部禁止;只能由 future approved provider 在边界内处理。 |

#### 敏感配置读取图

```text
config file / env / entry-local / job input
  -> opaque ref / safe selector
  -> strict validation and redaction
  -> adapter-local resolution where formally supported
  -> safe digest / issue / marker only
```

`infra::config` 只能输出 validated refs、redacted digests 和 safe config issues。application、domain、contracts 不读取 secret provider,也不持有 raw secret。future secret provider 若进入 P1/P2,也只能在正式 adapter 边界内解析,解析结果不得写入 truth、outbox、trace、audit、report 或 evidence。

| 配置项 / 配置族 | 敏感级别 | 存储方式 | 是否可明文 | 轮换方式 | 审计要求 |
|---|---|---|---|---|---|
| durable store / material store refs | `sensitive` | 普通配置保存 store ref / pool ref。 | 不可保存 DSN、credential、cert body。 | 新 ref + restart。 | 记录 slot、profile、old/new redacted digest、validation result。 |
| external resolver adapter / target refs | `sensitive` | 普通配置保存 adapter ref、target ref、credential ref。 | 不可保存 endpoint credential、raw response body。 | 新 ref + restart 或 new job run。 | 记录 family、mode、redacted ref digest、availability result。 |
| outbox publisher and route refs | `sensitive` | 普通配置保存 publisher ref 和 topic-neutral route ref。 | 不可保存 bus credential、raw topic secret、payload body。 | 新 route / publisher ref + restart。 | 记录 changed route class、enabled topic coverage、validation issue ref。 |
| handoff / report target refs | `sensitive` | 普通配置保存 target ref、archive/report root ref。 | 不可保存 package body、credential、external response body。 | 新 target ref + restart or new job run。 | 记录 target class、redacted digest、handoff / report issue ref。 |
| replay artifact root refs | `sensitive` | replay config / job input 保存 de-identified artifact root ref。 | 不可保存 raw historical body、raw external payload。 | per-run replay ref。 | 记录 run ref、artifact root digest、de-identification marker。 |
| redaction deny field refs | `internal` | 普通配置保存 forbidden field refs。 | 可保存 field refs,不可保存 matched raw values。 | 新 deny list + restart。 | 记录 added/removed field refs、actor、reason、validation result。 |
| safe diagnostic prefix / sink refs | `internal` / `sensitive` | 普通配置保存 prefix 或 sink ref。 | prefix 可明文;external sink ref 不可展开。 | 新 prefix / sink ref + restart。 | 记录 collision validation、sink availability、redacted digest。 |
| future raw secret material | `secret` | 不得存储于普通配置。 | 不可明文。 | provider-side rotation only。 | 只记录 provider ref digest,不得记录 material。 |

| Profile | 允许的敏感表示 | 禁止项 | 不可用策略 |
|---|---|---|---|
| `local-dev` | fake refs、in-memory refs、local target refs。 | raw secret、real credential、external body。 | invalid ref fail-fast;optional fake target 可在 feature disabled 时 absent。 |
| `ci-test` | deterministic fixture refs、fake store / adapter refs、fixed clock / id refs。 | production secret、real target credential、raw fixture body in config。 | fixture missing test fail-fast。 |
| `integration-like` | controlled adapter refs、credential refs、target refs。 | raw credential material、sibling body、fake fallback after controlled adapter selected。 | unavailable -> degraded / delayed / failed marker by adapter role。 |
| `operations-replay` | replay artifact root refs、de-identified historical refs、controlled target refs。 | raw historical body、raw secret、raw external payload。 | missing replay ref rejected;failed target enters job report。 |
| `staging-like` / `production-like` | future approved provider refs only。 | ordinary raw secret、fake override、test fixture、raw endpoint/body。 | provider unavailable fail-fast or job rejected;no fake fallback。 |

| 输出面 | 允许输出 | 禁止输出 |
|---|---|---|
| structured log / trace | operation name、adapter slot、profile、safe code、safe diagnostic ref。 | secret、credential、endpoint、route、payload body、full sensitive ref。 |
| error response | public/internal error code、validation issue ref、safe message。 | secret、full target ref、adapter error body、external body。 |
| audit record | actor ref、reason ref、section、old/new redacted digest、validation result。 | raw config、raw secret、full sensitive ref、provider response。 |
| job report / generated artifact | marker refs、safe issue refs、counts、redacted report refs。 | raw config files with secrets、package body、external GRC response body、evidence body。 |

| 敏感配置风险 | 系统行为 | 禁止替代 |
|---|---|---|
| ordinary config includes raw secret material | validation reject / fail-fast。 | parse as string and continue。 |
| env or entry-local carries raw credential | entry/job rejected。 | store full credential in audit or report。 |
| replay artifact root points to raw body bundle | job rejected / validation issue。 | replay raw historical body。 |
| adapter returns raw external error body | map to redacted failure ref。 | persist adapter error body。 |
| future secret provider unavailable | fail-fast / rejected / failed marker by profile and role。 | fallback to fixture in production-like。 |

当前 §8 不要求回写 `03-详细设计.md`。若后续要求 adapter 在 runtime builder 中解析真实 secret provider、支持 hot reload、admin override、产品级 credential schema、credential ref carrier、secret loading port 或 mapper,必须暂停并回 `03` / 架构 owning source。

## 9. 配置加载、校验与生效机制

> 校准来源：
> - `design-calibration/04_config_step_09_loading_validation_activation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“结构化中间产物”“回填草稿”“待确认事项”“03 影响判定”和“stop-review”小节。

配置加载必须先完成来源合并、严格解析、类型 / 范围 / 交叉字段校验和敏感 / forbidden body 校验,再装配 validated runtime config。runtime builder Ready 前不得暴露 API、worker、job facade 或 adapter registry。

```text
code defaults
  -> strict JSON config file
  -> environment variable overrides
  -> allowed entry-local selector / job-run-start input
  -> source merge with conflict detection
  -> strict parse
  -> type / enum / range / ref-shape validation
  -> cross-field validation
  -> sensitive / forbidden body validation
  -> assemble validated config refs
  -> runtime config / registry / frozen params
  -> builder Ready
  -> facade exposure
```

| 配置组 | 加载时机 | 校验方式 | 生效方式 | 失败策略 |
|---|---|---|---|---|
| `runtime.*` | startup;profile selector 可 entry-local。 | known profile、strict validation、no reload/hot flag。 | startup freeze;selector only current entry。 | invalid fail-fast / entry rejected。 |
| `stores.*` | startup。 | required group、known kind、ref shape、logical store completeness。 | store registry and repository adapters。 | required missing fail-fast。 |
| `externalResolvers.*` | startup;test fixture before fake runtime。 | unique family、known mode、profile compatibility、ref shape。 | resolver adapter registry。 | missing required family fail-fast。 |
| `inboundConsumers.*` | startup。 | enabled bool、namespace list、supported version、dedup retention。 | worker consumer registry。 | invalid fail-fast;unsupported runtime event rejected。 |
| `outbox.*` | startup;batch may be job-run-start。 | publisher ref、mode/profile compatibility、topic map coverage。 | publisher adapter and route map。 | missing enabled topic fail-fast;job batch rejected。 |
| `jobs.*` | startup;batch/timeout may be job-run-start。 | job kind enum、positive integer、retention / parallelism cross-field。 | job runner registry and frozen params。 | startup fail-fast or job rejected。 |
| `handoff.*` / `externalGrc.*` | startup;target may be job-run-start。 | target ref、retry ref、enabled conditional required。 | handoff/export target set and adapter registry。 | enabled missing target fail-fast / job rejected。 |
| `redaction.*` / `boundary.*` | startup。 | deny list non-empty、safe labels、positive page/body/time limits。 | redaction checker and guard params。 | unsafe config fail-fast。 |
| `idempotency.*` / `projection.*` / `reference.*` | startup;batch may be job-run-start。 | positive duration / batch / stale threshold、retention cross-field。 | cleanup params、query defaults、maintenance job params。 | invalid fail-fast / job rejected。 |
| `clockId.*` / `testFixtures.*` | startup or test harness / operations replay start。 | ref shape、timestamp parse、profile compatibility、de-identified replay root。 | ClockPort / IdGeneratorPort / fake runtime seed。 | test fail-fast / replay job rejected。 |

| Cross-field rule | Inputs | Validation | Failure |
|---|---|---|---|
| profile vs adapter mode | profile and adapter mode。 | production-like rejects fake/test;integration-like may use controlled seam。 | startup fail-fast。 |
| logical store completeness | truth/projection/reference/outbox/idempotency store refs。 | all required logical stores present and compatible。 | startup fail-fast。 |
| resolver family coverage | resolver families。 | required P0 families present exactly once。 | startup fail-fast。 |
| topic completeness | outbound feature keys and route refs。 | every enabled topic-neutral key has route ref。 | startup fail-fast。 |
| retention consistency | idempotency/job/event/report retention。 | retention covers retry,redelivery and replay windows。 | startup fail-fast。 |
| batch and page limits | job batch,outbox batch,projection/reference batch,page limit。 | batch <= page limit unless scoped run input lowers it。 | startup fail-fast / job rejected。 |
| redaction safety | deny fields and high-cardinality flag。 | deny list non-empty;P0 high-cardinality false。 | startup fail-fast。 |
| no invariant override | any config source。 | cannot set truth/state/query/outbox/idempotency invariant flags。 | config reject。 |

| 生效方式 | 本项目 P0 口径 | 适用配置 | 失败处理 |
|---|---|---|---|
| static design boundary | 不是配置项。 | truth ownership、state transition、query no-write、stored replay、marker source。 | 出现 override 即 reject。 |
| startup | runtime builder 前加载并冻结。 | runtime、stores、resolver、consumer、outbox、jobs defaults、handoff、redaction、boundary、idempotency。 | invalid => builder failed。 |
| job-run-start | 每个 job run 开始时冻结。 | job input scope、batch、target、replay root、current run cursor/page where allowed。 | invalid => job rejected。 |
| entry-local | 只影响当前入口选择。 | profile selector、config source selector、job request source、dry-run selector。 | invalid => current entry rejected。 |
| test harness | fake runtime / fixture load 前生效。 | fixture set、fixed clock/id、fake adapter seed。 | invalid => test fail-fast。 |
| reload / hot | P0 unsupported。 | 无。 | presence of reload/hot config => reject。 |

| Validated group | Assemble target | Exposed to | Not exposed to |
|---|---|---|---|
| runtime / profile | validated runtime config and runtime builder state。 | infra runtime builder。 | domain / public contracts。 |
| stores / material | store registry、repository adapters、UoW manager。 | application repository ports。 | raw store config、product DSN。 |
| resolvers / inbound / outbox | resolver ports、consumer registry、publisher route map。 | application / worker / job services。 | sibling body、event schema mutation。 |
| jobs / handoff / externalGrc | job runner params、handoff target set、optional export target。 | jobs and handoff services。 | core command acceptance、truth mutation。 |
| redaction / diagnostics / boundary | redaction checker、safe diagnostic refs、guard params。 | infra/api/worker/jobs observability hooks。 | raw matched values、raw error body。 |

|---|---|---|---|
| `ParseFailed` / `UnknownField` / `MissingRequired` | parser / schema validator。 | config source ref、module path、field class、issue ref。 | raw file body、secret。 |

|---|---|---|---|---|---|

| store / material refs | 可变更但 high / critical。 | high / critical。 | restart。 | store slot、ref digest、validation result。 | previous approved ref digest + restart。 |

| job batch / retry / retention | 可变更。 | medium / high by blast radius。 | job-run-start。 | job kind、old/new numeric class、run ref。 | new run with previous valid input。 |
| redaction / diagnostics | 可变更但安全关键。 | high / critical。 | restart。 | redaction field class、safe sink class、validation result。 | previous safe profile + restart。 |
| test fixtures / replay root | 只限测试或 operations-replay。 | test / operations review。 | test harness or job-run-start。 | fixture digest、replay root digest、de-identification marker。 | previous fixture / replay root rerun。 |

| validation | validation result、issue refs、safe diagnostic ref。 | raw secret、endpoint body、adapter error body。 |

|---|---|---|

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源：
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“结构化中间产物”“回填草稿”“待确认事项”“03 影响判定”和“stop-review”小节。

失效策略必须区分 invalid config、scoped input rejected、runtime dependency unavailable、optional read material degraded 和 job/report failed。invalid config 不能 degraded 成成功启动;runtime dependency / read material 的 degraded、delayed、failed marker 只能复制正式来源,不得由配置层合成。

| 策略词 | 语义 | 适用边界 | 禁止误用 |
|---|---|---|---|
| `fail-fast` | 在 startup / builder / validation 前阻断继续。 | required startup config、strict parse/type/range/cross-field、unsupported reload/hot。 | 事后改写 truth、stored report、stored replay。 |
| `fail-closed` | 安全不确定时拒绝危险动作。 | raw secret/body、unsafe redaction、production-like fake、forbidden boundary override。 | 宽松默认值或 silent fallback。 |
| `rejected` | 当前 job/entry/query/input 被拒绝。 | job-run-start required missing、entry-local selector invalid、raw target credential。 | 修改全局配置或启动成功。 |
| `test fail-fast` | test harness / fixture 不闭合时测试失败。 | fixture missing、fixed clock/id 非法、production-like fixture contamination。 | 生产 runtime fallback。 |
| `degraded` | 有限 read/job/adapter surface,显式返回正式 degraded/unavailable marker。 | optional read material stale/unavailable、formal adapter degraded branch。 | invalid config、raw secret、required startup binding。 |
| `delayed` | runtime action 可重试但不证明成功。 | consumer / publisher / handoff target temporary unavailable。 | command accepted truth rollback。 |
| `failed marker` | job/outbox/handoff/report 失败后写正式失败标记或报告。 | publisher failed、handoff failed、reference/report job partial failure。 | query repair、truth mutation。 |
| `no activation` | change 被拒绝且不生效。 | critical boundary change、unsafe redaction relax、unsupported reload/hot。 | force apply。 |

| 失效模式 | 触发面 | 系统行为 | 是否告警 | 安全输出 |
|---|---|---|---|---|
| required startup config missing | startup / builder。 | fail-fast;builder not Ready。 | 是。 | config section、field class、issue ref。 |
| type / range / enum invalid | startup / job / entry / test。 | startup fail-fast;job/entry rejected;test fail-fast。 | 是。 | expected class、rule ref、issue ref。 |
| high-priority illegal source | source merge。 | fail-fast / scoped reject;no fallback to lower priority。 | 是。 | source kind、profile、issue ref。 |
| raw secret or raw body detected | validation / job input / adapter output。 | fail-closed or scoped rejected。 | 是。 | forbidden class、profile、issue ref。 |
| unsafe redaction | startup / test harness。 | fail-closed;no unsafe reporting。 | 是。 | redaction rule class、safe field class。 |
| required store / adapter binding invalid | startup。 | fail-fast;no fake fallback in production-like。 | 是。 | adapter slot category、issue ref。 |
| runtime resolver unavailable | runtime adapter call。 | unavailable / delayed / degraded by formal role。 | 按 role。 | copied formal marker、safe diagnostic ref。 |
| query read material stale/unavailable | query。 | degraded / stale / unavailable surface;query no-write。 | 按 surface。 | formal marker category、no body/cursor leakage。 |
| publisher or handoff target failed | outbound / handoff job。 | failed marker / report issue;truth unchanged。 | 是。 | target digest、marker ref、report ref。 |
| rollback failed | change recovery。 | safe issue;manual/design intervention direction。 | 是。 | rollback ref、validation issue ref。 |

| 配置域 | 策略重点 | 红线 |
|---|---|---|
| runtime / builder / facade | required config fail-fast;builder Ready 前不暴露 facade。 | half-assembled facade、hot reload、config center dependency。 |
| repository / material store | selected required store missing fail-fast;optional read material unavailable may degraded。 | fallback to mismatched store、truth repair。 |
| source / resolver / inbound | required source/ref missing fail-fast or operation rejected;runtime unavailable follows formal marker。 | raw external body、marker synthesis、command emulation。 |
| publisher / outbox / handoff | enabled target missing fail-fast/job rejected;runtime failure becomes failed marker/report。 | delivery proves truth、publish failure rollback truth。 |
| query / read policy | stale/unavailable can degrade;query no-write preserved。 | read-time repair、hidden write、fake private fallback。 |
| operations job | required input missing rejected;runner dependency unavailable failed/suspended/report issue。 | job config modifies core truth、lease-as-truth、hot change during run。 |
| diagnostics / redaction | unsafe redaction fail-closed;diagnostic sink unavailable only safe issue/degraded reporting。 | raw output、admin hot relax、unsafe high-cardinality labels。 |
| test / replay / fixture | fixture invalid test fail-fast;replay root must be de-identified。 | fixture pollution into production-like、raw replay body。 |

| 输出面 | 允许字段 | 禁止字段 |
|---|---|---|
| alert / log / trace | issue ref、safe diagnostic ref、profile、adapter slot、marker category。 | raw config、secret、body、full sensitive ref。 |
| query surface | formal degraded/stale/unavailable marker、safe reason category。 | body excerpt、hidden write result、synthetic marker。 |
| job report | report ref、failed marker、target digest、counts。 | raw external payload、package body、provider response。 |
| audit | actor/ref/digest/validation result。 | raw backup、raw secret、stored report rewrite。 |

当前 §11 不新增 error DTO、availability marker、degraded marker、port、mapper、repository、schema、diagnostic sink 或 marker source。后续测试方案可覆盖配置缺失、校验失败、敏感禁输、no silent fallback、query no-write、no truth rollback 和 marker gate,但正式 TC、fixture、assertion、evidence schema 必须留给 `05-测试方案.md` 重启后定义。

未来新增或废弃配置必须先回到 Step 7~12 重新校准配置项、来源、profile、secret、加载、审计、失效和下游承接。config center、admin override、hot reload、online last-known-good、product-specific secret provider、compat parser、alias mapping、public deprecation issue schema 和 migration runner 均不属于当前 P0 已支持能力;如需要正式化,必须先完成 owning source 设计闭口。

当前 §13 不影响 `03-详细设计.md`。迁移未来若需要 old/new carrier、alias mapping、compat parser、runtime migration runner、public deprecation DTO 或 marker source,必须暂停并回 `03` owning Step。

2. 概要设计中的代码主体框架是否已经足够稳定？

   回答：是。`01-架构设计.md` 与 `02-概要设计.md` 已经把业务主语、实现分层和 P0 / P1 边界固定下来,详细设计不应再重画主线。

3. 概要设计中的关键对象、接口骨架、处理流和状态机是否足够继续展开？

   回答：是。对象已点名到 `MethodContent`、7 类 subtype、`OutboxEvent`、`DefinitionSnapshot`、`MethodPlugin`、`MethodConfiguration` 等;接口、处理流和状态机也已足以向下展开到模块级实现契约。

4. 哪些内容仍停留在概要设计轮廓,进入详细设计前必须补清？

   回答：文件布局、模块边界、对象完整字段、完整函数签名、trait / port / adapter 契约、协议 schema、函数级调用链、事务边界、错误模型、并发与幂等、配置绑定、可观测性和测试切口都还要在详细设计里补齐。

#### 配置来源链图: L4-archive 配置覆盖与装配链

```text
[explicit code declarations / schema metadata]
                    |
                    v
           [one strict JSON document] ----> [allow-listed ENV leaves]
                    |                                  |
                    +------------------+---------------+
                                       v
                            [infra::config.rs]
                    parse / type / range / cross-field
                                       |
                     body-free typed refs + safe issues
                                       v
                         [infra::runtime_builder.rs]
              freeze profile + surfaces + required exact slots
                                       |
                  exact handles + markers + validated budgets
                         +-------------+-------------+
                         v                           v
                [application facades]       [worker facades]
                         |                           |
                         v                           v
                  commands / queries       consumers / jobs

[opaque secret ref] --private resolution--> [exact infra adapter only]
[test fixture] -----test-only assembly-----> [fake support only]
```

关键说明：

- 该链只表达配置来源、校验和装配，不表达部署命令、网络拓扑或供应商产品。
- `secret resolver` 只解析已获胜的 opaque locator，不参加普通来源覆盖，也不把明文秘密返回到 domain/application/API/worker。
- required set 在 `ArchiveRuntimeAssembly::begin` 依据 exposed surface/selected target 冻结；missing、mismatch、`Degraded` 或 required `Disabled` 时不暴露相应 facade。
- source authority、项目状态、治理决定、manifest closure、完整性结果、外部 commit、恢复写权、Query no-write 和 readiness 不受配置覆盖。

| 控制面 | 作用 | 对应模块 / 入口 | P0 | 禁止控制 |
|---|---|---|---|---|
| profile / config identity | 选择有限 profile、schema/config revision | `infra::config.rs`、`runtime_builder.rs` | 是 | 业务状态、审批、readiness |
| exact adapter assembly | 绑定 11 类 `ArchiveAdapterSlot`，冻结 required/optional | `runtime_builder.rs` | 是 | marker 冒充 handle、缩减 required set |
| local store / consistency | UoW、CAS、read-set、probe、claim/fence 能力引用 | `store_adapter.rs`、worker control | 是 | 关闭 atomicity、last-write-wins、跨仓事务 |
| source / authority / visibility | 每个 `SourceClass`、authority 和 visibility 的 exact binding | source/authority/visibility adapters | 是 | workspace 补 canonical、缓存代替 current decision |
| integrity / compatibility | Bundle/target 能力与版本引用 | integrity/compatibility adapters | 是 | 选择算法/key、Unknown 配成 Verified |
| storage / lifecycle | placement/retrieve/lifecycle target 与正式 decision/schedule ref | storage/governance adapters | 是 | 生成 retention/hold/delete/risk 决定 |
| restore receivers | selected owner 到 exact receiver 的映射 | restore receiver adapters | 是 | Bundle 跨域写权、all-owner fallback |
| inbound consumers | 五类 inbound family、schema/trust 和 route binding | consumer adapters/worker | 条件 | arrival/ACK 当 commit、未知 family 动态订阅 |
| operation / cursor | operation key/input digest 与 public/private cursor seam | application/query boundary | 是 | ad hoc codec、private cursor 出站 |
| budgets / lifecycle | page/batch/timeout/retry/probe/lease 与 schedule ref | application/worker wrappers | 是 | zero/default、盲重试、schedule 授权销毁 |
| observability / redaction | safe telemetry、redaction、可选 material handoff | infra hooks、observability seam | 是 | raw body/secret、backend truth |

### 4.1 永久禁止配置化事项

| 禁止配置化项 | 原因 | 如需改变应走的流程 |
|---|---|---|
| source-authority matrix 与 Canonical/Conditional/Auxiliary 分类 | authority 是 owner 事实 | 重新核验 owning project 合同与 00/01/03 |
| identity/conversation/work/process/governance/artifact/workspace/observability truth | Archive 不拥有或反写这些 truth | owner 正式文档和边界变更 |
| 项目 `archived/dissolved/restored` 状态 | Archive 局部状态不能推导项目状态 | `L1-work`/正式 owner 状态流程 |
| RetentionPolicy、legal hold、delete authorization、risk acceptance | 需要正式 governance decision | governance owner/ADR；缺失即 blocked |
| manifest closure、revision immutability、source coverage | 不能因 limit 截断或缺 material 仍 Complete/Sealed | 03 对象/状态/持久化回写 |
| digest/signature/encryption/compression/schema authority 与结果 | provider/算法/key 尚未闭合 | 安全/基础设施 owner + 03/04 回写 |
| operation key equality、canonical input、duplicate replay | 防止异输入覆盖和盲重放 | 03 concurrency/idempotency 重校准 |
| intent-before-effect、commit-unknown probe/reconcile | 保护外部副作用和未知提交 | 03 flow/error/port 重校准 |
| local atomic UoW、CAS/read-set/fence/append-only history | 不能由 profile 放宽一致性 | 03 persistence/transaction 回写 |
| current visibility、Query no-write、redaction denylist | 防止越权和泄露 | 03 protocol/security/observability 回写 |
| per-owner receiver 与跨域写权限 | endpoint/registry 不是授权 | owner receiver/import contract |
| fake success、evidence、signoff、readiness | 局部替身或状态不是真实证明 | 05/06/07 证据链 |
| outbound event/outbox/publisher | `AR-HLD-Q-001` 未闭合 | 回退 02/03 与 Bus 合同后重开 |
| SDK compile dependency direction | 防止 server 反向依赖 client 或循环 | 全局依赖规则与 `L0-sdk` ADR |

所有 P0 配置均为冷生效：profile/binding/slot/codec/security 需新 assembly；page/batch/timeout/retry/lease/probe 在 startup 或 job-run-start 固化；已运行 operation/job 使用其 pinned config/binding identity。当前不支持 remote config center、admin override、online LKG、reload、hot 或 dynamic replacement。

## 5. 配置来源、优先级与冲突处理

> 校准来源：
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读：
> - 建议继续阅读上述文件的“来源优先级表”“冲突场景矩阵”“按配置域来源覆盖表”“敏感配置映射”和“跨来源审计”小节。

### 5.1 来源优先级

普通配置字段的唯一覆盖顺序由低到高为：

```text
code declaration (R0) < one strict JSON file (R1) < allow-listed ENV leaf (R2)
```

| 来源 | 优先级 | 允许内容 | 冲突处理 | 不可用策略 |
|---|---:|---|---|---|
| 显式 code declaration | R0 | schema metadata、required/source metadata、经确认的安全声明 | 同一声明重复属于设计错误；required 无默认仍 missing | 不补 zero/empty/null |
| 一个 strict JSON 配置文件 | R1 | ordinary scalar、typed object、finite map、opaque ref | 重复键、未知键、历史 alias、JSONC 或多文件合并均拒绝 | 文件不可读/非法→whole candidate fail-fast |
| allow-listed ENV leaf | R2 | registry 明确允许的 scalar 或 opaque ref | 覆盖 R1/R0；空字符串按 present 解析后校验 | 未出现表示无 override；未知 namespace→fail-fast |
| secret resolver result | 不参与覆盖 | winner locator 对应的私有 material/handle | 不改变字段 winner、mode、target、authority 或 capability | required resolution 失败→Unavailable/Blocked |
| test fixture / fake override | test-only lane | deterministic test assembly input | 只能在 test profile；不得覆盖 production candidate | production 发现→fail-fast |
| derived assembly / old-work snapshot | 不参与 merge | config identity、slot set、job budget、old binding | 只能由已验证 winner 派生；old work 读取 pinned identity | 缺失/不一致→Blocked |
| remote config center / admin / arbitrary CLI | 当前不允许 | 无 | 出现即 `UnsupportedSource` | candidate reject；未来先回写 03/04 |

### 5.2 冲突与非法 winner

| 场景 | 处理规则 | 是否阻断 |
|---|---|---|
| JSON 同一对象重复键 | strict parser 拒绝 whole candidate | 启动阻断 |
| 未知 key、历史 alias、camelCase/下划线别名混用 | 不建立兼容别名；拒绝 whole candidate | 启动阻断 |
| JSON 与 ENV 同字段出现 | ENV 是 winner；按 ENV 做完整 type/range/cross-field 校验 | 非法则阻断，不回退 JSON |
| 同级声明/来源值不一致 | registry 冲突，拒绝 candidate | 启动阻断 |
| required 为空字符串、null 或零值 | 视为 present 后校验失败；不取低优先级/default | 启动或相关操作阻断 |
| source/owner/consumer mapping 缺项或多项 | exact slot totality 校验失败；不选 first-match | facade/操作阻断 |
| raw secret 与 opaque locator 同时出现 | `ForbiddenSecretMaterial`；不记录值 | 启动阻断 |
| JSON 与 ENV profile 不一致 | `CrossFieldConflict`，拒绝 whole candidate | 启动阻断 |
| test fixture 出现在 production-like | profile isolation violation | 启动阻断 |
| required provider/store/secret 不可达 | typed unavailable/blocked；不切 fake/default | 受影响 assembly/operation 阻断 |
| optional slot 显式关闭 | 仅 validated registry 标为 optional 时接受 `DisabledByConfig` | 无关 surface 不阻断；required 仍阻断 |
| old work 用 current config 重建 | 禁止；读取 stored config/binding identity | 该恢复/重放阻断 |

### 5.3 按域来源边界

| 配置域 | 允许来源 | 禁止来源 | 失败姿态 |
|---|---|---|---|
| `profile` / `assembly` | DECL、JSON、有限 ENV scalar/ref | config center、admin、payload | invalid/missing→fail-fast |
| `stores` | DECL metadata、JSON opaque binding、必要 ENV ref | raw DSN/password、payload、生产 test override | resolve fail→assembly blocked |
| `sources` | JSON exact per-source ref、registry allow-listed ENV ref | workspace fallback、dynamic payload mapping | target-specific blocked |
| `authority_visibility` | JSON typed capability/policy refs | local allow boolean、cache result、event payload | unknown/expired→blocked/not available |
| `integrity_compatibility` | JSON capability/target refs | algorithm/key literal、Bundle digest reuse | unsupported/unknown→assessment blocked |
| `storage_lifecycle` | JSON storage/decision/schedule refs | self-authored retention/hold/delete | missing decision/storage→blocked |
| `restore_receivers` | JSON per-owner refs、opaque credential refs | all-owner fallback、raw endpoint | owner target blocked/unknown |
| `inbound` | JSON exact family/schema/trust refs | topic inferred from payload、unknown family | quarantine/no ACK success |
| `operation_cursor` | JSON typed codec/mapping refs | debug/JSON ad hoc、Bundle digest | mutation/continuation blocked |
| `budgets` | DECL confirmed bound、JSON/ENV scalar when allow-listed | zero implicit、job payload override | fail-fast/new job blocked |
| `observability` | JSON redaction/safe binding refs | raw sink endpoint/secret/body dump | safe signal degraded; native failure blocks UoW |

### 7.4 配置项闭环约束

| 约束 | 正式口径 |
|---|---|
| 来源 | 普通字段只服从 `DECL < one strict JSON < allow-listed ENV`；secret resolver、fixture、job payload、derived assembly 和旧作业快照不参与 merge。 |
| 必填与默认 | 必填项没有隐式 zero/empty/default；`Blocked`/`Disabled` 代表能力姿态，不代表成功。 |
| exact set | `SourceClass`、owner、inbound family、receiver、slot 和 exposed surface 都按有限 registry 做 totality 校验；不采用 first-match 或动态字符串 fallback。 |

## 8. 敏感配置与密钥管理

> 校准来源：
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“敏感级别和存储规则”“Step 7 敏感配置映射表”“读取、轮换、审计和禁止输出流程”及“跨敏感配置泄露风险审计”小节。

### 8.1 敏感级别与存储边界

| 敏感级别 | 本仓示例 | 普通 JSON/ENV | infra 私有处理 | 日志/错误/report/audit/trace |
|---|---|---|---|---|
| `internal` | profile、schema/config revision、预算、有限 telemetry mode | 允许；仍需 strict schema | 转为 validated typed value/ref | 仅有限 enum/category；不输出 raw document |
| `sensitive` | store/source/owner/receiver/storage/integrity/codec/cursor/sink/registry ref、redaction identity | 只允许 opaque ref；不得携 raw credential/locator body | 解析为 body-free binding identity | 不输出完整 ref、endpoint、target、scope、selector、key/digest |
| `secret` | password、private key、raw token、credential、certificate/DSN body、provider response | 禁止 | 仅由未来受控 provider/adapter 私有解析；P0 不定义 provider | 永不输出、序列化、持久化或复制 |
| protected material | source/export/artifact/workspace/observability body、receiver payload | 禁止 | 只接收 owner-approved material/ref seam；不放入 config | 不输出正文、body、raw response 或 hidden value |

可关联的 hash/ref 仍按敏感数据处理，不能用摘要化绕过禁止输出。Archive 不拥有 KMS、secret truth、key material 或 provider response。

### 8.2 按配置域的敏感处理、读取与轮换

| 配置组 | 存储/读取 | P0 轮换和生效 | 审计最小信息 | 失败姿态 |
|---|---|---|---|---|
| `profile.*` / `assembly.*` | strict value + opaque registry ref；仅 config reader 读取 raw | new config revision + new assembly | profile/category/revision posture | invalid/unknown→candidate reject |
| `stores.*` | opaque adapter/store ref；禁止 DSN/credential body | new binding + restart/new assembly；旧 work pinned | slot family/build posture | resolve/capability 缺失→assembly blocked |
| `sources.*` | per-SourceClass opaque ref；不记录 owner/selector/body | new binding + new job run | source class/posture | target-specific blocked/partial/unknown |
| `authority_visibility.*` | exact slot/redaction ref；不保存 allow/deny payload | new assembly；旧 operation 不漂移 | slot/category/policy revision | unavailable/unsafe→surface blocked |
| `integrity_compatibility.*` | capability/target ref；无 algorithm/key/digest | new target binding + job-run-start | target category/posture | Unknown/Unsupported/Conflicting |
| `storage_lifecycle.*` | storage、formal decision、schedule ref；无 location/credential/body | new assembly/job run；未决 effect 不重构 | target/decision category/revision | no dispatch/cleanup；Blocked/Unknown |
| `restore_receivers.*` | per-owner receiver/schema registry ref；无 endpoint/payload | new mapping + new plan/job revision | target kind/schema posture | item/plan blocked |
| `inbound.*` | finite family/schema/trust ref；无 topic/credential/body | new assembly；未知 family quarantine | family/schema category | rejected/quarantined；不 ACK success |
| `operation_cursor.*` | opaque codec/mapping ref；无 private cursor/key | new assembly；旧 operation/cursor pinned | protocol category/compatibility posture | mutation/continuation blocked |
| `budgets.*` | typed bounded internal value | startup 或 job-run-start | budget class/validation result | invalid/unknown→reject；不默认 |
| `observability.*` | safe sink/material ref；无 endpoint/secret/body | new assembly；sink failure 只 drop/degrade | sink/material posture | optional degraded；不建 evidence truth |

```text
          |
          v
[infra/config.rs: parse + sensitivity check + redacted issue]
          |
          v
[runtime_builder: validated binding identity]
          |
          +--> [exact adapter private resolution]
          |          |
          |          +--> [private secret/material use]
          |          |          |
          |          |          +--> [typed outcome only]
          |          |
          |          +--> [no body/secret/ref leakage]
          v
[application/api/worker: typed facade only]
```

关键说明：

- `secret resolver` 只解析已获胜的 opaque locator，不改变普通字段的 winner、profile、target、authority 或 capability。
- private resolution 失败不得改用空字符串、默认 provider、fake-success 或 raw-error fallback；required capability 进入 `Blocked/Unavailable`。
- P0 不支持 hot rotation：startup binding 以新 ref + 新 assembly/restart 生效；job target 以新 run 固化。旧 operation/effect/plan 保留 pinned config/binding identity。

### 8.3 禁止输出规则

| 输出面 | 允许 | 默认禁止 | 失败处理 |
|---|---|---|---|
| config validation issue | module/field class、slot family、profile、safe issue ref | raw file/value、secret、full ref、endpoint/body | 丢弃敏感 detail，返回 redacted typed issue |
| runtime log | finite category/posture、phase、safe issue ref | credential、secret、owner/selector/scope、location、digest/key、body | redaction fail→drop/suppression counter |
| metric label | profile class、slot family、error/posture 等固定 enum | 任意 ID/ref/key/digest/owner/free text | label validation reject |
| span | operation/channel/phase、typed outcome、trusted trace context | secret/ref/body/endpoint/provider response | omit unsafe attribute；不改变业务结果 |
| Archive durable record | 03 已定义的 body-free refs 与 native history | raw secret、provider response、unapproved body、新 generic audit ledger | UoW failure 保持失败；telemetry 不替代 truth |
| report/receipt/API error | safe disposition/error category/issue ref | raw config、secret、endpoint、stack/SQL/HTTP body | 映射 typed safe error；保留 blocked/unknown 区分 |

配置读取或变更只允许审计安全的 category、slot/profile、revision、validation/activation posture 和 issue ref；不记录完整 locator 或材料。真实 provider、密钥、算法、挂载与轮换命令继续属于 blocker 和未来运维边界。

## 9. 配置加载、校验与生效机制

> 校准来源：
> - `design-calibration/04_config_step_09_loading_validation_activation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置加载流程图”“配置域的 parse / type / cross-field / assembly 闭环”“Cross-field 校验矩阵”“生效方式矩阵”和“Config validation issue surface”小节。

#### 配置加载流程图: strict candidate 到受限 facade

```text
[code declaration / schema metadata]
              |
              v
[one strict JSON document] ---> [allow-listed ENV leaves]
              |                         |
              +-----------+-------------+
                          v
              [source occurrence collection]
                          |
          duplicate / unknown / alias / profile conflict
                          |
                          v
                 [infra::config.rs]
        parse -> type/range -> sensitive/body checks
                          |
                  cross-field validation
                          |
          body-free typed refs + validated parameters
                          v
              [infra::runtime_builder.rs]
  freeze profile + surfaces + selected targets + required slots
                          |
       inspect exact binding -> build real handle + marker
                          |
     reject missing/mismatch/Degraded/required Disabled
                          |
            [ArchiveRuntimeAssembly::Ready]
             /                         \
  restricted application facades       worker facades
```

`Ready` 只说明当前本地 exact assembly 的 required handles 已构造，不说明 Bundle、storage、receiver、owner、外部集成或产品 readiness。job/entry 不得重新读取 raw config、替换 handle 或缩短 required set。

### 9.1 按配置域的加载与装配

| 配置域 | 加载时机 | parse/type/range | cross-field 与 assembly | 失败策略 |
|---|---|---|---|---|
| `profile` / `assembly` | startup | finite profile、supported revision、exact registry shape | profile↔test/fake；surface↔required/optional slot；begin 后冻结 identity | candidate reject；Ready 前无 facade |
| `stores` | startup | typed refs；拒绝 DSN/body | Store/Context/Worker slot↔UoW/CAS/read-set/probe/fence capability | required capability 缺失→assembly blocked |
| `sources` | startup；job-run-start 选择 target | fixed SourceClass keys、opaque ref | selected source totality、owner/fence/coverage；workspace 不 fallback | target-specific blocked/partial/unknown |
| `authority_visibility` | startup | exact slot/redaction ref | Query surface 必须 current Visibility；redaction 不得放宽 | surface blocked/fail-closed |
| `integrity_compatibility` | startup；assessment job start | capability/target/version ref | target registry↔manifest/receiver context | Unknown/Unsupported/Conflicting；不验证/恢复 |
| `storage_lifecycle` | startup；job-run-start | storage/decision/schedule ref | schedule≠decision；effect kind↔current decision↔probe support | no dispatch/cleanup；Blocked/Unknown |
| `restore_receivers` | startup；restore job start | finite owner map/schema ref | frozen owner set 每项 exact match；禁止 all-owner fallback | per-item/plan blocked |
| `inbound` | startup | finite family/schema/trust refs | exposed family 必须 exact route；unknown schema不可接收 | reject/quarantine；no ACK success |
| `operation_cursor` | startup | body-free codec/mapping refs | non-Query 需 key+input codec；Query continuation 需完整 mapping | reserve/continuation blocked |
| `budgets` | startup；job-run-start | positive bounded number/duration | page/request、batch bound、retry/probe、lease/window 关系 | fail-fast 或当前 job rejected |
| `observability` | startup | finite mode/ref | telemetry off 不放宽 redaction；material handoff需 owner contract | sink drop/degrade；native UoW failure不变 |

### 9.2 Cross-field 校验矩阵

| 规则 | 必须校验 | 失败姿态 |
|---|---|---|
| profile 与 adapter posture | production-like 拒绝 fake/test；local/CI fake 仅 test assembly；integration-like 仅 controlled seam | startup fail-fast |
| surface 与 required slots | 每一 exposed surface 计算 exact required set；配置不能删除 required | assembly failed |
| source totality | required source 唯一；WorkspaceProjection 固定 Auxiliary，ObservabilityMaterial 固定 material | selected target blocked |
| restore owner totality | frozen owner set 每项有 exact receiver；无 all-owner fallback | item/plan blocked |
| Query cursor binding | query kind、public codec、repository mapping、visibility/snapshot/order basis 全部一致 | continuation blocked |
| operation codec | command/consumer/job 必须同时有 operation key 与 input-digest binding；不借 Bundle digest | mutation reserve blocked |
| storage/lifecycle authority | schedule 不产生 retention/hold/delete/risk decision；dispatch 前需 current formal decision | lifecycle blocked |
| budget ordering | required value 有界；page/batch 不越界；Unknown 不得以 retry 替代 probe；lease/window 关系有效 | fail-fast/job rejected |
| redaction safety | denylist 覆盖 03 forbidden classes；telemetry disabled 也不放宽 | fail-closed |
| inbound trust | family、schema/version、trusted source marker一致；unknown 不 ACK success | consumer rejected/quarantined |
| pinned old work | old operation/effect/plan 只用 stored identity，不按 current candidate 重建 | replay/restore blocked |

### 9.3 生效矩阵

| 生效方式 | P0 适用内容 | 失败处理 | 旧工作处理 |
|---|---|---|---|
| `startup / new assembly` | profile、bindings、slots、store、codec、redaction、进程预算、telemetry mode | validation/build fail-fast；Ready 前无 facade | 已运行 operation 不漂移；新 assembly 使用新 identity |
| `job-run-start` | selected source/owner target、batch/timeout/retry/probe/lease、schedule、replay input | 当前 job rejected/blocked；不进入 mutation/effect | run 固化值；partial resume 是新 operation + explicit unresolved set |
| `entry-local` | 当前入口的安全 selector/lower bound/diagnostic selector | 只拒绝当前入口；不得改 startup invariant | 不改变 stored result/intent |
| `test harness` | deterministic fake/clock/id/fixture | test fail-fast；production builder 拒绝 fake | test assembly only |
| `reload` / `hot` | P0 unsupported | 出现 source/key→`UnsupportedReload`/candidate reject | 无 online LKG 或半切换 |
| `build-time` / `static` | compile graph 与 truth/UoW/CAS/fence/Query no-write/restore/outbound 红线 | 按设计门禁处理；override key→`ForbiddenInvariantOverride` | 不由 runtime config 改变 |

### 9.4 Validation issue surface

| Issue 类别 | 安全载荷 | 禁止载荷 | 处理 |
|---|---|---|---|
| `ParseFailed` | source kind、redacted location、safe issue ref | raw JSON/body | candidate reject |
| `UnknownField` / `DuplicateField` / `AliasField` | module path、field class、issue ref | sensitive raw value | candidate reject |
| `MissingRequired` | module path、required class、issue ref | secret/ref body | fail-fast/target blocked |
| `InvalidType` / `InvalidEnum` / `InvalidRange` | expected class、module path、issue ref | raw sensitive value | fail-fast/entry/job rejected |
| `CrossFieldConflict` | rule ref、module paths、issue ref | involved body/value | fail-fast |
| `ForbiddenSecretMaterial` | forbidden class、module path、issue ref | detected material | fail-closed |
| `ForbiddenInvariantOverride` | boundary class、issue ref | attempted payload | fail-closed；需设计变更 |
| `UnsupportedSource` / `UnsupportedReload` | source/activation class、profile class、issue ref | source body | candidate reject |
| `BindingMismatch` / `CapabilityBlocked` | exact slot family、safe issue ref | provider response/credential | assembly/target blocked |

Issue ref 只是安全诊断句柄，不能证明 external success、evidence、acceptance 或 readiness。

## 10. 配置变更、审计与回滚

> 校准来源：
> - `design-calibration/04_config_step_10_change_audit_rollback.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“变更分类与权限边界”“Candidate 变更与生效流程”“变更审计记录字段与禁止输出”“回滚规则与边界”及“跨变更审计 / 回滚审计”小节。

配置变更采用不可变 candidate：收集来源、严格校验、按风险评审，再以新 config identity 建立 assembly 或以新 job-run-start 固化作业输入。没有原地替换 handle、在线覆盖或删除历史的路径。权限只按角色类别描述，不假设工单、部署或审批产品。

### 10.1 变更分类与权限边界

| 变更类别 | 典型配置域 | 发起方 | 评审要求 | 风险 | P0 生效 | 回滚 |
|---|---|---|---|---|---|---|
| profile/非敏感预算 | `profile.*`、`budgets.*` | 配置维护角色 | schema/cross-field；改变 profile posture 时独立评审 | medium/high | 新 assembly；job budget 新 run 固化 | 前一 validated candidate 重新校验并新 assembly/run |
| local store/context/worker | `stores.*` | infra/config owner | UoW/CAS/probe/fake posture | high | 新 assembly；新 lease context | 前一 validated binding + 新 assembly；旧 work 不漂移 |
| source/authority/visibility | `sources.*`、`authority_visibility.*` | source/authority owner + 配置维护角色 | source totality、visibility/redaction、owner 合同 | high/critical | 新 assembly；target 新 job 固化 | 前一 binding candidate；缺口仍 blocked |
| integrity/compatibility | `integrity_compatibility.*` | integrity/compatibility authority + 配置维护角色 | capability、schema/version、target compatibility | critical | 新 assembly；assessment 新 run | 前一 validated ref；未知不自动放行 |
| storage/lifecycle/governance | `storage_lifecycle.*` | storage/governance owner + 配置维护角色 | placement/decision/schedule/probe | critical | 新 assembly；effect/decision 新 run 固化 | 新 assembly 使用前一 ref；不撤销 owner decision |
| restore/inbound trust | `restore_receivers.*`、`inbound.*` | receiver/trust owner + 配置维护角色 | owner totality、schema/trust、ACK/commit boundary | critical | 新 assembly；新 plan/job 固化 | 前一 validated map；未闭合继续 blocked/quarantine |
| codec/cursor/redaction/telemetry | `operation_cursor.*`、`observability.*`、redaction | 协议/安全/观测 owner + 配置维护角色 | codec/mapping、default-deny、Query no-write | high/critical | 新 assembly；旧 key/cursor 不漂移 | 前一安全 revision + 新 assembly |
| 文档说明/注释 | JSONC、calibration | 文档维护角色 | 文档审阅；不改变 strict JSON | low | 不进入 runtime | 修订材料，不产生 runtime audit |

任何角色都不能通过配置改变 truth owner、RetentionPolicy/legal hold/delete/risk decision、Archive 状态、Query no-write、UoW/CAS/fence、outbound blocker 或 restore handoff 边界。

### 10.2 Candidate、评审、激活与回滚

```text
[authorized change candidate]
             |
             v
[DECL < JSON < ENV collection]
             |
             v
[parse + type/range + cross-field + sensitivity checks]
             |
       invalid? ---- yes ---> [reject; safe issue; no activation]
             |
             no
             v
[risk classification + independent review for high/critical]
             |
       reject? ---- yes ---> [audit rejected posture; active candidate unchanged]
             |
             no
             v
[new config identity / new assembly or new job-run-start]
             |
       build fail? ---- yes -> [audit blocked posture; no facade/effect]
             |
             no
             v
[active candidate; old work remains pinned]
             |
       anomaly/withdrawal
             v
[validate + review prior candidate -> new assembly]
```

“active”仅表示本地 validated assembly 暴露了允许的 facade，不表示 Bundle、storage、restore、owner 或产品 readiness。rollback 是新的受控变更，不是删除审计记录或重写业务历史。

### 10.3 变更审计最小字段与禁止输出

| 字段 | 允许值/处理 | 禁止内容 |
|---|---|---|
| `change_ref` / `candidate_ref` | opaque body-free ref | raw request、自由文本正文 |
| `actor_category` | finite role category | 人员身份、token、session |
| `profile` / `domain` / `classification` | validated finite enum | 任意未校验标签 |
| `old_identity` / `new_identity` | redacted identity 或安全 revision ref | 完整 locator、endpoint、DSN、secret |
| `validation_posture` | `accepted/rejected/blocked/unsupported` 等有限值 | raw error/provider response |
| `review_posture` | `not_required/pending/approved/rejected` | 未经授权的 approved 断言 |
| `activation_posture` | `not_activated/assembly_ready/target_blocked` 等有限值 | product readiness、external commit |
| `rollback_of` / `supersedes` | opaque lineage ref | 删除原记录、伪造旧成功 |
| `issue_ref` / `timestamp` | safe issue ref、受控时间 | stack、payload、secret、scope/owner |

保存位置、保留期、访问控制和导出由正式运维/治理 owner 决定；Archive 不创建第二套业务审计数据库，也不把配置审计当作 `L4-observability` evidence chain。

### 10.4 变更类型与回滚矩阵

| 场景 | 允许动作 | 禁止动作 | 结果姿态 |
|---|---|---|---|
| parse/type/cross-field 失败 | 记录 safe issue；保留现有 active assembly | 回退低优先级、猜默认、半应用 | `rejected` / `fail-fast` |
| required slot 缺失或 Degraded | 修正 candidate 后新 assembly | marker 冒充 handle、fake、缩短 required set | `blocked` |
| 新 assembly 构造失败 | 在安全边界内保留未替换 assembly；新请求按 gate | 半替换 adapter、修改旧 identity | `assembly_failed` |
| job-run-start 失败 | 拒绝当前 job；提交新 candidate/new run | 用 current config 猜旧 run、跳过 owner/decision | `rejected` / `blocked` |
| external effect Unknown | 保留 intent/Unknown；先 probe/reconcile | 以 rollback 直接重派或伪造 committed | `commit_unknown` / `reconcile_required` |
| 已激活 candidate 不安全 | 前一 validated candidate 重新评审并新 assembly；必要时阻断入口 | 删除审计、强制 hot swap | `blocked` 或安全旧 assembly |
| source/owner/governance 合同变化 | 等 owner 正式决定并提交新 ref | Archive 自行改状态/保留/hold/delete/risk | `blocked` / `unknown` |

P0 不支持 `reload`、`hot`、online LKG 或 dynamic adapter replacement；未来若需要这些能力，必须先回写 03/04 的 runtime、状态、错误、并发和回滚契约。

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源：
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“失效模式矩阵”“按配置域的降级边界”“配置失效处理流程”“告警与测试切口边界”及“跨域审计”小节。

总原则：影响安全、真相、完整性、恢复、授权、事务或外部效果的配置失败必须 fail-fast 或 fail-closed。只有不影响业务真相的安全 telemetry sink、可选 material handoff 或明确 optional surface 可有限 degraded/drop。`Ready`、ACK、配置发布或日志存在都不能升级为产品 readiness。

### 11.1 失效模式矩阵

| 失效模式 | 影响 | 系统行为 | 安全信号 | 测试切口 |
|---|---|---|---|---|
| 文件不存在/不可读 | 无 candidate | `ParseFailed`；不暴露 facade | safe issue category | missing/read failure |
| JSON 语法、重复、未知、alias | 语义不确定 | 整份 candidate fail-fast；不回退 | safe issue | strict parser matrix |
| 必填缺失/null/zero | required 不完整 | startup fail-fast；条件 job blocked | safe issue | each required key |
| 类型/枚举/范围错误 | 越界或错误边界 | candidate reject | safe issue | boundary matrix |
| cross-field 冲突 | slot/target/budget 不一致 | candidate reject；不部分装配 | safe issue | profile/slot/source/cursor/budget |
| raw secret/body/credential 出现 | 泄露/非法信任 | `ForbiddenSecretMaterial`；不记录值 | category only | forbidden-material canary |
| required slot 缺失/错配/Degraded | facade 无能力 | assembly failed；不暴露 affected/all facade | slot posture | required-set/marker/fake rejection |
| source owner/fence/coverage unknown | 快照不完整 | source `Blocked/Partial/Unknown`；不宣称 complete | source class | source matrix |
| authority/visibility/redaction 不可用 | 越权/泄露风险 | query/effect blocked；不 fail-open | slot/posture | denied/unknown/unavailable |
| integrity/compatibility unknown/unsupported | 无法证明可验证/可读 | assessment blocked/unknown；不 seal/restore success | target class | version/integrity negatives |
| storage/lifecycle/decision 缺失 | 误放置/误删除 | no dispatch；cleanup disabled/blocked | target/decision class | storage/decision negatives |
| receiver/schema map 不完整 | 可能写错 owner | per-item/plan blocked；无 all-owner fallback | target class | owner totality |
| inbound family/trust schema unknown | 未可信输入改变状态 | reject/quarantine；不 ACK success | family/schema class | unknown family/schema |
| operation key/input codec 缺失 | duplicate 无法判断 | mutation reserve blocked；不借 Bundle digest | protocol class | same/different input |
| cursor codec/mapping 缺失/漂移 | continuation 错页或泄露 | continuation blocked/NotAvailable | query class | stale/mismatch |
| budget relation invalid/unknown | 资源放大/无限等待 | startup fail-fast 或 job rejected | budget class | ordering/boundary |
| secret/ref 解析不可用 | adapter 无法安全构造 | `Unavailable/Blocked`；不 fake/盲重试 | slot class | adapter unavailable |
| config center source 出现 | 未授权覆盖 | `UnsupportedSource`；不在线读取/LKG | source class | remote rejection |
| config/binding identity drift | old work 不一致 | old work 用 pinned；新入口/恢复 blocked | revision class | identity mismatch |
| external timeout/MayHaveDispatched | 事实未知 | `CommitUnknown/ReconcileRequired`；只 probe/reconcile | target/posture | timeout/probe |
| local commit timeout/unknown | 本地提交未知 | `probe_commit`；确认前不重放/重派 | local posture | commit unknown |
| telemetry sink/redaction failure | 信号丢失 | drop/degraded；不改业务 UoW/result | suppressed counter | non-interference |
| audit/material handoff unavailable | 材料未交接 | 保留 native record；handoff blocked；不称 evidence complete | material class | handoff unavailable |

### 11.2 按配置域的降级红线

| 配置域 | 允许降级 | 必须 fail-closed | 可见姿态 |
|---|---|---|---|
| `profile`/`assembly` | 无（可拒绝 candidate） | 不缩减 required set、不切 fake | `Failed`/`Blocked` |
| `stores` | test harness 可 fail-fast | production store/UoW/CAS/probe 不得空实现 | assembly blocked/local Unknown |
| `sources` | 非必选 auxiliary/material 可 unavailable | canonical source/fence/coverage 不得 workspace fallback | Partial/Unknown/Blocked |
| `authority_visibility` | 无危险 surface 的诊断可继续 | authority/visibility/redaction 不得 fail-open | query/effect blocked |
| `integrity_compatibility` | 记录 Unknown/Unsupported | 不把 unknown 当 verified/compatible | assessment blocked/unknown |
| `storage_lifecycle` | 非执行性诊断 | no dispatch、no cleanup、无 delete/hold/risk 推断 | effect/lifecycle blocked |
| `restore_receivers` | 其他 owner item 可独立继续（合同完整时） | 缺 receiver 不 all-owner fallback | per-item partial/blocked |
| `inbound` | 未暴露 family 可 disabled | 已暴露但不可信不得 ACK success | quarantine/rejected |
| `operation_cursor` | 不支持 continuation 时仅可提供允许的首页 | mutation 无 codec、cursor mapping 不完整不得继续 | reserve/continuation blocked |
| `budgets` | 无 | 不得 zero/default/无限；关系未知即拒绝 | startup/job rejected |
| `observability` | sink drop、material handoff blocked | 不改变业务结果、redaction 或 native audit 义务 | degraded/dropped signal |

### 11.3 失效分类流程

```text
[candidate]
     |
     v
[parse + type/range + cross-field]
     | invalid
     v
[fail-fast: reject candidate]
     |
     v
[assemble exact required slots]
     | missing/mismatch/degraded
     v
[fail-closed: no facade/effect]
     |
     v
[runtime boundary]
 local commit unknown -> [probe_commit]
 external may-have-dispatched -> [probe/reconcile]
 telemetry issue -> [drop/degrade only]
```

`probe_commit` 和 external reconcile 必须使用 03 已定义的 typed boundary；没有 probe 合同时保持 `Unknown/Blocked`。safe issue/telemetry 不能证明 external success、readiness、evidence 或 acceptance。

### 13.1 版本轴与兼容职责

| 版本/identity 轴 | 用途 | 兼容规则 | 禁止替代 |
|---|---|---|---|
| `profile.schema_revision` | raw document 可解析形状 | loader 只接受明确支持集合；unknown→fail-fast | 不等 config/owner/Bundle schema |
| `profile.config_revision` | validated candidate/assembly identity | 每次变更新 identity；old work 保留 pinned ref | 不等审批、readiness、commit 或 content digest |
| binding/registry revision | exact slot/target/family mapping | 新 assembly/job 固化；旧 mapping 不由 current registry 重建 | 不等 source version/receiver commit |
| operation codec/input digest binding | durable duplicate identity | 必须有稳定 decoder/compatibility；未闭合→reserve blocked | 不借 Bundle integrity digest |
| public/repository cursor mapping | continuation identity | 与 selector/snapshot/order/store identity一起兼容 | 不回传 private cursor/临时编码 |
| owner/export/schema version | L1 source/receiver material 解释 | owner-specific、按 exact target 校验 | 不用 Archive config revision 比较 |
| Bundle manifest/assessment revision | Bundle closure/assessment basis | immutable；新配置不得重写 | 不等配置迁移或 owner version |
| local record/CAS/fence version | 并发/事务保护 | current versioned read/fence only | 不替代 owner fence 或 external commit |

### 13.2 当前迁移与新配置引入

| 旧配置 | 新配置 | 状态 | 兼容窗口/策略 | 移除条件 |
|---|---|---|---|---|
| 无 | 无 | 当前无迁移项 | 当前标准尚未发布正式 runtime config schema；README/旧 05/06/draft 不进入 alias/registry | 不适用 |

当前无迁移不代表未来可无版本演进；它表示本正式 04 是当前标准首个配置基线。新配置必须依次完成 authority/scope、03 影响判定、04 schema 闭环、来源冲突、安全/生效、变更/回滚、05/06/07/09 承接和 blocker closure。若改变 runtime type、builder、constructor、port、error、DTO、state、flow 或 persistence，必须先回写 03。

### 13.3 废弃、兼容与移除状态

| 状态 | loader 行为 | 冲突/优先级 | 下游要求 | 退出条件 |
|---|---|---|---|---|
| `active` | 按当前 schema parse/validate | 正式来源链 | 常规 test/acceptance/ops | 替代方案确认 |
| `deprecated` | 仅在明确 window 接受并产生安全 issue | old+new 同时出现不得 first-wins；冲突拒绝 | 05 warning/conflict；06/09 migration gate | profiles 迁移且 rollback 不依赖 old |
| `rejected` | 明确失败，不映射/fallback | 无 | 05 negative、06 VETO、09 提示 | removal boundary 达成 |
| `removed` | unknown/removed key fail-fast | 无兼容 | release/迁移记录可追溯 | old work 仍用 stored identity解释 |
| `design-change-required` | 不进入 runtime schema | 无 | 先重开 03/04/下游 | 新设计停审 |

安全红线、raw secret、未知 key、P0 unsupported source/activation 不提供成功兼容窗口；兼容窗口必须由明确 schema/release 边界、loader 行为、审计、测试、回滚和移除条件共同定义。

### 13.4 旧工作与迁移红线

| 对象 | 允许 | 禁止 | 不兼容姿态 |
|---|---|---|---|
| operation/result | 用 stored key/input/config identity 回放 | current codec 重算、删除 result、重跑 effect | consistency defect/blocked |
| Reserved/CommitUnknown | pinned binding + 正式 probe | 换新 key 盲重试 | Unknown/ReconcileRequired |
| external intent/effect | 保留固定 key/binding | current storage/receiver 重构 intent | CommitUnknown/Blocked |
| public cursor | 兼容 decoder + stored mapping继续 | 映射为 current repository cursor 或泄露 private token | Stale/NotAvailable |
| Bundle/manifest/assessment | 保持 immutable revision/basis | 因迁移重签、重算、升级 Verified | Unsupported/Unknown/Conflicting |
| restore plan/item/handoff | 旧 owner map 保留；新 map 新 revision | 原地换 receiver、partial 改 complete | Partial/Blocked/CommitUnknown |
| governance/storage history | 保留原 decision/target/action lineage | current policy 重写旧记录 | Blocked/Unknown |

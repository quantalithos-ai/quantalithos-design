| Query no-write、Consumer/Job/replay no-source-repair | 防读/维护侧成为隐式 writer | ownership + exact flow；current VETO |
| logical store、UoW、write order、append-only audit | 防配置关闭 atomicity/history/outbox/result | `03` persistence/transaction/recovery/test |
| idempotency/digest/replay、claim/fence/version/cursor | 防 duplicate/stale writer 与process lock替权威 | protocol/concurrency/persistence/migration |

## 5. 配置来源、优先级与冲突处理

> 校准来源:
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
>
> 延伸阅读:
> - 建议继续阅读上述中间产物的“来源表”“原子 merge/winner”“冲突矩阵”“23 域 source 审计”和“history no-current-fallback”。

Current ordinary source 低到高固定为：

```text
SRC-DECL < SRC-JSON < SRC-ENV
```

| 来源 | 优先级 | 适用配置 | 冲突处理 | 不可用时策略 |
|---|---:|---|---|---|
| code declaration / explicit default | R0 | field/type/required/source metadata；仅4族有显式值 | 仅在更高层缺席且存在声明 default 时供值 | required-no-default 继续 missing；不补 zero/empty/null |
| one selected strict JSON document | R1 | ordinary scalar、opaque locator、strict object、set、catalog | field winner覆盖R0；duplicate/alias/unknown使whole candidate失败 | zero-or-one；显式选择但不可完整读取=`ConfigSourceUnavailable` |
| allowlisted process ENV leaf | R2 | §7批准的61个scalar/ref leaf | 覆盖R1/R0；empty也算present；invalid winner不fallback | 缺席表示无override；namespace内unknown key使candidate失败 |
| sensitive resolver result | 不参与priority | winning locator对应private material | 不得改变mode/target/capability或回填root | required resolution失败=`SensitiveReferenceUnavailable` |
| derived/historical material | 不参与new merge | config ref、slice、catalog、Job snapshot、old binding | derived只来自winner；old work只读stored identity | 缺失时fail/manual/unavailable；不读current config重建 |

Per-field winner 以 compile-time registry order 执行：收集 R0/R1/R2 已授权 occurrence，选择最高 present，
只 decode winner；winner type/range/profile/cross-field 无效时拒绝 entire candidate，不检查低层值。Set/catalog 是 JSON
whole value，不做 ENV fragment append/delete/deep merge。Entry DTO、Job request、availability、secret result、runtime
state、health、probe、telemetry 与 source history 都不是 ordinary source。

### 5.1 Exact ENV registry

ENV namespace 固定为 `QUANTALITHOS_OBSERVABILITY__`。Canonical path segment 转 uppercase snake case并以
双下划线连接；实现必须维护 61 项 exact compile-time registry，不得运行时按 prefix suffix 反射任意 path。

| Registry family | Exact mapping / count |
|---|---|
| profile | `...__PROFILE` -> `profile`；1 |
| technical | `...__TECHNICAL__{CLOCK_MODE,CLOCK_BINDING_REF,ID_GENERATOR_MODE,ID_GENERATOR_BINDING_REF}`；4 |
| boundary | `...__BOUNDARY__{MAX_REQUEST_BODY_BYTES,DEFAULT_PAGE_LIMIT,MAX_PAGE_LIMIT,QUERY_READ_TIMEOUT_MS}`；4 |
| safety refs | `...__SAFETY__{REDACTION_POLICY_REF,SAFE_LABEL_POLICY_REF,CORRELATION_MAPPING_POLICY_REF,VISIBILITY_POLICY_REF,BODY_FREE_SCANNER_POLICY_REF}`；5 |
| stores | four `{MODE,BINDING_REF}` pairs + `TRANSACTION_TIMEOUT_MS` + `REQUIRED_SCHEMA_REVISION`；10 |
| idempotency | five exact `*_MS` leaves；5 |
| projection | six count leaves + `FRESHNESS_POLICY_REF`；7 |
| execution | `MAX_PARALLELISM`、`MAX_PLAN_ITEMS`、`JOB_TIMEOUT_MS`；3 |
| root external | five slots × `{MODE,BINDING_REF,CREDENTIAL_REF,CALL_TIMEOUT_MS}`；20 |
| entry loop | `OUTBOX_LOOP_CADENCE_MS`、`OUTBOX_LOOP_CANDIDATE_LIMIT`；2 |
| **Total** | **61 exact keys** |

Schema/source/operation sets、digest set、claim/retry object、capability array、all target/Consumer/schedule catalogs与
enabled sets明确没有 ENV 入口。Namespace内任何旧 alias、拼写错误、catalog index、set fragment或大小写变体均拒绝
whole candidate；无关 namespace 的变量忽略。

### 5.2 Source 冲突与历史规则

| 场景 | Current disposition |
|---|---|
| high-priority winner非法 | reject candidate；no lower-source fallback |
| JSON duplicate、canonical+alias、unknown key | reject ambiguous/unknown |
| ENV key不在61项registry | reject candidate |
| required/conditional field missing | reject；不补binary/provider/first-item/default |
| raw secret/body进入file/env | security VETO；不“脱敏后继续” |
| enabled mapping缺target/phase或duplicate subject | totality/capability failure before exposure |
| old Job/effect binding不可解析 | retain old material；manual/unavailable；no current/prior default route |
| remote/admin/CLI field/multi-file/include/hot source | unsupported；需要时先回设计 |

### 7.1 Raw schema 与命名

| Rule | Current contract |
|---|---|
| local root | exact `profile` + `technical/boundary/safety/stores/digest/idempotency/projection/execution/external/entries`；不重复项目名前缀 |
| field | lowercase `snake_case`；duration raw key以`_ms`结尾；不接受camelCase、旧key或alias |
| enum | exact lowercase token；unknown/case-fold/trim/numeric/`Other`/first-default拒绝 |
| ref/locator | non-empty opaque string；不得从prefix推owner/endpoint/topic/path/credential/body |
| optional ref | key必须出现且值为exact string或`null`；missing != null；empty不表示clear |
| set/catalog | JSON array；typed canonical order；input duplicate拒绝；catalog按formal subject key判重 |
| object | strict exact object；unknown/duplicate child拒绝；无`extra`/properties bucket |
| derived | `config_ref`、entry slice、safe catalog、Job snapshot不进入raw JSON |

下文简写：`N` ordinary、`R` ref-sensitive、`S-L` sensitive locator；`A` assembly、`E` entry-derived、`J` Job
snapshot、`H` historical effect。除明确声明外，baseline不是default。

| `boundary.default_page_limit` | 50 | 1..200 | items | `<= max_page_limit` |
| `boundary.max_page_limit` | 200 | 1..1000 | items | request只可收窄 |
| `boundary.query_read_timeout_ms` | 5000 | 100..30000 | ms | timeout unavailable；zero write |

## 8. 敏感配置与密钥管理

> 校准来源:
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读:
> - 三层 ownership、Step07 敏感配置总表、provider bootstrap、rotation/historical binding、禁止输出与停审/VETO。

本项目把配置中的 opaque reference 与实际 secret/material 严格分层。普通配置只承载经过 typed
constructor 验证的 reference/locator；解析出的 provider response、credential、endpoint、topic、DSN、
policy body 和证书私钥只允许在 infra/adapter 私有边界短暂存在。它们不是配置 identity，也不是业务、
Job、outbox、trace、report 或 evidence 的输入。

### 8.1 敏感级别与 ownership

| 级别 | Current 含义 | 可进入 validated root | 解析与输出规则 |
|---|---|---|---|
| `internal` | numeric、finite token、timeout、limit 等内部参数 | 是 | 可供受权 constructor 使用；不得整体 dump root |
| `sensitive` | binding、policy、target 或 transport 的 opaque identity | 是，typed ref | 只输出有限 family/phase/config ref；不得输出完整 ref 或其 fingerprint |
| `secret` | raw token、password、private key、certificate key、DSN、endpoint、provider material | 否 | 仅 concrete adapter 私有内存；不得写入配置、日志、持久化或证据 |

Step07 的 `R` 表示 sensitive typed reference，`S-L` 表示 sensitive locator，二者都不等同于 secret
material；`mixed` 对 nested leaf 分别判定。Application、domain、contract、entry 和 Job snapshot 只接收
已批准的 body-free projection。

| Ownership 层 | 持有内容 | 明确不得持有 / 执行 |
|---|---|---|
| `infra::config` candidate | source winner、typed ref、finite parameters、catalog | raw secret、provider response、业务正文、隐式 provider default |
| infra binding registry | immutable descriptor、family/mode/capability、opaque historical ref | 将 descriptor 重绑定到另一 target；向 application 暴露 locator |
| adapter-private handle | 调用所需最小 material/handle | `Debug`/`Serialize` 扩散、clone 到 service、进入 snapshot/log/report |
| safe application projection | finite operation、family、timeout、safe binding identity | endpoint、topic、credential、transport locator、provider body |
| durable execution/effect record | formal safe snapshot、effect binding、token/body-free digest | current config fallback、secret、locator、source truth 重建 |

### 8.2 Sensitive resolution chain

```text
DECL / strict JSON / allowlisted ENV opaque ref
  -> typed candidate + source/profile/redline validation
  -> body-free ConfigBindingRef
  -> owner-specific private descriptor / locator resolution
  -> adapter-private material handle
  -> complete runtime or one safe assembly error
```

Provider result 不参加 source priority，不得改变 mode、family、target、schema、capability、timeout、actor、
redaction 或 truth owner。`Disabled` 只有在 binding 与 credential 均为 null 且该 family 允许 optional 时才跳过
resolution；`Fake` 不接受 credential；`RuntimeLike` 不允许 `InMemory`、`Fake`、`Controlled`、`Fixed` 或
`Deterministic` 作为替代路径。

### 8.3 敏感配置族与安全处理

| 配置族 | 级别 | 普通存储 | private resolution | 轮换 / historical 规则 | 失败与审计 |
|---|---|---|---|---|---|
| `technical.clock_binding_ref` | sensitive | opaque adapter ref/null | clock registry | new assembly；old request 随 old runtime drain | safe field/family/config ref；missing fail |
| `technical.id_generator_binding_ref` | sensitive | opaque adapter ref/null | ID registry | new assembly；不改既有 object identity | safe issue；constructor fail |
| five `safety.*_policy_ref` | sensitive | policy ref | policy registry | new assembly；不热换 safety policy | unresolved fail closed |
| four `stores.*.binding_ref` | sensitive locator | store ref/null | store resolver/constructor | destination/schema 改变属于 migration class | capability/schema/UoW mismatch fail |
| `projection.freshness_policy_ref` | sensitive | policy ref | freshness registry | new assembly；Job freeze relevant setting | 不默认 Fresh |
| five root external `binding_ref` | sensitive | adapter ref/null | exact family registry | new binding revision；Disabled 只能显式 null | mode/family mismatch fail |
| five root external `credential_ref` | sensitive locator | credential ref/null | private credential resolver | overlap 未证明则 new binding | `SensitiveReferenceUnavailable` |
| outbound target catalog | mixed | strict typed catalog | effect + transport registry | old outbox pins old effect binding | duplicate/totality fail |
| report handoff catalog | mixed | strict typed catalog | consumer/effect/adapter registry | old intent pins preparation binding | no reroute/manual |
| peripheral export catalog | mixed | strict typed catalog | export registry | core 与 peripheral 隔离 | target unavailable 不污染 core |
| inbound Consumer catalog | mixed | strict typed catalog | transport + actor-policy registry | old accepted event 不重路由 | registration incomplete fail |
| Job schedule catalog | sensitive | schedule ref catalog | scheduler registry | 只影响 future trigger | 不补造 Job input |

表中 catalog family 展开到 27 个敏感 leaf/容器：technical 2、safety 5、store 1 family、freshness 1、
root adapter 2 families、outbound 3、handoff 3、export 3、Consumer 3、schedule 2。重复 slot 共享 schema
family，不得复制出第二套 raw key 或第二 owner。

### 8.4 Rotation 与 historical binding

| 变更情形 | Current 处理 | old work 行为 | 禁止 shortcut |
|---|---|---|---|
| policy ref 改变 | 新 ref、完整 candidate、redline 后 cold assembly | old runtime/Job 保持原 policy | 热改 policy、重判已提交 truth |
| store locator/schema 改变 | new assembly + schema/UoW/CAS/fence gate；必要时独立 migration | old rows/plan 不迁移解释 | fallback InMemory 或 current store 猜测 |
| credential-only rotation 且 target/idempotency namespace 不变 | 可保持 effect binding，但必须证明 overlap 与 old token 可 probe/finalize | old token 使用原 binding 与历史解析 | 原地改 adapter、提前删除 old material |
| target/route/topic 改变 | 新 effect binding、新 assembly | old outbox/intent/preparation 使用 old binding | current route fallback |
| provider namespace 改变 | 新 binding、新 token 规则 | old token 仍按旧 namespace 处理 | 复用 old token |
| old binding 无法解析 | stop before call，保留 durable identity，转 manual/unavailable | 不换 credential、target 或 token | 用 current config 猜恢复 |
| rollback | 对 prior semantic candidate 重新完整构建 | 不重写 durable work | 复用未经验证的 in-process LKG |

历史 registry 必须按 immutable binding identity 维护 descriptor 与恢复所需 opaque refs；registry revision 不得
原地重绑定到不同 destination/idempotency namespace。retire 前必须扫描 outbox、intent、preparation、Job plan、
terminal replay 和 manual/ambiguous obligation；仅凭时间、health 或 config activation 不得退役。

### 8.5 禁止输出与审计

| 输出面 | 允许 | 禁止 |
|---|---|---|
| log / error | finite phase、error kind、family、safe issue、必要 config ref | raw value、path/env、完整 locator、secret、provider cause |
| metric | low-cardinality family/result/count/duration | 任意 ref、endpoint、topic、actor、secret hash |
| trace | operation/family/phase/status、correlation context | config dump、provider body、credential/route |
| audit projection | 已有 formal safe identity 与变更类别 | generic secret-read ledger、raw diff、fingerprint |
| Job snapshot / outbox / intent | safe config subset、effect binding、token/body-free digest | locator、material、current fallback |
| report / evidence index | formal ref、purpose、safe issue、candidate status | evidence/artifact body、真实 alias、verdict/signoff |

Enforcement 必须在 serialization 前完成 typed allowlist mapping。禁止内容不能通过 hash、digest、base64、
部分遮罩或 debug level 绕过；mapping 失败时抑制整组不安全字段，不触发递归自观测。

### 8.6 Failure 与 stop rules

raw material 出现在 JSON/ENV、typed ref malformed、required locator 缺失、private resolution unavailable、
descriptor/capability mismatch 或 catalog/entry 不完整时，candidate 失败且不暴露 partial runtime。已装配后的
dependency `Unavailable` 是 availability 事实，不是 source fallback；external outcome `Unknown` 必须保留
原 intent/token 并 probe/manual，不能 blind retry 或换 route。配置失败不得写 ObservationReceipt、EvidenceLinkage、
RetentionMarker、ReportHandoff、Gap、NoWriteViolation 或任何 upstream source truth。

## 9. 配置加载、校验与生效机制

> 校准来源:
> - `design-calibration/04_config_step_09_loading_validation_activation.md`
>
> 延伸阅读:
> - exact ENV registry、VAL-S01~S13、23 域加载表、13-stage assembly、safe projection 与 activation boundary。

### 9.1 加载与 source snapshot

`infra::config` 是唯一 ordinary source reader，优先级固定为 `DECL < one strict JSON < 61 allowlisted ENV`。
JSON 与 ENV 先形成各自 immutable snapshot，再按 canonical registry 选择 winner。高优先级 winner 非法时拒绝整个
candidate，不回退低层值。当前不支持 JSONC、multi-file/include、remote/config-center、admin/CLI override、
watch、reload、hot update、in-place swap 或 automatic LKG。

### 9.2 校验顺序与错误边界

| 校验阶段 | 主要检查 | 成功产物 | 失败策略 |
|---|---|---|---|
| `VAL-S01` source capture | source 可读、snapshot coherent | captured source | `ConfigSourceUnavailable` |
| `VAL-S02` syntax/shape | strict UTF-8、object shape、size/depth ceiling、exact namespace | structural occurrences | `InvalidConfiguration` |
| `VAL-S03` leaf decode | primitive/enum/ref/null/object/array type、width、range | typed leaves | `InvalidConfiguration` |
| `VAL-S04` requiredness | required/conditional required、null/value组合、cardinality | complete candidate | `InvalidConfiguration` |
| `VAL-S05` canonical set | finite operation/schema/producer/catalog totality | canonical candidate | `InvalidConfiguration`/`EntryBindingIncomplete` |
| `VAL-S06` cross-field | windows、lease、retry、target、store、profile关系 | compatible candidate | `InvalidConfiguration` |
| `VAL-S07` profile | runtime class 与 mode/lane compatibility | profile-compatible candidate | `InvalidConfiguration` |
| `VAL-S08` redline | 24 configuration redlines与10 VETO | redline-compatible candidate | `InvalidConfiguration` |
| `VAL-S09` identity | body-free whole-candidate `ConfigBindingRef` | validated root + ref | `InvalidConfiguration` |
| `VAL-S10` sensitive resolution | owner-specific private refs/material | private registry | `SensitiveReferenceUnavailable` |
| `VAL-S11` store qualification | schema、atomic UoW、CAS、fence、claim | qualified stores | `StoreCompatibilityMismatch`/`RequiredCapabilityMissing` |
| `VAL-S12` adapter qualification | family/mode/phase/token/probe descriptor | private adapter registry | `AdapterConstructionFailed`/`RequiredCapabilityMissing` |
| `VAL-S13` exposure totality | façades、catalog、safe slices、registrars、entry group atomicity | complete runtime | `EntryBindingIncomplete` |

### 9.3 13-stage complete-or-error assembly

| Stage | Owner | 输出 | 暴露前停止条件 |
|---:|---|---|---|
| 1 | loader | R0/R1/R2 coherent snapshots | source failure；无 adapter |
| 2 | parser | typed candidate | parse/type/range failure；丢弃 candidate |
| 3 | validator | profile/redline-compatible candidate | whole-candidate reject |
| 4 | identity | `ValidatedObservabilityConfig` + `ConfigBindingRef` | identity failure；不解析 material |
| 5 | private resolvers | candidate-scoped private registry | required ref unavailable；reverse cleanup |
| 6 | store builder | qualified store/UoW descriptors | schema/atomicity/CAS/fence mismatch |
| 7 | technical builder | clock/ID/digest/policy factories | constructor failure；不泄露 handle |
| 8 | external/entry builder | adapter descriptors、private slots | mode/family/phase/capability mismatch |
| 9 | availability builder | body-free availability probe | health 不改变 config/truth |
| 10 | application composition | five façades + context factory | invariant failure；不暴露 partial façade |
| 11 | runtime builder | API、locator-free worker/jobs slices、two registrars | metadata/permission不一致 |
| 12 | runtime builder | one `BuiltObservabilityRuntime` | success 仅表示 wiring ready |
| 13 | entry root | static routes、opaque registration sets | prepare-all -> totality -> arm-all；失败 revoke/join all |

Worker/jobs 不接收 raw root、locator、private registry、repository、UoW 或 concrete adapter；registrar 是 one-assembly
least-authority capability。任何 entry group 不完整都使本次 composition 失败，不允许先开放其他 route。

### 9.4 生效与历史绑定

builder 成功只表示 new immutable runtime eligible for new work，不自动切换、drain、rollback、retire 或写审计。
accepted Job 在 start UoW 冻结 relevant `JobExecutionConfigSnapshot`；old Job/outbox/intent/preparation 只读存储的
snapshot/effect binding/token。历史 binding 缺失时在 external call 前 stop，保留 manual/unavailable，不读 current
config fallback。

## 10. 配置变更、审计与回滚

> 校准来源:
> - `design-calibration/04_config_step_10_change_audit_rollback.md`
>
> 延伸阅读:
> - CFG-CHG-01~12、职责分离、cold activation、safe audit、rollback 与 historical retirement。

### 10.1 变更分类与风险

| Class | 配置族 / 生命周期对象 | 基础风险 | 评审重点 | 生效边界 |
|---|---|---|---|---|
| `CFG-CHG-01` | profile/technical | medium；binding high | runtime/entry/safety | protected candidate + cold activation |
| `CFG-CHG-02` | boundary/projection limits | low/medium；schema high | entry/compatibility | new request/Job only |
| `CFG-CHG-03` | safety/policy/visibility | high | safety owner；禁止放宽 redline | new assembly/new work |
| `CFG-CHG-04` | store/transaction/schema | medium/critical | UoW、CAS、migration | compatible cold；migration separate |
| `CFG-CHG-05` | digest/retention/idempotency | high/critical | readable profile、active reference | new material；old obligation pinned |
| `CFG-CHG-06` | execution/claim/retry | medium/high | fence、recovery、budget | new assembly/Job snapshot |
| `CFG-CHG-07` | resolver/external adapter | high/critical | phase、capability、history | exact binding；no reroute |
| `CFG-CHG-08` | event/handoff/export catalogs | high/critical | subject totality、old token | whole catalog + pinned old work |
| `CFG-CHG-09` | API/Consumer/Job/schedule entries | high | static map、registrar atomicity | new entry composition |
| `CFG-CHG-10` | credential-only rotation | high/critical | overlap、same-ref recoverability | fresh assembly；no in-place mutation |
| `CFG-CHG-11` | activation/rollback lifecycle | max candidate risk | approval、drain、ownership | four-class host protocol |
| `CFG-CHG-12` | historical binding retirement | high | obligation scan、manual cases | only after retirement gate |

One candidate may hit multiple classes, but remains one protected approval and activation attempt. High-risk catalog/binding
changes cannot be split into low-risk scalar tickets.

### 10.2 职责分离与审计字段

| 角色 | 可执行职责 | 不可兼任 / 不得产生 |
|---|---|---|
| `A01` change requester | 提交 semantic candidate/ref | 不得单独批准或切换 owner |
| `A03` config reviewer | schema/profile/redline/identity review | 不得替代 safety/data/history reviewer |
| safety/data/integration reviewers | 各自 specialty review | 不得修改别的 owner truth |
| `A05` approval authority | approve one protected candidate | 不得跳过 VETO/affected gate |
| `A06` activation authority | prepare/switch/drain/reconcile | 不得把 ready 当 activated |
| `A09` retirement authority | obligation scan 后移除 old resolution | 不得凭时间/health退役 |

安全审计只允许记录 change/config/issue ref、canonical field/family、finite subject/phase、direction、validation、
activation/drain/rollback/obligation result 与 bounded counts。禁止 raw diff、完整 locator/ref、fingerprint、provider
body、业务 payload、evidence body、verdict 或 signoff。本文不新增 business config-audit schema。

### 10.3 Cold activation、rollback 与 durable work

```text
protected candidate -> complete validation/assembly -> approval
  -> ownership precondition -> switch -> drain/reconcile
  -> activation result / rollback or manual disposition
```

候选失败时旧 runtime 不变；切换前失败只 reject/abort；切换后 rollback 必须以 prior semantic candidate 重新完整
构建并再次经过审批和 capability gate。`Unknown` 先 reconcile，不得 pointer flip、自动 LKG 或声称 rollback 成功。
accepted request、Job、outbox、intent、plan、preparation、result、report 均保留原 snapshot/binding/token，不被
current config、new route 或新 credential 重写。

### 10.4 Historical retirement gate

只有 outbox publication、handoff preparation/delivery、export、Job plan、terminal replay 及 manual/ambiguous
obligation 均完成 authoritative scan，且 old reader/binding 已不再需要，才允许 retire。扫描缺失、结果未知、old
binding unavailable 或 retention hold 存在时保持 old resolution 并转 manual；retirement 不是 config rollback。

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源:
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读:
> - CFG-FAIL-01~25、七类 startup error、四类 availability、lifecycle handoff 与 affected failure register。

### 11.1 Startup error 分类

| Error class | 适用阶段 | 处理 |
|---|---|---|
| `ConfigSourceUnavailable` | source capture | candidate 不存在；old lifecycle 不变 |
| `InvalidConfiguration` | parse/type/required/cross/profile/redline | reject whole candidate；不 fallback |
| `SensitiveReferenceUnavailable` | selected private resolution | fail closed；不输出 material |
| `StoreCompatibilityMismatch` | store/schema/UoW/CAS/fence | 不暴露 runtime；不以 InMemory 替代 |
| `AdapterConstructionFailed` | family constructor | 清理 partial private handles；不改 target |
| `RequiredCapabilityMissing` | capability/phase/token/probe | affected surface 不暴露；不相信 config 自述 |
| `EntryBindingIncomplete` | catalog/registrar/entry atomicity | revoke/join all；zero partial active root |

### 11.2 Availability 语义

| 语义 | 含义 | 可否当成功 |
|---|---|---|
| `Disabled` | 显式未启用且配置满足 null/optional 规则 | 否；仅表示没有该 surface |
| `Unavailable` | 已配置但当前依赖不可用 | 否；请求返回 typed unavailable |
| `Misconfigured` | 声明与 descriptor/能力事实冲突 | 否；通常启动失败 |
| `Degraded` | formal 允许的受限能力 | 否；不得扩大到别的 target |

### 11.3 Failure register

| ID | 触发 | 必须行为 | 禁止行为 |
|---|---|---|---|
| `CFG-FAIL-01` | source 不可读/不一致 | fail-fast `ConfigSourceUnavailable` | partial source |
| `CFG-FAIL-02` | unknown/duplicate/alias | `InvalidConfiguration` | ignore/last-wins |
| `CFG-FAIL-03` | required 缺失 | reject | default/fake 补齐 |
| `CFG-FAIL-04` | type/range/overflow | reject | clamp/truncate |
| `CFG-FAIL-05` | cross/profile/redline | reject whole candidate | lower-source fallback |
| `CFG-FAIL-06` | identity drift/collision | no exposure | fingerprint代替 identity |
| `CFG-FAIL-07` | locator unavailable | safe private error | old cache/another target |
| `CFG-FAIL-08` | store atomicity/CAS/fence不足 | capability fail | process mutex/InMemory |
| `CFG-FAIL-09` | adapter descriptor mismatch | exact constructor/capability error | trust config claim |
| `CFG-FAIL-10` | enabled catalog duplicate/missing | entry fail-fast | first-call failure |
| `CFG-FAIL-11` | Consumer producer/schema incomplete | keep slot disabled | broad subscription |
| `CFG-FAIL-12` | registrar prepare/arm Nth failure | revoke/join all | partial active root |
| `CFG-FAIL-13` | optional explicit Disabled | typed Disabled | fake/no-op success |
| `CFG-FAIL-14` | post-assembly dependency unavailable | typed Unavailable/Degraded | source fallback |
| `CFG-FAIL-15` | commit outcome unknown | probe stored result/manual | ack success猜测 |
| `CFG-FAIL-16` | external outcome unknown/unsupported | retain intent/token，probe/manual | blind retry/new token |
| `CFG-FAIL-17` | activation ownership unknown | stop/reconcile | 写 activated |
| `CFG-FAIL-18` | drain timeout/unknown | preserve disposition | kill并称 rollback |
| `CFG-FAIL-19` | historical binding missing | stop before call/manual | current route fallback |
| `CFG-FAIL-20` | migration closure missing | block activation | silent dual interpretation |
| `CFG-FAIL-21` | active obligation blocks retirement | retain old reader | date/health-only retire |
| `CFG-FAIL-22` | prior candidate unavailable | rollback blocked/manual | unvalidated LKG |
| `CFG-FAIL-23` | authoritative change audit unavailable | stop before ownership mutation | unaudited switch |
| `CFG-FAIL-24` | telemetry sink failure/recursion | suppress recursion; outcome unchanged | telemetry drives retry/truth |
| `CFG-FAIL-25` | target/reality not established | boundary blocked/not evaluated | design claims ready |

### 11.4 Lifecycle handoff

任何 failure 只生成有限 phase/error/family/safe issue 诊断，不生成 business row、run/evidence identity、acceptance
result 或 signoff。Query 严格 no-write；rebuild、report、export、retention 与 audit projection 不得修复或反写 source
truth。12 项 affected 继续保持开放，failure policy 不替代其 owner/schema/UoW/flow closure。

### 13.2 普通字段演进

| 演进类 | 必须固定 | 关闭条件 |
|---|---|---|
| additive optional field | canonical path/type、absence semantics、identity | parser/fixture/consumer coverage |
| additive required field | producer/default/compatibility window | all sources and profiles provide it |
| rename | old/new mapping and ambiguity | dual-read audit then old reject |
| type widening | accepted representation and range | old values revalidated |
| enum add | unknown handling and owner | all finite consumers updated |

| nested shape change | whole-object replacement rule | no partial merge ambiguity |

### 13.3 Durable migration classes与义务

| Durable class | 迁移顺序 | 退役前义务 |
|---|---|---|
| schema/store revision | old reader -> inventory -> new reader -> switch-write | rows/plan/result/outbox compatible and scanned |
| digest write profile | retain old readable -> dual-read -> new write | old digest replay/verification closed |
| effect binding/target | retain old resolver -> new binding for new work | outbox/intent/preparation ambiguity zero |
| credential/provider revision | overlap old material -> fresh assembly -> new resolution | old token probe/finalize path retained |
| schedule/entry registration | new assembly/register -> old admission drain | accepted event/Job not reconsumed |
| report/evidence reference schema | retain reader -> new index projection | historical report/replay obligations closed |

所有 migration 都遵循 `inventory -> preserve old -> introduce new -> switch new work -> reconcile -> retire`；不改写
old snapshot、outbox、intent、plan、token、result、report 或 source truth。七类 obligation 为 pending outbox、handoff
preparation、handoff delivery、export delivery、nonterminal Job、terminal replay、manual/ambiguous recovery。

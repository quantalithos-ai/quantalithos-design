# L4-observability 03-详细设计 Step 09 · 60 项协议 exact-flow cards

> 本文件是 Step 09 的 current authoritative supplement。
> 它覆盖 Step 08 的 `C01-C16`、`Q01-Q14`、`I01-I09`、`E01-E12`、`J01-J09` 共 60 项协议。
> `03_ddd_step_09_function_flows.md` 中的共享模板只描述共性顺序；本文件的逐协议卡决定具体入口、owner、port、结果和边界。
> `defined_with_affected_open` 仅表示设计记录与后续 owner 路由存在，不表示代码、运行、测试或验收完成。

## 1. 使用规则

每张卡必须同时满足以下条件：

- `Step 08` 的协议名、DTO/Envelope/Job input 与入口 callable 一一对应。
- `Step 06` 的对象、状态或 record 是唯一 domain owner；Step 07 的 port 是唯一调用面。
- Mutation flow 明确 reserve、load/guard、domain decision、write set、cursor、history、outbox/stale、stored result、completion、commit 顺序。
- Query flow 明确只读输入、same-committed-boundary 读取、visibility/freshness/missing/degraded 映射和 zero-write。
- Consumer flow 明确 header-before-payload、source-version/duplicate 分支、local landing 和 worker action 不混淆。
- Event flow 只从 accepted local UoW 的 typed committed snapshot 产生；publisher 不重建 current truth。
- Job flow 明确 immutable plan、claim/fence、item UoW、report fold、external phase 和 exact replay。
- 未决 owner/上游能力以 `affected` 保留；不使用默认值、first-row、字符串解析或 generic fallback 补齐。

## 2. 固定调用顺序

### 2.1 Mutation protocol

```text
[typed entry]
  -> [operation-specific assembler]
  -> [operation context + digest candidates]
  -> [atomic idempotency reserve]
  -> [owned read + policy/source-version guard]
  -> [domain factory/transition]
  -> [same-UoW truth/marker + history]
  -> [assign tagged cursor]
  -> [projection membership/stale + immutable event snapshot]
  -> [stored result]
  -> [reservation completion]
  -> [commit]
```

`Replay`、`Conflict`、`InFlight` 在 domain/service effect 前返回。`CommitOutcomeUnknown` 不产生新的 mutation；先 probe 原 reservation/result/marker。

### 2.2 Query protocol

```text
[typed query entry]
  -> [query assembler + zero-key context]
  -> [least-authority committed read facet]
  -> [relation/version/presence validation]
  -> [P11 visibility + freshness/degraded mapping]
  -> [response surface]
```

Query 不创建 UoW、reservation、stored result、history、outbox、gap、refresh、rebuild 或 read-audit record。

### 2.3 Consumer protocol

```text
[worker callback]
  -> [header/schema/producer validation]
  -> [typed payload decode]
  -> [atomic reservation + source-event uniqueness]
  -> [source-version comparator]
  -> [local observation landing]
  -> [typed local event snapshot/stale marker]
  -> [stored receipt/result + completion]
  -> [commit]
  -> [exact worker action mapper]
```

Worker action (`Acknowledge`/`Retry`/`DeadLetter`) 不是 application outcome。Commit probe 仍 indeterminate 时不得 wildcard 选择 action。

### 2.4 Event protocol

```text
[accepted local transition]
  -> [typed event encoder for exact event name]
  -> [immutable payload snapshot + historical binding ref]
  -> [outbox append in source UoW]
  -> [J01 claim]
  -> [publish stored bytes]
  -> [CAS publication marker]
```

Event producer 不读取 query view、current route 或下游 truth 重建 bytes。

### 2.5 Job protocol

```text
[job entry + immutable input]
  -> [operation reservation]
  -> [plan/config/binding snapshot + Draft report]
  -> [claim work key + fencing token]
  -> [item read/guard/effect]
  -> [item result/report fold under fence]
  -> [finalize stored report/result]
  -> [complete reservation]
```

J06 在 `R06.6-F2-H13-UPSTREAM` 未关闭时只能形成 controlled blocked coordination；J07/J08 的 preparation、delivery、feedback 不能合并。

# L5-chat 原型主路径记录

> 阶段：P2 主路径原型
> 状态：`completed_for_prototype`
> 日期：2026-09-30

## 1. 协作入口路径

```text
对话
  -> 最近对话
      -> group / channel
      -> dm
      -> 受限入口
      -> thread 快捷入口
```

原型通过左侧最近对话和线程区域提供入口。当前语境、可见状态和来源状态在对话头部持续显示。受限入口不展示旧缓存正文。

## 2. 对话与 thread 路径

```text
群聊
  -> 消息时间线
      -> 回复
      -> 查看 thread
          -> thread 时间线
          -> 返回原对话
```

已验证的展示行为：

- 回复目标显示在 composer 上下文中；
- thread 入口显示当前 thread 名称和来源对话；
- 返回对话时恢复对话语境；
- thread 与原对话使用不同标题和副标题；
- thread 不改变 Conversation owner 的正式状态。

## 3. 对话与绑定项目路径

```text
群聊顶部项目入口
  -> 项目详情
      -> 项目进度
          -> 整体流程
          -> 阶段子流程
```

项目详情的“关联群聊”标签可以返回项目下的其他群聊。一个项目可以显示多个群聊，但各群聊成员范围独立。

## 4. 项目路径

```text
项目
  -> 项目列表
      -> 选择项目
          -> 概览
          -> 项目进度
          -> 关联群聊
          -> 工作项
          -> 证据
```

项目进度路径支持：

```text
项目整体 BPMN
  -> 阶段节点
      -> 阶段工作流程图
          -> 工作流节点
              -> 节点详情
```

流程图中的并行结构支持点击分支查看安全摘要；分叉、汇聚和 Governance Gate 不提供本地编辑或审批操作。

## 5. 成员路径

```text
成员
  -> 公司级人员目录
      -> 筛选人员
      -> 直接对话入口
```

原型只展示安全成员摘要。公司成员目录不自动扩展为项目成员列表或所有群聊成员列表。

## 6. 路径状态检查

| 路径 | 原型结果 | 备注 |
|---|---|---|
| 最近对话 -> group/channel | 可走通 | 显示演示对话 |
| 最近对话 -> dm | 可走通 | 显示直接对话 |
| 对话 -> thread -> 返回 | 可走通 | 保持当前对话语境 |
| 对话 -> 绑定项目 | 可走通 | 进入项目进度标签 |
| 项目 -> 概览 / 进度 / 群聊 / 工作项 / 证据 | 可走通 | 标签切换为本地状态 |
| 项目进度 -> 阶段子流程 -> 节点详情 | 可走通 | 只读安全摘要 |
| 项目 -> 关联群聊 -> 对话 | 可走通 | 群聊成员范围独立 |
| 成员 -> 公司目录 -> 直接对话 | 可走通 | 正式可见性仍未接入 |
| 受限入口 -> 内容遮蔽 | 可走通 | 不从演示缓存恢复正文 |

## 7. 未在 P2 关闭的事项

- 正式路由和深链接格式尚未确定。
- 项目与群聊绑定的 owner 和 SDK query 尚未确定。
- 公司目录的正式权限过滤尚未确定。
- 页面刷新后的层级恢复尚未接入真实 store。
- P2 不验证 Gate、发送、Artifact 和恢复的终态交互；这些属于 P3/P4。

## 8. P2 结论

P2 主路径原型通过。协作入口、对话、thread、项目详情、项目流程下钻、关联群聊和公司成员目录均有可导航演示路径。下一阶段进入 P3 受控交互原型，专门审查草稿发送、GateCard 和 Artifact preview 的状态反馈。

# L5-chat 原型停审记录

> 阶段：P6 修订与停审
> 状态：`prototype_frozen_for_formal_design`
> 日期：2026-09-30

## 1. 停审范围

本轮 Desktop-first HTML 原型已完成以下体验验证：

- 对话、group / channel / dm / thread 入口；
- 草稿、回复、发送 pending 和未知结果；
- 项目列表与项目详情；
- 项目概览、项目进度、关联群聊、工作项、证据标签；
- 一个项目关联多个群聊；
- 群聊进入绑定项目，项目返回关联群聊；
- 公司级成员目录与直接对话入口；
- 项目整体 BPMN、阶段子流程和节点详情；
- 并行分叉、并行分支、并行汇聚和独立 Governance Gate；
- GateCard、Artifact preview、Runtime / Agent / 工具活动安全摘要；
- offline、stale、gap、revoke、restore、unknown；
- 键盘焦点、状态播报、drawer 返回和窄窗口布局。

## 2. P5 修订决定

P5 没有发现需要重做 HTML 页面结构的问题，因此 P6 不引入新的页面或状态。已确认的修订决定如下：

1. 项目与项目进度继续保持在同一项目详情容器中。
2. BPMN 并行分叉和并行汇聚使用独立节点。
3. Governance Gate 位于并行汇聚之后，不与 BPMN 网关合并。
4. 项目成员、群聊成员和公司成员目录继续分别表达。
5. 流程、工作项、执行活动、Artifact 和测试只显示安全摘要。
6. pending、confirmed、rejected、failed、unknown、stale、restricted 等状态不互相替代。

## 4. 原型边界与证据声明

- HTML 原型不连接 SDK、服务 API、内部 bus 或 owner 系统。
- 原型数据是虚构数据，不是用户、项目、群聊、成员、Gate、Artifact 或 Runtime 真相。
- 原型交互不是测试、验收、集成、性能、可访问性或 readiness 证据。
- 原型中的节点坐标、CSS、文案和演示状态不构成生产 schema、DTO、路由或 SDK 方法。
- 原型没有实现真实缓存、离线队列、授权、文件下载、跨端同步或正式恢复。
- 未创建实现代码、commit、run、report、artifact 或正式验收结果。

## 5. 停审结论

本轮原型已冻结，状态为 `prototype_frozen_for_formal_design`。后续只可将已确认的交互决定作为正式需求和架构讨论输入；正式文档必须重新按其各自 SOP、calibration flow、Step 中间产物和三层门禁执行。未经新的用户授权，不进入正式 `00`，也不进入 `01`～`07`。

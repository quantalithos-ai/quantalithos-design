# L5-chat 原型受控交互记录

> 阶段：P3 受控交互原型
> 状态：`completed_for_prototype`
> 日期：2026-09-30

## 1. 草稿与发送

```text
编辑本地草稿
  -> 本地校验
  -> 发起演示发送
  -> pending
      -> confirmed / rejected / failed / unknown
```

原型行为：

- 草稿只保留在当前页面；
- 发送后先追加本地演示消息并标记 `pending`；
- 用户可以切换演示结果姿态；
- `unknown` 明确提示只能探测、等待或由用户决定；
- 不会因为消息出现在时间线、toast 或界面连接恢复而显示为正式发送成功；
- 受限语境禁止模拟发送。

## 2. GateCard

```text
查看 GateCard
  -> 查看安全摘要
  -> 发起演示操作
  -> 等待演示结果
      -> 已确认 / 已拒绝 / 失败 / 未知
```

原型行为：

- Gate 来源标记为治理安全摘要；
- 点击操作后先显示等待结果；
- confirmed 只标记为“演示结果”，不表示正式审批成功；
- rejected、failed、unknown 各自有独立标签和说明；
- unknown 不自动重发；
- 关闭抽屉、toast、按钮点击和网络反馈不改变正式治理状态。

## 3. Artifact preview

```text
Artifact 引用
  -> 安全预览
      -> available
      -> restricted
      -> stale
      -> unavailable
```

原型行为：

- 只展示 Artifact 引用和预览状态；
- available 只显示占位预览，不加载真实正文；
- restricted 隐藏正文并解释遮蔽原因；
- stale 显示需要重新验证，不标记为最新；
- unavailable 不生成替代正文、下载地址或版本信息；
- Artifact owner 仍拥有正文、版本链和访问资格。

## 4. 状态区分

| 交互 | 本地姿态 | owner 结果 | 原型表达 |
|---|---|---|---|
| 发送 | editing / pending | confirmed / rejected / failed / unknown | composer 状态与消息标签分开 |
| Gate 操作 | not_started / pending | confirmed / rejected / failed / unknown | Gate 抽屉状态与卡片状态同步为演示值 |
| Artifact | opening / viewing | available / restricted / stale / unavailable | 预览面板状态，不推断权限 |

## 5. 受控边界审查

- pending 不表示业务提交已经成功。
- confirmed 仅为本地演示结果，不是治理或 Conversation owner 的确认。
- unknown 不自动重放、重发或升级为失败/成功。
- Artifact 预览状态不等价于 Artifact 权限判断。
- 客户端不直接调用内部 bus，不读取原始工具参数或凭证。
- 所有结果均标记为演示，未生成测试、运行或验收证据。

## 6. P3 结论

P3 受控交互原型通过。草稿发送、GateCard 和 Artifact preview 的主要状态分支已能在 HTML 原型中切换和观察，且本地交互与正式 owner 结果保持分离。下一阶段进入 P4 恢复与可访问性原型。

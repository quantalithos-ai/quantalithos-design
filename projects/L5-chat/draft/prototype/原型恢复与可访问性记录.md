# L5-chat 原型恢复与可访问性记录

> 阶段：P4 恢复与可访问性
> 状态：`completed_for_prototype`
> 日期：2026-09-30

## 1. 连续性状态路径

```text
正常展示
  -> offline / stale
  -> gap / unknown
  -> reconnecting / resuming
  -> 重新验证
      -> fresh / partial / restricted / blocked / needs_action
```

原型通过恢复卡片、顶部 notice、恢复抽屉和时间线遮蔽表达不同姿态。重新验证只表示发起演示查询，不把连接恢复或页面刷新当作业务结果确认。

## 2. 恢复分支

| 分支 | 页面表达 | 安全要求 |
|---|---|---|
| offline | 内容需验证、操作结果保持未知 | 不把本地材料标记为最新 |
| gap | 时间线暂停变化应用 | 不自行补齐缺失事件 |
| revoke | 当前正文、引用和卡片遮蔽 | 不从本地缓存恢复隐藏内容 |
| restore | 等待正式验证 | 不自动升级为 fresh 或授权成功 |
| unknown attempt | 探测、等待或用户决定 | 不自动重放或重发 |

## 3. 焦点与语义

- 对话时间线使用语义区域和 `aria-label`。
- 状态 notice 使用 `role=status` 和 `aria-live`。
- Drawer 使用对话框语义，打开时保存前一焦点，关闭后尝试恢复。
- 关闭按钮、返回按钮和受限恢复入口均有可访问名称。
- 流程节点使用按钮语义和状态 `aria-label`，允许键盘聚焦和触发。
- 项目、成员和群聊条目使用按钮语义，不依赖鼠标悬停才能发现入口。
- 状态颜色同时配合文字标签，不单独依赖颜色表达状态。

## 4. 窄窗口行为

- 桌面三栏在较窄窗口收缩为主内容和可打开导航。
- 右侧 inspector 在窄窗口隐藏，详情通过 drawer 访问。
- 项目列表和成员列表在窄窗口隐藏非核心列，保留名称和状态。
- 流程画布保留横向滚动，避免节点尺寸随内容漂移。
- drawer 和 toast 使用视口约束，避免遮蔽操作文本。
- `prefers-reduced-motion` 下减少过渡效果。

## 5. 仍待生产验证的内容

- 真实键盘焦点顺序和焦点陷阱。
- 屏幕阅读器对 SVG / 流程连线和并行网关的完整朗读。
- 真实 SDK 重连、cursor gap、snapshot rebuild 和 revoked 语义。
- 多端同时修改草稿、项目选择和流程位置时的恢复规则。
- 真实权限变化时项目、群聊、成员和 Artifact 的遮蔽时序。

## 6. P4 结论

P4 原型覆盖通过。当前 HTML 版本可以演示离线、gap、撤销、重新验证、未知结果、焦点返回、状态播报和窄窗口布局。它不构成生产恢复实现、可访问性验收或跨端同步证据。下一阶段进入 P5 逐路径评审。

## 3. 配置控制面总览

> 校准来源：
> - `design-calibration/04_config_step_03_control_plane.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置来源链图”“配置控制面总表”“配置域 / 功能模块总表”“域内停审记录”和“跨控制面审计”小节。

#### 配置来源链图: L5-runner 配置汇流与装配链

```text
[static schema / forbidden declarations / safe optional defaults]
                              +
          [one selected external strict JSON document]
                              |
                              v
         [source snapshot -> strict parse -> validation]
                              |
                              v
              [immutable validated snapshot]
                              |
                              v
 [stores/UoW -> adapter registry -> clock/id/digest -> policies]
                              |
                              v
     [RunnerRuntimeConfig + builder capability markers]
                              |
                              v
          [facade + entry + worker + operations]
```

关键说明：

- 图表达配置来源和逻辑装配顺序，不表达文件挂载、env 名、CLI 参数、SDK 方法、数据库或平台拓扑。
- selector 只选择一份完整文档，不是叶级值源；raw secret/material 不进入普通来源链。
- builder `Ready` 只表示本地组合可以安全暴露 fail-closed surface；每个 external slot 仍独立判定 configured/enabled/ready。
- 业务调用仍需当次满足 authority、basis、generation、guard 和 owner safe read；配置校验不能替代。

| 控制面 | 作用 | 允许读取/装配层 | 是否 P0 | 不控制什么 |
|---|---|---|---:|---|
| source/schema | 选定完整文档、生成 source snapshot、严格解析和校验 | `infra/config` | 是 | deployment mechanism、artifact approval |
| runtime/profile | 固定 schema/profile/config identity 和 assembly posture | `infra/config`、runtime builder | 是 | environment 名称、readiness、owner truth |
| local stores/cache | 绑定 state/projection/result/operation/material cache logical capability | runtime builder、infra adapters | 是 | backend、DSN/path、durability 事实 |
| external/platform bindings | 将 closed slot 关联 opaque ref，形成 per-slot marker | adapter registry、entry/worker readiness gate | 是 | endpoint、SDK method、private implementation |
| bounded policies | 提供 body/page/embedded/Job/idempotency 有界策略 | builder、entry、operations | 是 | safety cap 放宽、Unknown replay |
| observability/redaction | 绑定 mandatory redaction 与 optional diagnostic/handoff/telemetry | builder、safe presentation/handoff | 是 | formal audit/evidence、raw log fallback |
| determinism | 绑定 clock/connectivity、ID、canonical digest 和 test fixture | builder、test harness | 是 | ad hoc PID/path/time/hash identity |
| peripheral features | 请求 presentation/diagnosis/handoff/archive 外围能力 | builder、entry/operations | 是 | owner mutation、planned Consumer、core success |

Raw config 的唯一解析者是 `infra/config`；runtime builder 只接 validated snapshot。`entry`、`worker` 和 `operations` 只读取边界视图或冻结后的 typed policy。`application` 只接 typed ports/policies，`domain` 与 `contracts` 不持有 config handle，也不重新 parse。

配置绝不拥有或修改 Release/Artifact truth、Governance approval/baseline、Project/Work truth、Sandbox execution/isolation、Runtime outcome、Observability evidence/audit 或 Archive truth。`configured != enabled != ready` 是所有七域的共同不变量。

## 4. 配置分类与边界

> 校准来源：
> - `design-calibration/04_config_step_04_categories_boundaries.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置类别表”“生效方式矩阵”“按配置域组织的分类边界”“禁止配置化项表（VETO）”和“跨分类审计”小节。

| 配置类别 | 说明 | 示例 | 是否允许热更新 | 主要风险 |
|---|---|---|---:|---|
| `static_design_boundary` | schema、requiredness、hard safety cap 和不可配置不变量 | closed profile/slot、no-write、no-replay | 不适用 | 被外部值放宽会绕过设计 |
| `startup_assembly` | bootstrap 前冻结的 profile、refs、limits 和 feature posture | store/binding/redaction/provider refs | 否 | 半装配、旧新 snapshot 混用 |
| `entry_local_selector` | 只选择当前入口的一份完整文档/profile | source selector | 不属于 hot | 被误作 leaf/global override |
| `job_run_start_policy` | 在 reserve/claim 前冻结本次 Job 的更严格策略 | batch、parallelism、timeout、retry | 不属于 hot | 中途改变 basis/report |
| `sensitive_ref` | 指向受控 provider/factory 的 opaque ref | adapter/store/policy/target ref | 否 | 拓扑泄露或被当 raw secret |
| `diagnostic_redaction` | 安全预览、诊断、handoff 和 telemetry posture | redaction policy/binding | 否 | redaction 放宽、local log 升 evidence |
| `test_deterministic` | 隔离的 fake clock/id/digest/store/adapter/fixture | `fixtureSetRef` | 仅 test startup | fake 污染 non-test profile |
| `peripheral_feature_request` | 请求已有外围 path，不创造 capability | diagnosis/handoff/archive flags | 否 | flag 被误读为 enabled/ready |

| 生效方式 | 适用域 | 当前允许 | 失败处理 |
|---|---|---:|---|
| `startup` | runtime/stores/bindings/observability/determinism/features/global caps | 是 | whole snapshot reject 或 builder/affected capability Blocked |
| `new_assembly` | 配置变更、binding/provider 替换与轮换 | 是 | 创建新 snapshot/builder；不原地改旧实例 truth |
| `job_run_start` | Job batch/parallelism/timeout/retry/idempotency/read budget | 是 | 当前 Job reject/blocked；已开始 Job 不变 |
| `entry_start` | whole-document/profile selector | 是 | 当前入口 reject；不改全局 snapshot |
| `test_startup` | test-only fixture/fake refs | 仅 `test-deterministic` | profile mismatch 或 fixture 缺失即 test fail-fast |
| `hot` / `reload` | 无 | 否 | Unsupported/reject-new-value；当前 snapshot 不变 |
| `static` | truth/state/guard/security/dependency invariants | 不是配置 | 必须回写相应 00～04 与正式评审 |

| 禁止配置化项 | 原因 | 如需改变应走什么流程 |
|---|---|---|
| `latest/default/newest/tag/branch` 或 mutable Release/version | 破坏显式 immutable selection 与 traceability | 回到 00/02/03 selection contract |
| 本地 approval/baseline/revoke/expiry override | Runner 不拥有 Artifact/Governance truth | 上游 owner contract + 03 authority seam |
| integrity/signature/manifest/platform gate bypass | 未验证材料可能进入运行 | 00/03、Artifact/Sandbox 合同和 06 gate |
| `Complete/Verified/Qualified`、`Accepted/Running`、`Confirmed/Cleaned` 合并 | 破坏多轴状态和 owner truth | 回到 02/03 状态与 flow |
| Query/render/reconnect write/refresh/reconcile switch | 破坏 Query no-write | 修改 03 protocol/flow，不得加 flag |
| expected-version/generation/lease/ProtectionGuard 关闭 | 产生 stale write、误删或越界控制 | 修改 03 consistency/guard contract |
| Unknown/commit-unknown 自动 replay/resend/reclaim/resume | 可能重复副作用 | 修改 03 recovery/idempotency；当前禁止 |
| raw secret/body/path/PID/port/URL/private backend 入普通配置或记录 | 泄露、事实越界、依赖绕过 | 安全/架构/03/04 重开 |
| local log/receipt/report/handoff 升级 formal audit/evidence/verdict/signoff | Runner 不拥有证据真相 | Observability/06 合同重开 |
| direct sibling DB/bus 或 Sandbox 私有 package/backend | 绕过 SDK/public boundary | 正式 public SDK/API/adapter 合同 |
| feature flag 创建 planned Consumer、outbound event 或 owner mutation | 当前无对应正向协议/事务合同 | 回退 00～03 与 04 全链 |
| product fake/in-memory fallback | 将测试能力伪装为真实能力 | 07/技术 authority 先选真实实现并重开设计 |

| 配置域 | 适用类别 | 域内禁止项 | 当前结论 |
|---|---|---|---|
| `runtime` | startup assembly、entry selector | implicit profile、truth/readiness switch | closed profile，no default |
| `stores` | startup、sensitive ref、test deterministic | raw DSN/path、product fake、owner store | logical refs；`RUN-DDD-003` |
| `bindings` | startup、sensitive ref、test deterministic | endpoint、private backend、SDK method/body | closed slots；`RUN-UP-*` |
| `limits` | startup/job-run policy | zero/unlimited、hard-cap bypass、auto replay | required/authority-pending |
| `observability` | diagnostic/redaction、sensitive ref | disable redaction、raw output、evidence switch | mandatory redaction；`RUN-UP-005` |
| `determinism` | startup、test deterministic | ad hoc time/id/hash、non-test fake | typed refs，fixture test-only |
| `features` | startup/peripheral request | owner mutation、reserved path、readiness creation | request-only，default disabled |

## 5. 配置来源、优先级与冲突处理

> 校准来源：
> - `design-calibration/04_config_step_05_sources_priority_conflicts.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“来源角色与优先级”“冲突处理表”“按配置域组织的来源覆盖”“来源停审与跨来源审计”和“详细设计影响、回填草稿与门禁”小节。

P0 普通值链只有 `static declarations / safe optional defaults < one selected external strict JSON document`。host/deployment selector 是 source-of-source，只选一份完整文档及入口 profile，不覆盖叶子值。sensitive resolver、test fixture registry 和 Job/request input 均位于普通覆盖链之外。

| 来源 | 优先级 / 角色 | 适用配置 | 冲突处理 | 不可用时策略 |
|---|---:|---|---|---|
| static declarations | 0；不可覆盖约束 | schema、requiredness、closed enum、hard safety cap、forbidden fields | 外部放宽尝试一律 reject | 声明不完整属于设计/实现 blocker |
| safe optional defaults | 1 | 仅 `false`、`null`、空 optional array 等不会开启正向能力的值 | 一份合法 external document 可覆盖 | default 也须通过同一 validator；不能单独构造可运行 runtime |
| one selected strict JSON document | 2；唯一普通外部值源 | profile、logical refs、finite policies、safe feature requests | 合法字段覆盖 safe default；非法/歧义整份 reject | missing/unreadable/parse/type/cross-field failure 均 fail-fast |
| host/deployment selector | source-of-source | 只选一份完整文档/profile | 多选、不唯一或 leaf override reject | 阻断当前 bootstrap/entry；不猜默认 profile/path |
| sensitive resolver/factory | validation 后独立 seam | 以 opaque ref 解析受控 runtime material | 不参与普通覆盖；family/ref mismatch reject | required provider/material 不可用则 fail-closed/Blocked |
| deterministic fixture registry | test-only seam | 显式 test ref 对应的 fake 行为 | 不覆盖文档；non-test 使用 reject | fixture 缺失使 test assembly fail-fast |
| Job/request input | protocol input，不是 config source | 03 已有本次 run scope/page/target/basis | 只能在允许范围内收窄 startup cap | 非法则拒绝当前 run；不改 global snapshot |
| env/CLI leaf override | P0 unsupported | 无 | 检测到该控制模型即 design reject | 不适用 |
| config center/admin/hot patch | P0 unsupported | 无 | 不能注入当前 schema | 必须先回写 03/04 loader/lifecycle/audit/rollback |

`config_ref` 由 source snapshot 与 canonical validation 结果派生，是不含正文的本地 correlation identity。它不是用户填写字段，也不是 Release/artifact digest、commit、正式 audit 或 evidence。

| 冲突 / 错误场景 | 处理规则 | 阻断范围 |
|---|---|---|
| external 合法字段与 safe default 同名 | external 值覆盖 default | 不阻断 |
| external 值类型、enum、ref 或范围非法 | 不回退 default；整份文档 reject | bootstrap/new assembly |
| duplicate key、alias/旧 key、unknown section/field | strict closed-schema reject | bootstrap/new assembly |
| 同一 slot 重复或 ref family 歧义 | reject | bootstrap/new assembly |
| profile 与 store/binding/feature/fixture family 不兼容 | cross-field reject | bootstrap/new assembly |
| startup required ref/value 缺失 | fail-fast；builder 不进入安全暴露状态 | whole runtime 或相关 core capability |
| numeric authority 未解析 | 不取零、无限、demo 或历史数值 | affected entry/write/Job Blocked；核心时 assembly blocked |
| optional feature=false 且 target 缺失 | 使用安全 default，保持 Disabled | 不阻断无关路径 |
| feature=true 但 contract/ref/readiness 不全 | reject 或显式 Blocked | affected peripheral capability |
| JSON 含 raw secret/body/path/credential URL/DSN | security reject before snapshot；不回显 | whole document |
| fake/fixture 出现在 non-test profile | profile/security reject | bootstrap/new assembly |
| selector 选中多份文档或多个 profile | source ambiguity reject | current bootstrap/entry |
| 新文档非法时尝试旧缓存/LKG/default fallback | 禁止执行 | 无自动回退 |
| 尝试配置 static/VETO 项 | design-boundary reject | whole document |

| 配置域 | 允许来源与组合 | 禁止来源 / 覆盖 | 不可用策略 |
|---|---|---|---|
| `runtime` | declarations + safe default + one document；selector 只选整体 | implicit profile、URL/DOM/storage、env/CLI leaf | source/profile 不唯一即 fail-fast |
| `stores` | document 中 logical refs；test profile 可由 fixture registry 解析 fake ref | raw DSN/path/backend、product fake、query override | guarantee 不足则 builder Blocked |
| `bindings` | document 中 closed slot→opaque ref；registry 形成 marker | endpoint、SDK method、owner body、direct sibling DB/bus | required/contract unknown 即 per-slot Blocked/Unsupported |
| `limits` | static hard caps + document finite values + 正式 run-local 更严格值 | zero/unlimited、放宽 cap、覆盖 no-replay | reject entry/Job 或 Blocked；不猜数字 |
| `observability` | document 中 mandatory redaction 与 optional safe refs | raw log/body/secret、disable redaction、evidence producer switch | redaction fail-closed；optional telemetry 可 degraded |
| `determinism` | document refs；test-only fixture registry | ad hoc time/id/hash、non-test fake | required provider 缺失阻断 mutation/test |
| `features` | safe defaults + document request/ref | owner mutation、reserved Consumer/outbound event、安全绕过 | false 为 Disabled；request 前置不全为 Blocked |

## 6. 环境、部署 profile 与配置矩阵

> 校准来源：
> - `design-calibration/04_config_step_06_environment_profiles_matrix.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“环境角色与 profile 总表”“Profile 配置与能力矩阵”“配置域的 profile 差异”“跨平台、断线与恢复矩阵”和“测试/验收/实施承接矩阵”小节。

环境角色、runtime profile 与 readiness 是三个独立维度。所有环境使用同一个 closed schema 和一份 strict document；profile 名称既不证明外部合同存在，也不证明 runtime/product ready。

| 环境 / profile | 用途 | 配置来源 | 外部依赖 | 敏感配置处理 | 差异说明 |
|---|---|---|---|---|---|
| local design/dev / `local-safe` | 本地装配、schema/页面、负向 flow 和 blocked UX | 一份 local strict JSON；profile 显式 | local store/cache 可 blocked；owner/Sandbox/Runtime 不允许 success fake | opaque refs；通常不解析真实 material | 可验证 fail-closed，不可声称完整主链运行 |
| CI unit/contract / `test-deterministic` | deterministic contract/domain/service/adapter parity tests | 一份受控 test JSON + 文档外 fixture registry | fake clock/id/digest/store/ports；必须覆盖 blocked/unknown/error | fake/fixture refs；无 raw body/secret | 只证明语义和可重复性，不证明真实 integration |
| controlled integration / `integration-pending` | 正式 SDK/owner seam 到达后的逐 slot 验证 | 一份受控 immutable JSON | 已闭合 slot 可 controlled/real-like；其余 Blocked/Unsupported | credential/endpoint locator 仅 opaque ref | 当前 `RUN-UP-001~008` 阻塞关键正向闭环 |
| staging-like rehearsal / `product-pending` | 未来产品候选的全链预演 | 一份受评审/版本化 JSON artifact；机制待定 | 仅 public SDK/API、durable local capability 和正式平台 seam | approved provider ref only | 当前 blocked，不构成 staging readiness |
| production/end-user / `product-pending` | 未来端侧正式运行 | 一份批准且不可变的 JSON artifact；机制待定 | 所有 required local guarantees 与启用 slot 的 formal readiness | raw secret 零落盘/零输出；provider-owned rotation | 当前 pending/blocked，不是发布 profile |

同一 `product-pending` 可映射不同环境角色，但各环境的文档身份、binding refs、authority 和外部 readiness 不可互换。Runner 不定义 `offline` profile；断线、休眠和网络不可用是 runtime observation，不能把旧 cache 或旧 authority 转成当前可信输入。

| 维度 | `local-safe` | `test-deterministic` | `integration-pending` | `product-pending` |
|---|---|---|---|---|
| profile 显式 / single document | required / yes | required / yes | required / yes | required / yes |
| local store refs | required；保证未知即 Blocked | required parity fakes | controlled/durable-like pending | formal durable refs required，当前 blocked |
| authority/material/integrity | blocked/disabled；无成功 fake | synthetic parity only | per-slot contract 到达后验证 | formal only，当前 blocked |
| Sandbox/Runtime | blocked/disabled | typed fake outcomes only | formal seam pending | formal only，当前 blocked |
| platform resource | safe Unknown/Unsupported | deterministic observations | controlled multi-platform pending | formal support matrix pending |
| redaction/diagnostic | mandatory；optional seam 可 blocked | fail-closed parity fake | formal safe read/handoff pending | formal provider where enabled |
| clock/id/digest | non-fake authority pending | fixed deterministic providers | controlled provider | formal provider |
| fake provider | 禁止正向成功 fallback | 允许且必须显式 | 禁止冒充 real | 禁止 |
| readiness 结论 | local composition 仍可 blocked | test harness only | per-slot pending/blocked | product blocked |

| 配置域 | local-safe | test-deterministic | integration-pending | product-pending | 跨 profile 规则 |
|---|---|---|---|---|---|
| runtime | 显式 profile/config identity | 显式 fixture identity | controlled document identity | approved artifact identity pending | 无 implicit switch |
| stores | logical refs；能力不足 Blocked | parity fake refs | durable-like refs pending | formal durable refs required | integration/product 禁 fake/in-memory fallback |
| bindings | blocked/disabled refs | explicit fake refs | formal slot refs逐项到达 | formal-only refs | ref 不直接产生 Ready |
| limits | authority-pending | deterministic fixture values | workload authority pending | formal authority required | test 数字不迁移 product |
| observability | mandatory redaction；外围可 blocked | safe-output/redaction fake | controlled formal seam pending | formal provider/handoff | raw log永不升级 evidence |
| determinism | non-test refs；缺失阻断 mutation | fixed clock/id/digest/fixture | controlled providers | formal providers | fake ref 只在 test |
| features | default disabled | 可测 request/reject | formal prerequisite 后才请求 | formal prerequisite + review | flag 不解除 contract/authority blocker |

| 场景 | 配置行为 | runtime / 用户可见行为 |
|---|---|---|
| OS/arch/filesystem 差异 | 只选择正式 platform binding ref；不写私有命令/path | Unsupported/Unknown/Conflict 显式；不伪造 allocation |
| 离线/断线 | 不换 profile，不回退旧 authority 或 cached config | Stale/Unknown/RecoveryCase；不自动 replay |
| 休眠/重启 | 重新加载并验证选定文档，创建新 assembly marker | 重验 generation/lease/protection/readiness；旧 marker 不恢复能力 |
| source/lease 过期或撤销 | config 不得 override | freeze/block；经 owner safe read 恢复 |
| 配置文档变化 | 新 config identity + new assembly | 已开始 Job 保留冻结 snapshot；不原地热改 |

所有 profile 共同遵守：显式 immutable version、authority/integrity gate、`accepted != running`、`confirmed != cleaned`、Query no-write、Unknown/no-replay、ProtectionGuard、mandatory redaction、SDK/public seam、local record != evidence。

## 7. 配置项清单

> 校准来源：
> - `design-calibration/04_config_step_07_config_items.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“配置项总表”“按配置域组织的配置项批次与停审”“模块级严格 JSON demo 与作用说明”“完整严格 JSON demo”“Cross-field 校验摘要”和“跨配置项闭环审计”小节。

项目本地 JSON 恰有七个顶层功能模块：`runtime`、`stores`、`bindings`、`limits`、`observability`、`determinism`、`features`。它们是配置域，不等于七个代码 package 或七个物理文件。`config_ref`、source snapshot、availability/readiness marker、issue ref 和 resolved material 都是派生结果，不是用户配置项。

### 7.1 `runtime`、`stores` 与 `bindings`

| 配置项 | 类型 | 默认值 | 是否必填 | 来源 | 作用域 | 生效方式 | 敏感级别 | 失败策略 | 关联模块 |
|---|---|---|---|---|---|---|---|---|---|
| `runtime.schemaVersion` | exact literal | 无 | 是 | one document | document | startup | public | 非 `runner-config/v1` → Unsupported/Reject | config loader |
| `runtime.profile` | closed enum | 无 | 是 | one document | assembly | startup | internal | 缺失、未知、family mismatch → fail-fast | `RunnerRuntimeProfileRef` / builder |
| `stores.stateStoreRef` | non-empty opaque ref | 无 | 是 | one document | assembly | startup | sensitive | unresolved/guarantee不足 → builder Blocked | `StateStore` |
| `stores.projectionStoreRef` | non-empty opaque ref | 无 | 是 | one document | assembly | startup | sensitive | identity/version不足 → builder Blocked | `ProjectionStore` |
| `stores.resultStoreRef` | non-empty opaque ref | 无 | 是 | one document | assembly | startup | sensitive | stored-result/idempotency不足 → mutation Blocked | `ResultStore` |
| `stores.operationStoreRef` | non-empty opaque ref | 无 | 是 | one document | assembly | startup | sensitive | claim/checkpoint/recovery不足 → Jobs Blocked | operations store |
| `stores.materialCacheRef` | non-empty opaque ref | 无 | 是 | one document | assembly | startup | sensitive | quarantine/promotion/protection不足 → acquisition/run Blocked | `MaterialCache` adapter |

`adapterBindings[].slot` 只允许 `context-read`、`release-authority-read`、`material-source`、`integrity-verifier`、`sandbox-run`、`runtime-status`、`platform-resource`。每个 item 只含 exact `slot` 与 non-empty opaque `bindingRef`，同一 slot 最多一次。store/cache、diagnostic/redaction/handoff、clock/id/digest、Archive 和 presentation 由各自模块拥有，不得在此重复。

## 8. 敏感配置与密钥管理

> 校准来源：
> - `design-calibration/04_config_step_08_sensitive_secrets.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“敏感级别与读取边界”“敏感配置表”“Profile、读取、轮换与变更边界”“禁止输出规则”和“跨敏感配置审计”小节。

当前 JSON 不含 raw secret 配置项，但包含可能暴露拓扑、provider、target、store 或 policy identity 的 sensitive refs。普通配置只保存 opaque ref；解析后的 token、password、private key、cert、credential-bearing URL、DSN、endpoint、path 或正文只能停留在 provider/adapter 的最小边界。

#### 敏感配置读取图: L5-runner opaque ref 与 material 隔离

```text
[one strict JSON document]
          | opaque refs only
          v
[strict parse + forbidden material checks]
          |
          v
[validated refs + redacted config identity]
          |
          v
[controlled resolver / adapter factory]
          | material remains inside provider/adapter
          v
[capability marker + safe issue ref -> typed application port]

raw material --X--> snapshot / application / domain / store / log / error / report
```

关键说明：

- Resolver/factory 是逻辑安全边界，不代表当前已有 `SecretProviderPort` 或具体 KMS/Vault/OS key store。
- 如果真实 resolver 需要新 port、constructor、error 或 lifecycle，必须先回写 03。
- ref 存在、material 可用和 capability Ready 是三个不同事实。
- application/domain/contracts 只接 typed port/policy/marker，不接 raw material 或 config handle。

| 敏感级别 | 含义 | 示例 | 处理要求 |
|---|---|---|---|
| `public` | 无安全/运行拓扑含义的 schema label | `runner-config/v1` | 可在文档和必要输出出现 |
| `internal` | 本地控制面语义 | profile、slot、positive finite limit、boolean request | 可入 JSON；输出最小化，不升级 truth |
| `sensitive` | 暴露 provider/target/store/policy identity 或拓扑 | 所有 store/binding/policy/fixture/target `*Ref` | JSON 仅存 opaque ref；普通输出不明文；变更需安全记录 |
| `secret` | 真实认证、连接或加密材料 | token、password、private key、cert body、credential URL、raw DSN | 永不进入普通 JSON、domain、store 或任何输出 |
| `forbidden_body` | 相邻 owner/运行/诊断正文 | manifest/Release/SDK response/stdout/stderr/raw log | 不得借配置或 resolver 进入 Runner truth |

| 配置项族 | 敏感级别 | 存储 / 读取 | 是否可明文 | 轮换方式 | 安全记录要求 |
|---|---|---|---:|---|---|
| `stores.*StoreRef`、`materialCacheRef` | sensitive | JSON opaque ref → capability resolver | ref仅文档可见；普通输出否 | new ref + new document + new assembly | section/slot、redacted digest、safe result |
| `bindings[].bindingRef` | sensitive | JSON ref → closed slot factory/registry | 同上 | new ref + new assembly | slot、digest、readiness class；无 endpoint/method |
| `limits.jobs.retryPolicyRef` | sensitive policy ref | JSON ref → typed policy resolver | ref仅文档可见 | new ref + new Job/assembly | policy family/digest/result；无 policy body |
| redaction binding/policy refs | sensitive/security-critical | JSON refs → mandatory redaction provider | ref仅文档可见 | new refs + new assembly；不得降级旧 policy | policy digest、validation、safe issue |
| diagnostic/handoff/telemetry refs | sensitive | optional refs → adapter factory | ref仅文档可见 | new ref + new assembly | slot/digest/safe availability；无 raw diagnostic |
| clock/id/digest refs | sensitive/internal | JSON refs → typed provider factory | ref仅文档可见 | new ref + new assembly | provider family/digest/result |
| `fixtureSetRef` | sensitive/test-only | JSON ref → isolated fixture registry | 仅 test document | new test document/fixture identity | fixture family/digest；无 fixture body |
| presentation/archive refs | sensitive | optional refs → capability/adapter registry | ref仅文档可见 | new ref + new assembly | slot/digest/safe status |
| raw provider material | secret | provider/adapter 内存最小生命周期；实现未选 | 否 | provider-owned | 只记 ref digest/result；永不记 material |
| owner/diagnostic/runtime body | forbidden_body | 不由配置解析 | 否 | N/A | 只允许正式 safe typed ref/summary |

| 生命周期点 | 允许行为 | 禁止行为 |
|---|---|---|
| source load | 读取 bytes、严格 parse；问题产生 redacted issue | dump document/value/path |
| ref validation | 校验 non-empty、family、slot、profile 和 forbidden lexical class | 把 URL/path/credential 当合法 opaque ref |
| resolve/factory | material 只在 provider/adapter 最小范围；产生 safe marker | material 注入 domain/application DTO/store |
| runtime use | typed port 调用并再次满足 readiness/authority gate | 以 ref 存在绕过 probe |
| rotation | 新 source/config identity/new assembly；已开始 Job 保持 snapshot | 原地热改 marker/truth 或自动 replay |
| rollback | 选择仍获批准且重新验证的 whole document/ref | 复用旧 raw material或 LKG 绕过验证 |

| 输出面 | 允许字段 | 永久禁止 | 失败处理 |
|---|---|---|---|
| parser/validator issue | source/config ref、section、安全 key class、issue kind | whole JSON、raw value、path/URL/secret | reject且不回显 |
| structured log | operation、profile、slot、safe outcome、redacted digest/issue ref | full sensitive ref、material、endpoint/topic/path/stack/body | 舍弃不安全字段/事件，仅保留安全计数 |
| public/internal error | typed code、safe issue ref、retry disposition | config value、SDK/provider/OS raw error、credential | 映射 safe blocked/invalid/unavailable |
| metric | low-cardinality profile/slot/outcome/error class | IDs、full refs、endpoint、free text、body digest | drop unsafe label；business outcome不变 |
| trace/local history | safe operation/ref/state/source version | secret、config body、adapter response、raw log | safe span only；非 formal audit |
| stored result/Job report | public safe surface、bounded refs/counts | target credential、full config/ref、payload | safe Blocked/Failed/Unknown surface |
| handoff | already-redacted safe material refs + formal target carrier | secret/raw log/package/config body | validation/redaction failure则不提交 |
| UI/CLI/page | safe status、next step、redacted issue ref | raw validation value、endpoint/path/secret/stack | Restricted/Blocked presentation |

Runner 可以留下本地 safe config-validation/assembly marker，但它不是正式安全审计、Observability evidence、verdict、signoff 或 approval record。

#### 配置加载流程图: L5-runner 配置加载与校验

```text
[static schema / forbidden declarations / safe optional defaults]
                              +
          [one selected external strict JSON document]
                              |
                              v
          [source bytes snapshot + source correlation ref]
                              |
                              v

                              |
                              v
```

关键说明：

|---|---|---|---|---|---|
| runtime | bootstrap | exact object/literal/profile enum | source/profile/ref family compatibility | startup/new assembly | whole assembly fail-fast |
| stores | bootstrap | five non-empty opaque refs | profile family、role separation、required guarantees | startup | invalid reject；core不足 builder Blocked |
| bindings | bootstrap | exact array/object、closed slot、unique ref | profile family、formal contract/readiness 独立 | startup | invalid reject；unready per-slot Blocked |
| limits | bootstrap；Job run start | positive/representable/full embedded object/policy ref | hard caps、stricter-only、horizons、no-replay | startup/job-run-start | startup fail-fast 或 current Job reject/Blocked |
| observability | bootstrap | required/nullable refs | mandatory redaction、feature/ref pairs、provider capability | startup | redaction fail-closed；optional telemetry degraded |
| determinism | bootstrap/test startup | required refs + nullable fixture | fake isolation、provider family/capability | startup/test-startup | mutation/test Blocked/fail-fast |
| features | bootstrap | boolean/nullable refs | prerequisites、archive pair、VETO | startup | Disabled 或 Blocked；不生成 Ready |
| entry selector | entry start | exactly one whole-document selector | 不允许 leaf override | entry-start | current entry reject |

### 9.1 Cross-field validation rules

| Rule ID | 规则 | 失败 surface |
|---|---|---|
| `RUN-CFG-V-001` | exact schema；四值 profile 且显式 | safe `UnsupportedSchema` / `InvalidProfile` issue |
| `RUN-CFG-V-002` | test refs only in test；integration/product 禁 fake；local-safe 禁 success fake | document reject |
| `RUN-CFG-V-003` | five store/cache refs 齐全、logical family 分离、capability marker 独立 | invalid reject；capability不足 builder Blocked |
| `RUN-CFG-V-004` | adapter slots closed/unique，不重复其他域拥有的 slot | document reject |
| `RUN-CFG-V-005` | URL/path/credential/raw body/SDK method/private backend 不得充当 ref/body | security reject，无 raw echo |
| `RUN-CFG-V-006` | all numeric positive、representable、≤ static cap；embedded object完整 | document reject |
| `RUN-CFG-V-007` | request/Job value只可收窄 startup cap，不可关 guard | current entry/Job reject |
| `RUN-CFG-V-008` | idempotency windows 覆盖 formal retry/redelivery/claim/report/commit-unknown horizon | affected capability Blocked；核心可使 assembly Blocked |
| `RUN-CFG-V-009` | possible-effect timeout、Unknown、commit-unknown 不得自动 replay/resend/reclaim | policy reject |
| `RUN-CFG-V-010` | redaction binding/policy required、family compatible、fail-closed | assembly/output Blocked |
| `RUN-CFG-V-011` | diagnostic/handoff request=true 需 ref、profile allowance、formal prerequisite | reject 或 peripheral Blocked |

### 9.2 Runtime builder 装配与暴露

| 顺序 | 输入 | 产物 | 门禁 / 禁止 |
|---:|---|---|---|
| 1 | validated snapshot | profile/config identity + typed policies | 不暴露 raw document handle |
| 2 | store/cache refs | store capability states、UoW/repository/cache adapters | core guarantee不足不继续；不选 private backend |
| 3 | external/platform/observability refs | per-slot configured/availability markers | configured不等Enabled/Ready；保留 `RUN-UP-*` |
| 4 | clock/id/digest refs | typed providers | missing 阻断 mutation；无 ad hoc fallback |
| 5 | limits/features | immutable entry/query/Job policies和request markers | domain/contracts不读 config；flag不改 invariant |
| 6 | required local guarantees | `RunnerRuntimeConfig`、builder state、safe facade | facade仅在本地安全组合后暴露；per-port仍可 Blocked |
| 7 | entry/Job start | frozen run-local effective policy | 不改 global snapshot；current run输入只可更严格 |

| 生效边界 | snapshot 语义 | 失败 / 回退 |
|---|---|---|
| `startup` | 生成一个 immutable validated snapshot 与 builder marker | invalid 不构造新 facade；无 silent fallback |
| `new_assembly` | 新 source/config identity、新 stores/adapters/markers | 失败不篡改旧 truth；外部 lifecycle 决定旧实例，不称自动 LKG |

| `static` | 不进入 config | 改变需正式设计 review |

|---|---|---|---|
| source unavailable/ambiguous | source class/ref、issue ref | path/body/env dump | bootstrap fail-fast |
| parse/duplicate/unknown/alias | section/key class、issue ref | raw document/value | reject whole document |
| missing/type/enum/range | safe field path class、expected class、issue ref | sensitive value | reject assembly/entry/Job |
| invalid ref/forbidden material | slot/ref family/forbidden class、issue ref | full ref/material | security reject |

## 10. 配置变更、审计与回滚

> 校准来源：
> - `design-calibration/04_config_step_10_change_audit_rollback.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“变更角色与风险级别”“配置变更表”“安全审计/变更记录字段”“回滚与并存 snapshot 矩阵”和“跨变更审计”小节。

Runner runtime 不提供 admin 配置写 API，也不拥有正式 configuration audit/evidence truth。完整配置文档由外部 configuration/release maintainer 或受控 automation 生成/选择；Runner 只负责严格验证、建立新 assembly 和产出不含正文的本地安全 marker。

| 角色边界 | 允许 | 禁止 | 安全记录语义 |
|---|---|---|---|
| configuration/release maintainer ref | 提交完整 startup document、选择 rollback target | 绕过 validator、修改 owner/domain truth、写 raw secret | actor/change/reason/reviewer refs + document digest/result |
| release/config automation ref | 对已批准 artifact 执行 selection/validation/new assembly | 自动批准高风险变更、猜测 LKG | automation/run ref + source/config refs + result |
| entry caller ref | 选择一份完整 source/profile 并启动新入口 | leaf override、持久化 global config、传 secret | entry/source selector class + result |
| authorized Job caller ref | 提交 03 已有 bounded run-local input | 扩大 cap、改 global snapshot、复用冲突 idempotency key | Job/run/input digest + result |
| test harness ref | 选择 fixture/fake test document | 进入 local/integration/product runtime | test/fixture digest + profile |
| design authority ref | 改 schema、slot、lifecycle 或 VETO | 当成普通 config patch | 正式 design review/baseline ref；由外部流程持有 |

| 风险级别 | 适用变更 | 最低要求 |
|---|---|---|
| low | 在已有 authority cap 内收窄本次 page/batch 等 run-local 值 | validation + safe change record |
| medium | test fixture、local-safe presentation 或 disabled peripheral 变化 | reviewer/automation approval + rollback target |
| high | profile、stores/cache、external slot、redaction、clock/id/digest、limit/horizon/retry、feature false→true、sensitive ref | 相关 architecture/security/contract/operations review + rollback plan |
| critical/rejected | raw secret/body、fake 污染 non-test、redaction/guard/no-write/no-replay 放宽、owner truth override、hot/admin bypass | 不得激活；如确需改变，先重开 00～04/03 |

| 变更类型 | 发起方 | 评审要求 | 生效方式 | 安全记录 | 回滚方式 |
|---|---|---|---|---|---|
| schema/profile/source policy | maintainer/design authority | high；schema 扩展先设计 review | whole new document/new assembly | old/new schema/profile class、digest、review refs | previous still-approved document 重新验证 |
| stores/cache refs | maintainer/automation | high：durability/UoW/version/quarantine/protection | new assembly | slot、old/new redacted ref digest、capability result | whole-document rollback；不足则 Blocked |
| external/platform refs | maintainer/automation | high：public contract/SDK/security | new assembly | slot、ref digests、contract/readiness class | whole-document rollback；无 private/fake fallback |
| numeric limits/hard-cap relation | maintainer/authority；Job caller只可收窄 | startup/widen high；run-local narrowing low | new assembly/new run | policy class、value digest/range class、authority ref | previous document/new run；无 authority 不激活 |
| idempotency windows/retry | maintainer/authority | high：commit-unknown/no-replay/recovery | new assembly/new run where allowed | policy digest、horizon validation、review refs | previous document；不删 unresolved、不 replay |
| redaction binding/policy | maintainer/security authority | high；relaxation critical/rejected | new assembly | policy/binding digest、validation、reviewer refs | previous stricter approved document；failure无 visible content |
| diagnostic/handoff/telemetry refs | maintainer/contract owner | high when enabling | new assembly | slot/ref digest、feature transition、availability class | reviewed disabled document/new assembly；business truth不回滚 |
| clock/id/digest refs | maintainer/implementation authority；test harness in test | non-test high；test medium | new assembly/test startup | provider family/digest/profile/result | previous approved ref；valid前 mutation Blocked |
| feature false→true / target ref | maintainer/contract/security owner | high；formal prerequisite required | new assembly | feature class、ref digest、contract result | reviewed false document/new assembly |
| feature true→false | maintainer | medium；确认不破坏 core dependency | new assembly | transition + affected surface | previous whole document if still approved |
| Job run-local input | authorized Job caller | protocol/limit validation；不得扩大 cap | new run only | run/input digest、effective policy/config ref | current run reject；old report不改 |
| test fixture | test harness | test review + fixture isolation | test startup | fixture digest/profile/test run ref | previous fixture + rerun；无 product fallback |
| forbidden key/material/VETO override | any source | critical reject | no activation | safe forbidden class + issue/source ref | 修正文档或正式 design change；无 runtime rollback |

正式变更记录由外部 configuration/release owner 持有。其最小语义包括 document/source/version ref、old/new redacted canonical digest、safe section/key/slot/policy class、actor/reviewer/reason/change refs、validation/activation outcome、config/profile refs 和 explicit rollback target/change ref。禁止记录 raw document、path/URL、plain diff、secret/full sensitive ref、provider error 或审批正文。具体 digest algorithm、ticket/audit 产品和 record schema 尚未选定，本文不声称已产生任何真实记录。

| 场景 | 旧 runtime / Job | 新 assembly / run | 恢复 / 回滚 | 禁止 |
|---|---|---|---|---|
| source/parse/type/cross-field失败 | 已运行实例保持 immutable snapshot；生命周期不被隐式改变 | 不构造 | 修正文档，或显式选择 still-approved previous document 并重验 | lower-priority/default/LKG fallback |
| core store/provider builder失败 | 旧实例不被原地修改 | 不暴露新 facade；affected mutation Blocked | whole-document rollback + new assembly | 删除失败 slot 绕过 review |
| optional slot运行期不可用 | 旧实例按 per-slot typed failure | 不因 failure 自动换 config | dependency recovery；必要时评审新文档 | private/fake adapter fallback |
| 新配置合法但表现异常 | 旧/新实例生命周期由 host/product owner 管理 | 新实例可按正式 lifecycle 停止/替换 | reviewed previous artifact重验并new assembly | 从 UI/log 推断 rollback 成功 |
| sensitive provider rotation失败 | 已开始调用/Job按原 basis进入 typed outcome | 新 assembly/operation Blocked | previous still-approved 或新 approved ref，重新验证 | 输出 material、偷偷复用旧 secret |

## 11. 失效模式与降级 / fail-fast 策略

> 校准来源：
> - `design-calibration/04_config_step_11_failure_degradation.md`
>
> 延伸阅读：
> - 建议继续阅读上述中间产物的“策略术语”“失效模式表”“按域与生效方式的失败策略”“安全记录与告警要求”“测试切口”和“跨失效审计”小节。

| 策略 | Runner 配置语义 |
|---|---|
| `fail-fast` | 在 bootstrap/entry/Job/test start 发现不可构造输入时立即失败，不暴露新 facade，不进入 mutation/owner call。 |
| `fail-closed` | authority、安全、redaction、capability 或 effect 不确定时保持 Blocked/Unknown/Restricted/ManualReview，不以宽松默认补齐。 |
| `disabled` | optional feature未请求或为 false；不建立 positive capability，不影响无关安全主链。 |
| `degraded` | 合法配置下 runtime safe read/外围能力部分不可用；经 03 typed surface 暴露。非法配置不得降级成可运行。 |
| `reject-new-value` | 新 document/entry/Job input非法时拒绝，不热改 current snapshot。 |
| `restart rollback` | 外部 owner显式选择仍获批准且重新验证通过的完整文档，建立 new assembly。 |
| `last-known-good` | P0 不支持 automatic/online LKG，不搜索“latest good”，不信任旧 cache。 |

| 失效模式 | 影响 | 系统行为 | 安全记录 / 告警语义 | 测试切口 |
|---|---|---|---|---|
| source缺失、不可读、多选 | 无唯一 document | bootstrap/entry fail-fast | source class/ref + issue；无 path/body | missing/unreadable/ambiguous source |
| malformed/comment/trailing/duplicate JSON | shape不可信 | whole document reject | parse class/section only | strict parser negatives |
| unknown/alias/removed key | schema漂移或历史污染 | reject | key class + schema version | unknown/legacy key |
| schema/profile缺失或未知 | assembly posture未知 | fail-fast；不 default local/test/product | safe enum class | required/closed enum |
| store/cache ref缺失或非法 | local guarantees不成立 | builder/mutation Blocked；no facade where core required | slot/capability/issue | each core ref negative |
| store capability无法证明 | UoW/version/durability/quarantine不足 | fail-closed；no fallback | safe capability class | marker/facade exposure |
| adapter slot重复/unknown/ref非法 | registry不可信 | document reject | slot/rule ID | slot matrix |
| external contract未闭合 | positive call不安全 | per-slot Blocked/Unsupported；safe query仅在正式支持时 degraded | blocker/slot/issue | configured != ready |
| non-test使用fake/fixture | profile隔离破坏 | security/profile reject | profile/provider class | fake contamination |
| numeric missing/zero/overflow/超 cap | boundedness不成立 | startup fail-fast 或 run-local reject | policy/range class | limit boundaries |
| numeric authority未定 | 无合法 product 值 | affected capability `ConfigAuthorityPending`/Blocked | policy family/blocker | no guessed default |
| idempotency horizon不足/未知 | duplicate/commit-unknown不安全 | mutation/Consumer/Job Blocked | horizon class/issue | cross-horizon |
| retry policy允许possible-effect replay | 重复副作用风险 | policy reject；Unknown保留 RecoveryCase | policy/rule ID | no replay |
| redaction ref缺失/失败 | 输出可能泄露 | no visible content/handoff；affected output Blocked | policy/slot/issue，无 raw | redaction fail-closed |
| raw secret/body/path/URL/credential | 泄露/越界 | security reject且不回显 | forbidden class only | zero-output assertions |
| optional feature=false/target null | 外围能力未启用 | DisabledByConfig；无关 core继续 | optional info marker | disabled isolation |
| feature=true但前置不全 | 虚假启用 | reject或explicit Blocked | feature/prerequisite class | prerequisite matrix |
| archive requested但unready | 外围 Archive不可用 | Archive path Blocked；core run/cleanup不变 | slot/issue | peripheral isolation |
| clock/id/digest provider缺失 | mutation identity/time/digest无来源 | reserve/write 前 Blocked；safe read可受限 | provider class | zero mutation calls |
| run-local扩大 startup cap | 越权 | current Job/entry reject；global snapshot不变 | run/rule issue | stricter-only |
| new assembly parse/build失败 | 变更不能激活 | reject new value；旧 runtime不被原地改 | change/config refs/result | no implicit rollback |
| runtime dependency暂时不可用 | 合法 config 下 adapter failure | typed Unavailable/Degraded/Unknown；无 private fallback | slot/outcome/safe diagnostic ref | per-port runtime failure |
| timeout/断线且effect可能发生 | owner outcome未知 | Unknown + RecoveryCase + query-first/manual review | correlation/recovery ref | ambiguous effect/no replay |
| config digest drift | source不可复核 | 阻断 new assembly/release gate | expected/actual redacted digest refs | drift mismatch |
| rollback artifact撤销/不兼容 | 不能安全回滚 | rollback reject；要求新修复 document | target/status issue | no latest/LKG |
| config center/admin/hot source | 当前控制面未设计 | Unsupported/reject | control/source class | unsupported controls |
| test fixture缺失/非法 | 不可重复 | test assembly fail-fast | fixture digest/class | deterministic fixture |

| 配置域 | invalid config | runtime dependency failure | 允许的安全继续 | 禁止 fallback |
|---|---|---|---|---|
| runtime | whole assembly fail-fast | N/A；profile不等 health | new assembly 不暴露 | implicit profile/LKG |
| stores | fail-fast/Blocked | storage unknown按03 recovery；no write replay | 正式支持时的 safe read | in-memory/test/product switch |
| bindings | reject | per-slot Blocked/Degraded/Unavailable/Unknown | unrelated paths only | private SDK/backend/direct DB/bus |
| limits | fail-fast/entry/Job reject | policy frozen | existing Job保持 basis | zero/unlimited/old defaults |
| observability | redaction fail-closed；optional ref invalid reject | diagnostic/telemetry可 Failed/Degraded | business truth不变；无 raw output | local raw log as evidence/content |
| determinism | fail-fast/mutation Blocked | provider error → typed Unknown/Blocked | no new mutation identity | timestamp/PID/path fallback |

## 2. 测试目标与范围

> 校准来源：

>

本轮目标是证明 `L5-sync` 的 local contract 和安全边界可以被逐层验证：显式项目/版本/来源/目标选择与访问检查、source/workspace binding、`.qs-sync` 逻辑 metadata、status/pull/clone、增量/游标/映射、dirty non-overwrite、冲突/恢复/probe、Review handoff/provenance、Query zero-write、配置和 redaction。测试不证明外部 Artifact/Baseline/Review/Workspace/Archive/Git remote truth 已改变。

### 2.1 P0/P1/P2 目标

| 优先级 | 范围 | 当前完成上限 |
|---|---|---|
| P0 | CP-SYNC-01～06 的 local invariants；10 Command、13 Query、3 Consumer、3 Job 的 protocol/flow 负向与 controlled fake；17 state；UoW/幂等/恢复；42 leaf/4 profile；redaction、依赖和 VETO | planned local evidence；不声称执行/通过 |
| P1 | SDK/source/access/review/probe、metadata driver、Git/filesystem tool 的 controlled/real-like seam | contract/fixture/环境闭合前 `blocked/waiting` |
| P2 | 批量预取、结果比较、归档引用消费、容量/性能数字、LFS/浅克隆/GUI/Tauri 等外围/未核验选择 | deferred/future trigger，不是核心 exit gate |

### 2.2 核心范围/非范围

| 范围项 | 主要验证 |
|---|---|
| explicit selection/access | principal、project、version/source、target、operation 完整；owner unknown/stale/denied/archived/dissolved fail-closed |
| binding/metadata | binding、generation、manifest、cursor、mapping、provenance 关系；logical migration/rebind guard |
| clone/pull/status | safe plan/path/run、增量/全量/无变化、cursor only on Finalized、Query no-write |
| conflict/recovery | conflict fact、manual resolution、checkpoint、probe、resume/cancel；无 blind replay/auto resolution |
| push-review | candidate freeze、attempt-before-call、transport/probe/Decision layering；ACK≠accepted |
| configuration | strict JSON、source precedence、42 leaf、4 P0 profile、activation/failure/redaction |
| diagnostics/evidence boundary | safe ref/digest/correlation、raw body/secret/path/output 禁止、计划路径固定 |

明确非范围：Project、Artifact、Baseline、Review Gate/Decision、Workspace projection、Archive、Git remote truth；自动 merge/rebase/push/stash、dirty overwrite、自动冲突选择、共享数据库/私有 endpoint/任意 bus；部署 runbook、验收 verdict、实施 commit。

### 2.3 VETO 目标

| VETO | 必须由测试捕获的方向 |
|---|---|
| `VETO-SYNC-001` | 自动 merge/rebase/push/stash、dirty overwrite、blind replay |
| `VETO-SYNC-002` | local commit、ACK、HTTP 200、remote object、log/cache/telemetry/job report 不得升格 Artifact/Baseline/accepted/approved/readiness |
| `VETO-SYNC-003` | Sync 不创建/修改/伪造 Project、Artifact、Baseline、Review Gate、Workspace、Archive、Git remote truth |
| `VETO-SYNC-004` | provenance/冲突证据不可删除或伪造；raw body/credential/path/output 不泄露 |
| `VETO-SYNC-005` | owner/access/source/comparator unknown 时不得危险 materialize/handoff |

### 4.1 分层模型

```text
L6 release/evidence summary (planned)
  -> L5 CLI/Consumer/Job entry contract (planned)
  -> L4 controlled adapter contract (blocked/waiting for positive)
  -> L3 application/flow fake (planned)
  -> L2 domain/state/property (planned)
  -> L1 static/architecture (planned)
```

| 层级 | 首要责任 | 能证明 | 当前姿态 |
|---|---|---|---|
| L1 static/architecture | import/dependency、forbidden remote/publisher/shell | 依赖方向和禁止 surface | planned |

| L3 application/flow fake | Command/Query/Consumer/Job 编排、UoW/write-set、replay | local flow 与副作用隔离 | planned |
| L4 repository/adapter | version/atomic visibility、SDK/Git/fs/metadata error mapping | controlled seam；正向 owner/tool/physical integration受阻 | blocked/waiting |

### 6.1 Shared protocol

| ID | 场景 | 期望 |
|---|---|---|
| `TC-SYNC-PROTO-001` | 缺 actor/correlation/schema/source/key | trusted boundary 前拒绝；不 begin UoW |

### 6.2 Command 场景（10）

| Command | 关键正向/异常 | 必须禁止 |
|---|---|---|
| `CloneWorkingCopy` (`TC-SYNC-CMD-001`) | explicit selection、safe path、empty/compatible target、Finalized；missing/dirty/gap/partial/unknown | fetch/push/merge/rebase/stash/overwrite；local finalize≠Artifact/Baseline |
| `MigrateSyncMetadata` (`TC-SYNC-CMD-002`) | expected generation、supported target、new generation、old chain protected；corrupt/unsupported/commit unknown | in-place rewrite/delete provenance；query/scan mutation |
| `RebindWorkingCopy` (`TC-SYNC-CMD-003`) | explicit new selection/reason、new identity/generation；dirty/unknown/race | directory/Git/default inference；overwrite/materialize/old-history delete |
| `PullWorkingCopy` (`TC-SYNC-CMD-004`) | full/incremental/no-op proof、plan/run、known apply→finalize；gap/rename/delete/dirty/unknown | cursor advance before Finalized；auto merge/rebase/stash |
| `RecordConflictResolution` (`TC-SYNC-CMD-005`) | human actor、bounded scope、Recorded→Validated | system actor；intent≠effect；不调用 file/cursor/source/handoff |
| `ResumeSyncOperation` (`TC-SYNC-CMD-006`) | exact checkpoint/fingerprint/generation/resolution、typed next action | force retry、继续旧 PC、绕过 safety gates |
| `ProbeUnknownOutcome` (`TC-SYNC-CMD-007`) | durable prior attempt、new probe identity、formal result mapping | original submit/resubmit；telemetry/log 不能代 probe |
| `CancelSyncOperation` (`TC-SYNC-CMD-008`) | local non-terminal cancel、result/provenance retained | remote cancel、file cleanup/rollback claim、history delete |
| `PushReviewCandidate` (`TC-SYNC-CMD-009`) | gates→Frozen candidate→Prepared attempt→pre-call revalidate；known/unknown transport | Git push；commit/ACK→Artifact/Baseline/accepted；unknown resubmit |
| `RefreshReviewHandoffStatus` (`TC-SYNC-CMD-010`) | Decision read 或 formal probe、body-free snapshot | 创建/改变 Gate/Decision；missing默认pending/accepted；blind read+probe |

每个 Command 另测 same/different digest、version/generation race、forbidden output 和 exact replay。

### 6.3 Query 场景（13，全部 zero-write）

`GetAccessEvaluation`、`GetSyncOperation`、`GetWorkingCopyBinding`、`GetMetadataHealth`、`InspectWorkingCopy`、`GetMaterializationStatus`、`GetConflict`、`ListConflicts`、`GetRecoveryStatus`、`GetSyncStatus`、`GetReviewHandoffStatus`、`GetProvenance`、`GetSyncDiagnosticSummary` 分别覆盖 exact selector/hit、missing/not-visible/partial/unavailable/stale，并由 spy 断言不 begin UoW、reserve idempotency、获取 write lock、写 repository/provenance、调用 formal probe/handoff 或发送 diagnostic。`InspectWorkingCopy` 即使允许 read-only Git/fs inspect 也不能 persist/lock/fetch/apply。

### 6.4 Consumer/Job 场景

| 入口 | 核心断言 |
|---|---|
| `ConsumeAccessOrPostureInvalidated` | stale evaluation/snapshot、未消费 plan/candidate invalidated；duplicate receipt；无 cancel/pull/handoff |
| `ConsumeMaterialSourceInvalidated` | cursor unknown、plan/candidate invalidated；unsupported/quarantine；无 auto pull/rollback/cursor advance |
| `ConsumeReviewDecisionChanged` | exact attempt 的 body-free Decision snapshot；无创建/解释 Decision |

### 1.1 证明范围与基线

本计划只定义local-contract、controlled/fake seam、真实PG、entry/Web、配置/脱敏/恢复的实施路径。owner/SDK exactconsumer、publisher/human/org/auth、Governancefullbinding、材料、receiver/probe、notice、Obsproducer缺资格时，受影响formal-selected保持blocked；Billing/Archive/event等future不进入实现。

当前来源为未提交workingtree，不是已冻结不可变designcommit；日期或设计静态审查不替冻结。用户确认07仍须另行明确implementation/commit授权，冻结baseline并核targetrepo/toolchain/export及currentrequired条件后才可激活第一边界。本文不表示任何代码、run、artifact、EV或部署完成。

### 2.3 非范围与future

不实现owner Method/Role/ProcessTemplate正文、Capability Registry/Adaptertruth、MemberImage内容、Artifact正文与血缘、Identitytruth、人类/组织认证或Governanceapproval。安装/激活/卸载、支付/订阅/账本/分成/跨境交易无正式owner时只future/blocker；明确局部entitlement/transaction不能扩成财务truth。

Archiveexport/restore、canonicalevent/outbox、Bus直连当前0active；rating/review/ranking/recommendation、公开发布CLI及新商务/权限运营后台未纳入需求，需授权重开。当前publisher/application/version等Web控制仍属范围，不只是静态UI。

#### 范围图: 只消费owner，保存Marketplace局部事实

```text
[owner immutable refs / formal decisions / typed outcomes]
  | consume; no body/registry/approval copy
  v
[Marketplace listing/application/version/distribution/withdrawal]
  +--> [API + typed Web current views]
  +--> [internal Worker jobs + local audit/recovery]
```

关键说明：图是所有权关系，不是owner内部实现；资格缺失只blocked/degraded/Unknown，箭头不证明真实正向结果。

## 10. 回退、暂停与变更控制

> 校准来源：[07 Step 10](design-calibration/07_implementation_plan_step_10_rollback_pause_change.md)。
>
> 延伸阅读：该文件的“暂停规则表”“回退规则表”“变更控制表”“恢复流程”“本次经验回写与正反例”；所有规则都是future实施许可条件，本轮只设计。

### 10.1 必须暂停

字段/DTO/state/ref/port/phase冲突、baseline漂移、任何当前requiredGate失败、VETO命中、secret/body/redaction泄露、Unknown无formalprobe、expectedcase缺失、schema/DAG不合法或qualification不足但当前要求positive，立即pause。记录精确source/affectedscope/ledger与redactedfailure；秘密原始输出隔离不归档。

### 10.2 保护性回退与恢复

| 场景 | 允许动作 | 禁止 |
|---|---|---|
| 未提交当前增量 | 用户授权且先记录用户/无关改动后，只保护性撤回自己当前boundary增量 | reset/checkout/删除目录破坏用户或前序改动 |
| 已提交未handoff | 同scope实际fix/revert，提交另授权，记录impact | 混nextboundary/改写前序已交付责任 |
| 测试/脚本失败 | 保留失败raw/report，修当前，新run_id/newexecution_id | 覆盖completedrun/挑passed/改TC/AC/VETO绕过 |
| design变化 | 回所属truth/calibration，横扫同类面/55经验，固定新baseline | 在旧baseline继续、实现临补schema |
| PG测试失败 | 获准隔离testfixture/受控migration恢复，按版本记录 | 删除正式history/fullresult/checkpoint |
| CommitUnknown/外部不确定 | 保留原intent/permission/operation/fullresult，formalprobe/reconcile/latebinding | blindretry/cancel-as-success/当未提交 |

#### 恢复流程图: 原责任保留，新run重验

```text
[pause; preserve original responsibility and failed run]
  -> [safe failure + ledger + exact affected scope]
  -> [repair owning design/current increment; protect user worktree]
  -> [freeze new baseline if changed; re-read]
  -> [new run/execution: Design > Scope > Worktree > Build/Test > Evidence]
       +--> failure: remain blocked
       +--> true success + authority: Commit > Handoff > next current
```

关键说明：这是恢复控制，不自动rollback/deploy；无终局/probe仍waiting，不能code/pass改变外部结果。source缺失、原report不完整继续等待，不删除Unknown责任。

|---|---|
| 新需求/运营/安装/支付 | 00～07受影响scope/owner/FR/AC/VETO/phase/boundary |
| 字段/enum/state/typedport | 03+05/06/07全链factory/DTO/flow/PG/测试/验收 |
| SDK/owneroperation/schema/version/scope | 01/03/04/05/06/07、slot/positive/negative/current |
| phase/boundary/共享路径 | 07 Step5/6/7/11/12、ledger/skeleton、前后依赖 |
| evidence/schema/config/toolchain | 04/05/06/07及03绑定、redaction/DAG/golden/compatibility |

修复后检查是否需沉淀通用经验，并按MEM-MP-007提供项目正反例/横扫/种子更新。既有标准已覆盖本轮phase、JSON映射、suite/path/maturity问题，无新通用规则需要越权修改；若未来发现未覆盖规则，记录标准/SOP待回写，取得范围授权前不得自行改其他项目或标准。

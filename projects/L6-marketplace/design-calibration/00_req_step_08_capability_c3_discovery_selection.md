## 3. SOP 问题回答

1. 故事：消费者希望找到范围内合适资产并选择确切版本；组织管理者希望区分适用范围与真实来源。
2. 功能：目录分类/标签与搜索；安全详情；版本选择与资格说明。类型分类不能合并 listing into capability registry/method catalog；一类可多 listing，一个 listing 多市场版本，各版本固定 owner 来源。
3. 规则：owner visibility、正式授权和市场限制共同收紧；public 不是凭据豁免；搜索/总数/提示/详情/历史每条同门槛；未知版本不能默认 latest，选择需 exact 来源与市场版本关系。
4. 数据：市场分类/展示 metadata 本地 truth；owner 摘要与索引为快照；选择是明确引用语义，不是资产内容副本。
5. 接口：同步可见查询、版本选择资格；维护索引后台入口但不反写市场或 owner truth。没有 formal scope resolver 不解析 ID 或 UI 过滤冒充授权。
6. 质量：stable page 排序/去重、一致可见性、来源 freshness 可判别、查询 no-write；索引与目录 stale 可降级但不能扩大可见性或承诺可获取。
7. 验收：五类 mapping 正确、同类多 listing、多版本、无可获取版本、隐藏/受限/撤回、不支持 owner、陈旧索引各有结果；所有公开信息需真实来源，缺评分/截图不造值。

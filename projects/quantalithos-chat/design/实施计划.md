> 聊天前端 — Vue 3 + Vite + Naive UI + sdk-wasm
> 关联详细设计：`projects/quantalithos-chat/design/详细设计.md`

## 一、前置条件

> **必须先阅读** `docs/design/实施计划书写规范.md` §二-A 前置条件，完成 Git 仓库初始化和通用前置检查。

### 1.1 必读文档

| 文档 | 阅读目的 |
|------|---------|
| projects/quantalithos-chat/design/概要设计.md | 理解三栏布局、页面结构、层间约束 |

### 1.2 编码约束

- 语言：TypeScript + Vue 3 SFC，代码全英文
- 框架：Vue 3 + Vite + Naive UI + Pinia + Vue Router
- 数据获取全部通过 sdk-wasm，不直接调用 HTTP API
- 不使用 Options API（统一 Composition API）
- Commit scope：layout | chat | kanban | progress | artifact | settings | sdk | stores | common

### 1.3 提交规范

遵循 `docs/design/实施计划书写规范.md` §前置条件 3 的 commit 格式。

### 1.4 工具链准备

```bash
node --version    # >= 18
npm --version     # >= 9
```

## 二、技术风险评估

| 风险 | 影响 | 是否需要 Spike | 缓解方式 |
|------|------|---------------|---------|
| sdk-wasm 在 Vite 中的加载方式 | 中 | 否 | Vite 原生支持 WASM import；sdk-wasm 提供 init() 入口 |
| Naive UI 与自定义主题冲突 | 低 | 否 | Naive UI 支持 CSS Variables 主题覆盖 |
| 虚拟滚动与消息气泡高度不一致 | 中 | 否 | vue-virtual-scroller 支持动态高度（estimateSize） |

## 五、回退规则

| 阶段 | 回退触发条件 | 回退目标 |
|------|------------|---------|
| 阶段 1 | Naive UI 与 Vite 版本不兼容 | 概要设计，评估换 Element Plus 或 Headless UI |
| 阶段 2 | sdk-wasm 类型与 TS 类型不一致 | 详细设计，对齐 types/ 与 sdk-models |
| 阶段 3 | sdk-wasm 未就绪导致无法集成 | 继续使用 Mock 数据开发；sdk-wasm 就绪后切换 |
| 阶段 4 | vue-virtual-scroller 与 Naive UI 冲突 | 评估 @tanstack/virtual 或自研虚拟滚动 |
| 阶段 5 | 包体积超过 500KB | 分析 bundle（rollup-plugin-visualizer）；拆分 chunk |

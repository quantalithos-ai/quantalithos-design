# quantalithos-chat 详细设计

> 聊天前端 — Vue 3 + Vite，飞书式三栏布局，通过 sdk-wasm 与平台交互

---

## 一、技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 响应式 UI |
| 构建 | Vite | 快速开发 + HMR |
| UI 库 | Naive UI | Vue 3 原生组件库 |
| 状态管理 | Pinia | Vue 3 官方推荐 |
| SDK | @quantalithos/sdk-wasm | Rust → WASM，API 调用 |
| 路由 | Vue Router | SPA 路由 |
| 样式 | CSS Variables + Scoped CSS | 主题切换 |
| Phase 2 | Tauri | 桌面端（直接调用 sdk Rust） |

## 三、核心组件设计

### 3.1 GateCard（门禁审批卡片）

```vue
<!-- components/chat/GateCard.vue -->
<template>
  <div class="gate-card" :class="{ pending: !responded }">
    <div class="gate-header">
      <span class="gate-icon">🔒</span>
      <span class="gate-title">{{ gate.title }}</span>
      <span class="gate-timeout" v-if="gate.timeout">⏰ {{ remainingTime }}</span>
    </div>
    <div class="gate-desc">{{ gate.description }}</div>
    <div class="gate-artifacts" v-if="gate.artifacts?.length">
      <div v-for="a in gate.artifacts" :key="a.id" class="artifact-link">
        📄 {{ a.name }}
      </div>
    </div>
    <div class="gate-actions" v-if="!responded">
      <button class="btn-approve" @click="respond('approve')">✅ 确认通过</button>
      <button class="btn-reject" @click="respond('request_changes')">❌ 需要修改</button>
    </div>
    <div class="gate-result" v-else>
      {{ responded === 'approve' ? '✅ 已通过' : '❌ 已驳回' }}
    </div>
  </div>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { respondGate } from '../../sdk'

const props = defineProps<{ gate: GateCardData }>()
const responded = ref<string | null>(null)

async function respond(action: string) {
  await respondGate(props.gate.id, action)
  responded.value = action
}
</script>
```

### 3.2 PipelineBar（进度条）

```vue
<!-- components/progress/PipelineBar.vue -->
<template>
  <div class="pipeline-bar">
    <div v-for="(node, i) in progress.nodes" :key="node.id" class="pipeline-node">
      <div class="node-dot" :class="node.status">
        {{ node.status === 'completed' ? '✓' : i + 1 }}
      </div>
      <div class="node-label">{{ node.name }}</div>
      <div class="node-line" v-if="i < progress.nodes.length - 1"
           :class="node.status === 'completed' ? 'done' : ''"></div>
    </div>
  </div>
</template>

<script setup lang="ts">
import type { PipelineProgress } from '../../types/views'
defineProps<{ progress: PipelineProgress }>()
</script>
```

### 3.3 数据流

```
用户操作 → Pinia Store → sdk-wasm → gate → platform/flow/runtime
                ↑                                    │
                └────────────── 响应 ─────────────────┘

Phase 1（轮询）：
  Store 定时调用 sdk-wasm API 刷新数据

Phase 2（WebSocket）：
  sdk-wasm 建立 WS 连接 → 收到事件 → 更新 Store → Vue 响应式更新 UI
```

## 四、Phase 分期

### Phase 1

| 模块 | 范围 |
|------|------|
| 布局 | 三栏布局（NavBar + ConvList + MainContent） |
| 聊天 | Assistant 私聊 + 项目群聊 + 消息收发（轮询） |
| 门禁 | GateCard 渲染 + 审批操作 |
| 看板 | KanbanBoard（按状态分组） |
| 进度 | PipelineBar + StageFlow（SVG） |
| SDK | initSdk + 核心 API 封装 |

Phase 1 不实现：WebSocket 实时推送、Tauri 桌面端、产物预览、Agent 配置页

### Phase 2

| 模块 | 范围 |
|------|------|
| WebSocket | 实时消息推送（替换轮询） |
| 流式输出 | Agent 回复流式渲染 |
| Tauri | 桌面端打包 |
| 产物 | 产物预览（Markdown/代码/图片） |
| 设置 | Agent 配置 + 项目设置 |

排他网关 Phase 1
Exclusive Gateway (XOR)
只走一条分支。评估条件，走第一个为 true 的出口。都不满足走 default。合并时任一分支到达即通过。
场景：代码审查通过/打回、测试通过/失败、门禁确认/驳回

并行网关 Phase 2
Parallel Gateway (AND)
分支时：同时启动所有出口分支（token 分裂）。合并时：等待所有入口分支完成才通过（token 合并）。
场景：多任务并行执行（TASK-003 和 TASK-004 无依赖，同时开发）

包含网关 Phase 3
Inclusive Gateway (OR)
分支时：评估所有条件，走所有为 true 的出口（可能走 1 条也可能走多条）。合并时：等待所有已激活的分支到达。
场景：根据风险等级，可能同时触发安全审查 + 性能测试 + 合规检查（满足哪些条件就走哪些分支）

事件网关 Phase 3
Event-based Gateway
流程暂停，等待多个事件中的第一个到达，由到达的事件决定走哪条分支。和 Exclusive 的区别：XOR 评估数据条件，Event-based 等待外部事件。
场景：发布后等待：用户确认"继续" 或 监控告警触发 或 超时 — 哪个先到走哪条路

Message Flow

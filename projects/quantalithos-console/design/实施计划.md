# quantalithos-console 实施计划

> 云端管理后台 — Vue 3 + Vite + Naive UI + Monaco Editor + sdk-wasm
> 关联详细设计：`projects/quantalithos-console/design/详细设计.md`

---

## 一、前置条件

> **必须先阅读** `docs/design/实施计划书写规范.md` §二-A 前置条件，完成 Git 仓库初始化和通用前置检查。

### 1.1 必读文档

| 文档 | 阅读目的 |
|------|---------|
| projects/quantalithos-console/design/概要设计.md | 理解功能模块、层间约束、技术选型 |
| projects/quantalithos-console/design/详细设计.md | 理解组件设计、数据流、代码骨架 |
| projects/quantalithos-sdk/design/详细设计.md §四 | 理解 sdk-wasm 的 JS 桥接 API |
| projects/quantalithos-chat/design/详细设计.md | 参照 chat 的 SDK 集成方式（技术栈相同） |

### 1.2 编码约束

- 语言：TypeScript + Vue 3 SFC，代码全英文
- 框架：Vue 3 + Vite + Naive UI + Pinia + Vue Router
- 数据获取全部通过 sdk-wasm，不直接调用 HTTP API
- 不使用 Options API（统一 Composition API）
- Commit scope：layout | project | workitem | agent-config | flow | artifact | sandbox | monitoring | settings | sdk | stores | common

### 1.3 提交规范

遵循 `docs/design/实施计划书写规范.md` §前置条件 3 的 commit 格式。

### 1.4 工具链准备

```bash
node --version    # >= 18
npm --version     # >= 9
```

| 风险 | 影响 | 是否需要 Spike | 缓解方式 |
|------|------|---------------|---------|

## 五、回退规则

| 阶段 | 回退触发条件 | 回退目标 |
|------|------------|---------|
| 阶段 1 | Naive UI 与 Vite 版本不兼容 | 概要设计，评估换 Element Plus |
| 阶段 2 | console 与 chat 类型定义不一致 | 详细设计，统一 types/ 或从 sdk-wasm 自动生成 |
| 阶段 3 | Monaco Editor Vite 集成失败 | 评估 CodeMirror 6 替代 |
| 阶段 3 | 5 个模块开发量超预期 | 缩减 Phase 1 范围（只做项目+工单+Agent 配置） |
| 阶段 4 | 乐观锁冲突检测不可靠 | 改为悲观锁（编辑时锁定资源，Phase 2） |
| 阶段 5 | 首屏包体积超过 600KB | 分析 bundle；拆分 chunk；评估去掉 Naive UI 部分组件 |

# quantalithos-console 概要设计

> 云端管理后台 — 项目管理、Agent 配置、流程编辑、产物管理、设计系统、监控

---

## 一、项目定位

### 1.1 核心职责

quantalithos-console 是平台的管理配置入口，面向管理员和项目负责人。

```
chat vs console：

  chat（日常协作）                    console（管理配置）
  ─────────────                      ──────────────────
  和 Agent 聊天                       配置 Agent 角色
  看 Agent 执行过程                   编辑流程模板
  审批门禁                            管理工单和产物
  查看项目进度                        监控系统状态
  
  用户每天用                          管理员按需用
  实时交互                            CRUD 管理
```

### 1.2 在整体架构中的位置

```
quantalithos-chat (聊天)    quantalithos-console (管理)
      │                              │
      │ sdk-wasm                     │ sdk-wasm
      └──────────┬───────────────────┘
                 │
      quantalithos-sdk
                 │
                 │ HTTP/WebSocket
                 ▼
      quantalithos-gate (API 网关)
                 │
      ┌──────────┼──────────┐
      ▼          ▼          ▼
   platform    flow      runtime
```

### 1.3 和 chat 的关系

| 维度 | chat | console |
|------|------|---------|
| 用户 | 所有用户 | 管理员 / 项目负责人 |
| 场景 | 日常协作（聊天、审批、看执行） | 管理配置（配置、编辑、监控） |
| 技术栈 | Vue 3 + Vite + Naive UI + sdk-wasm | 相同 |
| 共享 | sdk-wasm（API 调用） | 相同 |
| 部署 | 独立部署（:3000） | 独立部署（:3001） |

## 二、功能模块

### 2.1 项目管理

- 项目列表（创建 / 归档 / 删除 / 筛选）
- 项目详情（基本信息 / 成员管理 / 配置）
- 项目仪表盘（进度概览 / 工单统计 / 产物统计 / Agent 活跃度）

### 2.2 工单管理

- 工单列表（筛选 / 搜索 / 批量操作）
- 看板视图（按状态分列 / 拖拽流转）
- 工单详情（状态历史 / 评论 / 关联产物 / 依赖关系）
- 依赖图可视化（DAG 图，显示任务间依赖和执行波次）

### 2.3 Agent 配置中心

- 角色定义管理（YAML 编辑器 + 实时预览 + 语法校验）
- 共享规则管理（启用 / 禁用 / 编辑 / 按项目覆盖）
- 三级覆盖可视化（system → company → project 合并结果预览）
- Agent 运行状态（在线 / 执行中 / 挂起 / 状态栈查看）

### 2.4 流程模板管理

- 流程模板列表（pipeline / stage / agent 分类）
- BPMN 流程图查看器（Phase 2：只读渲染）
- BPMN 流程图编辑器（Phase 3：可视化拖拽编辑节点和边）
- 流程模板版本管理（版本历史 / diff / 回滚）
- 流程实例监控（当前运行中的流程 + Token 状态 + 节点执行进度）

### 2.5 产物管理

- 产物列表（按项目 / 类型 / 标签筛选）
- 产物预览（Markdown 渲染 / 代码高亮 / JSON 格式化 / 图片）
- 版本历史（diff 对比 / 回滚）
- 产物关系图（来源追踪：哪个节点产出 / 哪个任务引用）

### 2.6 设计系统（Phase 3）

- Design Tokens 管理（颜色 / 字体 / 间距 / 圆角 / 主题）
- 组件库管理（组件定义 / 变体 / 实时预览）
- 原型管理（原型列表 / 预览 / 版本）
- 未来：内置原型编辑器 或 集成 Penpot

### 2.7 用户与权限

- 用户管理（创建 / 禁用 / 角色分配）
- 角色权限（admin / user / viewer）
- API Token 管理（创建 / 吊销 / 权限范围）
- 操作审计日志（谁在什么时候做了什么）

### 2.8 系统监控

- 服务健康状态（platform / flow / runtime / gate 的 /health 端点）
- LLM 调用统计（token 消耗 / 成本 / 平均延迟 / 错误率）
- Agent 执行统计（任务完成率 / 平均耗时 / 重试率）
- 错误日志（最近错误 / 按服务筛选 / 详情查看）

### 2.9 系统设置

- 全局配置（LLM 模型选择 / API Key / 默认参数）
- 事件总线配置（Phase 1 进程内 / Phase 2 Redis）
- 存储配置（MinIO / S3 连接信息）
- 通知配置（邮件 / Webhook）

## 三、技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue 3 + Composition API | 和 chat 一致 |
| 构建 | Vite | 和 chat 一致 |
| UI 库 | Naive UI | 和 chat 一致，丰富的表格/表单/图表组件 |
| 状态管理 | Pinia | 和 chat 一致 |
| SDK | @quantalithos/sdk-wasm | 和 chat 共享 |
| 图表 | ECharts | 监控仪表盘 |
| 代码编辑 | Monaco Editor | YAML 编辑器（角色定义 / 流程模板） |
| 流程图 | Vue Flow | BPMN 流程图渲染和编辑（Phase 3） |
| Markdown | markdown-it | 产物预览 |
| 代码高亮 | Shiki | 产物预览 |

## 四、Phase 分期

### Phase 2（console 首版）

| 模块 | 范围 |
|------|------|
| 项目管理 | 列表 + 详情 + 仪表盘 |

| 监控 | 服务健康 + LLM 统计 + Agent 统计 |

| 模块 | 范围 |
|------|------|
| 流程编辑器 | BPMN 可视化拖拽编辑（Vue Flow） |
| 设计系统 | Design Tokens + 组件库 + 原型管理 |
| 用户权限 | 用户管理 + RBAC + API Token + 审计日志 |
| 系统设置 | 全局配置 + 存储配置 + 通知配置 |

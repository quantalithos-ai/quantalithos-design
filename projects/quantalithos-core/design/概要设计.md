# quantalithos-core 概要设计

> 核心共享库 — 语言无关的协议定义 + Python BPMN 引擎 + 共享数据模型

## 一、项目定位

### 1.1 核心职责

quantalithos-core 是所有子项目的公共基础，包含：

- **schemas/**：语言无关的协议定义（JSON Schema），Rust 和 Python 项目都从这里生成/对齐数据结构
- **python/**：Python 端共享实现（BPMN 引擎 + 通信协议 + 数据模型），flow 和 runtime 共同依赖
- **rust/**：Rust 端共享数据模型（Phase 2，和 sdk-models 对齐）

```
                    quantalithos-core
                    ┌─────────────────────────────────────┐
                    │                                     │
                    │  schemas/          语言无关定义       │
                    │  (JSON Schema)     所有项目对齐       │
                    │                                     │
                    │  python/           Python 实现        │
                    │  ├── bpmn/         BPMN 引擎         │
                    │  ├── protocol/     通信协议           │
                    │  └── models/       数据模型           │
                    │                                     │
                    │  rust/             Rust 实现(Phase 2) │
                    │  └── models/       数据模型           │
                    │                                     │
                    └──────────┬──────────────────────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
              ▼                ▼                ▼
         flow (Python)    runtime (Python)   sdk (Rust)
         依赖 python/     依赖 python/       对齐 schemas/
```

### 1.2 与 sdk 的区别

```
core = 定义"是什么"（协议、模型、引擎）
sdk  = 实现"怎么用"（API 客户端、WebSocket、状态管理）

core 的消费者：flow、runtime（Python）+ sdk（对齐 schemas）
sdk 的消费者：chat、sync、gate（Rust）

两者不重叠。
```

## 三、BPMN 引擎设计

### 3.1 抽象层（visitor 模式）

```python
# bpmn/models.py

class NodeCategory(str, Enum):
    EVENT = "event"
    ACTIVITY = "activity"
    GATEWAY = "gateway"

class FlowNode(BaseModel):
    """BPMN 节点抽象基类"""
    id: str
    category: NodeCategory
    name: str = ""
    status: str = "pending"

    def accept(self, visitor: "NodeVisitor") -> Any:
        return visitor.visit(self)

class EventNode(FlowNode):
    category: NodeCategory = NodeCategory.EVENT
    event_position: str        # start | intermediate | end | boundary
    event_trigger: str = "none"

class ActivityNode(FlowNode):
    category: NodeCategory = NodeCategory.ACTIVITY
    task_type: str = "abstract"
    sub_process_type: Optional[str] = None
    actor: Optional[str] = None
    action: Optional[str] = None

class GatewayNode(FlowNode):
    category: NodeCategory = NodeCategory.GATEWAY
    gateway_type: str          # exclusive | parallel | inclusive
    direction: str = "diverging"
    condition_field: Optional[str] = None
    default_route: Optional[str] = None
```

### 3.2 引擎核心

```python
# bpmn/engine.py

class BPMNEngine:
    """BPMN 流程引擎 — flow 和 runtime 共享"""

    def __init__(self, visitor: NodeVisitor):
        self.visitor = visitor

    async def run(self, process_def: ProcessDefinition, instance: ProcessInstance):
        """按 nodes + edges 驱动流程执行"""
        current_node = self.find_start(process_def)

        while current_node:
            instance.node_states[current_node.id] = "running"

            # visitor 模式：不同的消费者提供不同的 visitor 实现
            result = await current_node.accept(self.visitor)

            instance.node_states[current_node.id] = "completed"
            if result:
                instance.node_outputs[current_node.id] = result

            # 找下一个节点
            current_node = self.find_next(process_def, instance, current_node)

    def find_next(self, process_def, instance, current_node) -> Optional[FlowNode]:
        """按 edges 找下一个节点（处理条件分支）"""
        outgoing = [e for e in process_def.edges if e["source"] == current_node.id]

        if current_node.category == NodeCategory.GATEWAY:
            return self.evaluate_gateway(process_def, instance, current_node, outgoing)

        # 普通节点：走第一条 sequence edge
        for edge in outgoing:
            if edge.get("flow_type", "sequence") == "sequence":
                return self.get_node(process_def, edge["target"])

        return None  # 没有出口 = 流程结束
```

### 3.3 visitor 接口

```python
# bpmn/visitor.py

class NodeVisitor(ABC):
    """节点访问者接口 — flow 和 runtime 各自实现"""

    @abstractmethod
    async def visit_event(self, node: EventNode) -> Optional[dict]:
        """处理事件节点"""

    @abstractmethod
    async def visit_activity(self, node: ActivityNode) -> Optional[dict]:
        """处理活动节点"""

    @abstractmethod
    async def visit_gateway(self, node: GatewayNode) -> Optional[dict]:
        """处理网关节点"""

    async def visit(self, node: FlowNode) -> Optional[dict]:
        match node.category:
            case NodeCategory.EVENT:
                return await self.visit_event(node)
            case NodeCategory.ACTIVITY:
                return await self.visit_activity(node)
            case NodeCategory.GATEWAY:
                return await self.visit_gateway(node)
```

### 3.4 flow 和 runtime 的 visitor 实现

```
flow 的 visitor（FlowNodeVisitor）：
  visit_event:
    start → 推进到下一个节点
    end → 流程完成，推进阶段
  visit_activity:
    task → 构造 FlowMessage 发给 runtime
    user → 创建门禁审批
    ad_hoc → 发 session_start
    call_activity → 启动子流程
  visit_gateway:
    exclusive → 条件求值，选择分支
    parallel → 同时启动所有分支

runtime 的 visitor（AgentNodeVisitor）：
  visit_event:
    start → 跳过
    end → 工作流完成
  visit_activity:
    abstract → 注入 action 到 prompt，Agent think→act，等待 step_complete
  visit_gateway:
    exclusive → 读取上一步 step_complete 的结果，选择分支
```

## 四、通信协议

# protocol/flow_message.py

class FlowMessage(BaseModel):
    """flow → runtime 统一消息"""
    message_id: str
    type: str              # agent_create | task_assign | session_start | chat_message | ...
    agent_id: str
    project_id: str
    payload: dict
    created_at: datetime

class NodeResult(BaseModel):
    """runtime → flow 执行结果"""
    message_id: str
    agent_id: str
    result_type: str       # completed | blocked | failed
    output: Optional[dict] = None
    reason: Optional[str] = None
    reasoning_trace: Optional[str] = None
    duration_ms: int = 0
    tool_call_count: int = 0
    total_tokens: int = 0
    created_at: datetime

## 五、Phase 分期

### Phase 1

| 模块 | 范围 |
|------|------|
| schemas/ | FlowMessage + NodeResult + ProcessDefinition + RoleDefinition + SharedRule |
| bpmn/models | EventNode(start/end) + ActivityNode(abstract/user/ad_hoc) + GatewayNode(exclusive) |
| bpmn/engine | 基础引擎（线性遍历 + exclusive 条件分支） |
| bpmn/visitor | NodeVisitor 接口 |
| protocol/ | FlowMessage + NodeResult |
| models/ | RoleDefinition + SharedRule + WorkItem |

### Phase 2

| 模块 | 范围 |
|------|------|
| bpmn/models | EventNode(boundary/intermediate) + ActivityNode(service/script/call_activity) + GatewayNode(parallel) |
| bpmn/engine | Parallel Gateway（Token 分裂/合并）+ Call Activity（子流程） |
| rust/models | 和 schemas/ 对齐的 Rust struct |

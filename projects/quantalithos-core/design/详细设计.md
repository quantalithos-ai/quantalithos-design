| 文件 | 职责 | 主要消费者 |

| bpmn/process.py | ProcessDefinition 流程定义 + YAML 加载 | flow, runtime |
| bpmn/engine.py | BPMNEngine 流程驱动（visitor 模式） | flow, runtime |

| bpmn/gateway.py | GatewayEvaluator 条件求值 | flow, runtime |
| protocol/flow_message.py | FlowMessage 统一消息 | flow（构造）, runtime（接收） |
| protocol/node_result.py | NodeResult 执行结果 | runtime（构造）, flow（接收） |
| models/role.py | RoleDefinition 角色定义 | runtime |
| models/rule.py | SharedRule 共享规则 | runtime |
| models/workitem.py | WorkItem 工单模型 | flow, runtime, platform |
| models/artifact.py | Artifact 产物模型 | flow, runtime, platform |

### 1.2 设计原则

- **零业务逻辑**：core 不知道 TDD、不知道博客项目、不知道 Agent 池。它只定义数据结构和引擎接口
- **语言无关**：schemas/ 是 Python 和 Rust 的共同基准，Python Pydantic 模型是权威实现
- **向后兼容**：ProcessDefinition 带 version 字段，消费者可按版本加载
- **visitor 模式**：BPMNEngine 不包含任何节点处理逻辑，全部委托给 NodeVisitor 实现

### 2.2 FlowNode 基类

```python
class FlowNode(BaseModel):
    """BPMN 节点抽象基类"""
    id: str                          # 节点唯一 ID，ProcessDefinition 内唯一
    category: NodeCategory           # 节点类别（子类固定值）
    name: str = ""                   # 显示名称（自然语言）

    def accept(self, visitor: "NodeVisitor") -> Any:
        """visitor 模式入口"""
        return visitor.visit(self)
```

`status` 不在 FlowNode 上定义——它是运行时状态，由消费者的 ProcessInstance 管理（`instance.node_states[node.id]`）。

### 2.3 EventNode

```python
class EventNode(FlowNode):
    """事件节点 — 流程的开始、结束、中间事件"""

    event_trigger: EventTrigger = EventTrigger.NONE
```

| 类型 | Phase 1 | Phase 2 |

| end(none) | ✅ | ✅ |
| end(terminate) | ✅ | ✅ |
| end(error) | ✅ | ✅ |
| boundary(error) | — | ✅ |

```python
class ActivityNode(FlowNode):
    """活动节点 — 任务执行、门禁、协作会议、子流程"""
```

### 2.7 ProcessDefinition

```python
# bpmn/process.py

class ProcessDefinition(BaseModel):
    """BPMN 2.0 流程定义"""
    process_id: str                  # 全局唯一（如 "tdd_workflow"）
    name: str
    description: str = ""
    version: str = "1.0.0"           # 语义化版本
    nodes: List[FlowNode]            # discriminated union（按 category 反序列化）
    edges: List[FlowEdge]
    data_objects: List[dict] = []    # Phase 2
    artifacts: List[dict] = []       # Phase 2
    pool: Optional[dict] = None      # Phase 2
    created_by: str = "system"
    created_at: Optional[datetime] = None

    @validator("nodes", pre=True)
    def parse_nodes(cls, v):
        """按 category 字段反序列化为正确的子类型"""
        result = []
        for item in v:
            if isinstance(item, FlowNode):
                result.append(item)
                continue
            category = item.get("category")
            match category:
                case "event":    result.append(EventNode(**item))
                case "activity": result.append(ActivityNode(**item))
                case "gateway":  result.append(GatewayNode(**item))
                case _: raise ValueError(f"未知的 category: {category}")
        return result

    def get_node(self, node_id: str) -> Optional[FlowNode]:
        """按 ID 查找节点"""
        for node in self.nodes:
            if node.id == node_id:
                return node
        return None

    def get_outgoing_edges(self, node_id: str) -> List[FlowEdge]:
        """获取节点的所有出口边"""
        return [e for e in self.edges if e.source == node_id]

    def get_incoming_edges(self, node_id: str) -> List[FlowEdge]:
        """获取节点的所有入口边"""
        return [e for e in self.edges if e.target == node_id]

    def find_start_node(self) -> Optional[EventNode]:
        """找到 start 事件节点"""
        for node in self.nodes:
            if isinstance(node, EventNode) and node.event_position == EventPosition.START:
                return node
        return None

    @classmethod
    def from_yaml(cls, path: str) -> "ProcessDefinition":
        """从 YAML 文件加载"""
        with open(path) as f:
            data = yaml.safe_load(f)
        return cls(**data)

    @classmethod
    def from_dict(cls, data: dict) -> "ProcessDefinition":
        """从字典加载（platform API 返回时用）"""
        return cls(**data)
```

nodes 字段使用 `@validator` 实现 discriminated union：YAML/JSON 中 nodes 是 dict 列表，按 `category` 字段自动反序列化为 EventNode / ActivityNode / GatewayNode。

## 五、BPMN 引擎核心

### 5.1 NodeVisitor 接口

```python
# bpmn/visitor.py

class NodeVisitor(ABC):
    """节点访问者接口 — flow 和 runtime 各自实现"""

    @abstractmethod
    async def visit_event(self, node: EventNode) -> Optional[dict]:
        """处理事件节点，返回 None（事件节点通常无产出）"""

    @abstractmethod
    async def visit_activity(self, node: ActivityNode) -> Optional[dict]:
        """处理活动节点，返回执行产出（存入 node_outputs）"""

    @abstractmethod
    async def visit_gateway(self, node: GatewayNode) -> Optional[dict]:
        """处理网关节点，返回 None（网关不产出，只路由）"""

    async def visit(self, node: FlowNode) -> Optional[dict]:
        """按 category 分发到具体方法"""
        match node.category:
            case NodeCategory.EVENT:
                return await self.visit_event(node)
            case NodeCategory.ACTIVITY:
                return await self.visit_activity(node)
            case NodeCategory.GATEWAY:
                return await self.visit_gateway(node)
```

返回值契约：`Optional[dict]` 是节点的执行产出，由 BPMNEngine 存入 `instance.node_outputs[node.id]`，供后续节点的 `input_refs` 和网关条件求值使用。返回 `None` 表示无产出。

### 5.2 flow 侧 visitor 职责映射

flow 的 `NodeDispatcher` 实现 NodeVisitor 模式：

| visitor 方法 | 节点类型 | flow 行为 |
|-------------|---------|----------|
| visit_event | start(none) | 直接推进到下一节点 |
| visit_event | end(none/terminate) | 流程实例完成，通知 on_process_completed |
| visit_activity | abstract/service/script | 构造 task_assign FlowMessage → runtime |
| visit_activity | user | 创建门禁 GateRequest → 等待用户操作 |
| visit_activity | ad_hoc | 构造 session_start FlowMessage → runtime |
| visit_activity | call_activity | 启动子流程 ProcessInstance |
| visit_gateway | exclusive/diverging | GatewayEvaluator 条件求值，选择一条出口 |
| visit_gateway | parallel/diverging | 同时启动所有出口分支（Phase 2） |
| visit_gateway | parallel/converging | 检查所有入口分支是否完成（Phase 2） |

### 5.3 runtime 侧 visitor 职责映射

runtime 的 `AgentNodeVisitor` 实现 NodeVisitor 模式（仅 Level 3 Enforced 使用）：

| visitor 方法 | 节点类型 | runtime 行为 |
|-------------|---------|-------------|
| visit_event | start | 跳过，推进到下一节点 |
| visit_event | end | 工作流完成，返回最终 output |
| visit_activity | abstract | 注入 action 到 prompt → Agent think→act 循环 → 等待 step_complete 或 submit_step_result |
| visit_gateway | exclusive/diverging | 读取上一步 output，按条件选择分支 |

runtime 不使用：parallel gateway、call_activity、user task、ad_hoc — 这些是 flow 的职责。

### 5.4 BPMNEngine

```python
# bpmn/engine.py

class BPMNEngine:
    """BPMN 流程引擎 — 按 nodes + edges 驱动流程执行"""

    def __init__(self, visitor: NodeVisitor):
        self.visitor = visitor

    async def run(self, process_def: ProcessDefinition, instance) -> None:
        """
        驱动流程执行，直到 end 节点或无出口。

        instance 参数：duck typing，需要有以下字段：
          - node_states: Dict[str, str]   节点状态
          - node_outputs: Dict[str, dict] 节点产出
        """
        current_node = process_def.find_start_node()
        if current_node is None:
            raise ProcessDefinitionError(
                f"ProcessDefinition '{process_def.process_id}' 没有 start 节点"
            )

        while current_node is not None:
            instance.node_states[current_node.id] = "running"

            # visitor 模式：委托给消费者实现
            result = await current_node.accept(self.visitor)

            instance.node_states[current_node.id] = "completed"
            if result is not None:
                instance.node_outputs[current_node.id] = result

            # end 节点：流程结束
            if (isinstance(current_node, EventNode)
                    and current_node.event_position == EventPosition.END):
                break

            current_node = self._find_next(process_def, instance, current_node)

    def _find_next(
        self,
        process_def: ProcessDefinition,
        instance,
        current_node: FlowNode,
    ) -> Optional[FlowNode]:
        """按 edges 找下一个节点"""
        outgoing = process_def.get_outgoing_edges(current_node.id)

        if isinstance(current_node, GatewayNode):
            return self._evaluate_gateway(process_def, instance, current_node, outgoing)

        # 普通节点：走第一条 sequence/default 边
        for edge in outgoing:
            if edge.flow_type in (EdgeType.SEQUENCE, EdgeType.DEFAULT):
                return process_def.get_node(edge.target)

        return None  # 无出口 = 流程结束

    def _evaluate_gateway(
        self,
        process_def: ProcessDefinition,
        instance,
        gateway: GatewayNode,
        outgoing: List[FlowEdge],
    ) -> Optional[FlowNode]:
        """网关路由（委托给 GatewayEvaluator）"""
        evaluator = GatewayEvaluator()
        next_node_id = evaluator.evaluate(gateway, outgoing, instance.node_outputs)
        if next_node_id:
            return process_def.get_node(next_node_id)
        return None
```

### 5.5 ProcessInstance 协议

core 不定义 ProcessInstance — flow 和 runtime 各自有不同的实现：

- flow 的 ProcessInstance 有 `parent_instance_id`、`edge_history`、`created_at`、`updated_at`
- runtime 的 WorkflowEngine 用一个简单的 dict（`{"node_states": {}, "node_outputs": {}}`）

BPMNEngine 通过 duck typing 接受任何有 `node_states` 和 `node_outputs` 属性的对象：


## 六、网关条件求值

### 6.1 GatewayEvaluator

```python
# bpmn/gateway.py

class GatewayEvaluator:
    """网关条件求值器"""

    def evaluate(
        self,
        gateway: GatewayNode,
        outgoing: List[FlowEdge],
        node_outputs: dict,
    ) -> Optional[str]:
        """返回应该走的下一个节点 ID"""
        match gateway.gateway_type:
            case GatewayType.EXCLUSIVE:
                return self._evaluate_exclusive(gateway, outgoing, node_outputs)
            case GatewayType.PARALLEL:
                raise UnsupportedGatewayType("Parallel Gateway 在 Phase 2 实现")
            case _:
                raise UnsupportedGatewayType(f"不支持的网关类型: {gateway.gateway_type}")
```

### 6.2 排他网关求值

```python
    def _evaluate_exclusive(
        self,
        gateway: GatewayNode,
        outgoing: List[FlowEdge],
        node_outputs: dict,
    ) -> str:
        """排他网关：逐一检查条件边，返回第一个匹配的目标节点 ID"""

        # 1. 检查有条件的边
        for edge in outgoing:
            if edge.flow_type == EdgeType.CONDITIONAL and edge.condition:
                if self._eval_condition(edge.condition, node_outputs):
                    return edge.target

        # 2. 走 default 边
        for edge in outgoing:
            if edge.flow_type == EdgeType.DEFAULT:
                return edge.target

        # 3. 走 gateway.default_route
        if gateway.default_route:
            return gateway.default_route

        raise NoMatchingCondition(
            f"Gateway '{gateway.id}' 没有匹配的条件，也没有 default 边"
        )
```

### 6.3 条件表达式求值

```python
    def _eval_condition(self, condition: str, node_outputs: dict) -> bool:
        """
        Phase 1：简单字符串匹配（== 和 !=）
        Phase 2：表达式引擎

        condition 格式示例：
          "verdict == 'approved'"
          "is_bug != true"
          "review_prd.verdict == 'needs_revision'"
        """
        # 解析 field_path op value
        match = re.match(r"^([\w.]+)\s*(==|!=)\s*['\"]?(.+?)['\"]?$", condition.strip())
        if not match:
            raise InvalidCondition(f"无法解析条件: {condition}")

        field_path, op, expected = match.groups()

        # 解析字段路径
        actual = self._resolve_field(field_path, node_outputs)

        # 比较
        if op == "==":
            return str(actual) == expected
        elif op == "!=":
            return str(actual) != expected

        return False

    def _resolve_field(self, field_path: str, node_outputs: dict) -> Any:
        """
        解析字段路径，从 node_outputs 中取值。

        路径规则：
          "verdict"                → 在所有 node_outputs 中查找第一个包含 verdict 的
          "review_prd.verdict"     → node_outputs["review_prd"]["verdict"]
          "review_prd.output.verdict" → node_outputs["review_prd"]["output"]["verdict"]
        """
        parts = field_path.split(".")

        if len(parts) == 1:
            # 短路径：在所有 node_outputs 中查找
            for node_id, output in reversed(list(node_outputs.items())):
                if parts[0] in output:
                    return output[parts[0]]
            return None

        # 长路径：第一段是 node_id，后续是嵌套 key
        node_id = parts[0]
        if node_id not in node_outputs:
            return None

        value = node_outputs[node_id]
        for key in parts[1:]:
            if isinstance(value, dict) and key in value:
                value = value[key]
            else:
                return None
        return value
```

### 6.4 Phase 2 表达式引擎预留

Phase 2 将 `_eval_condition` 替换为完整的表达式引擎：

```python
# Phase 2 接口预留
class ExpressionEngine(ABC):
    @abstractmethod
    def evaluate(self, expression: str, context: dict) -> Any:
        """求值表达式，返回结果"""

class SimpleExpressionEngine(ExpressionEngine):
    """Phase 1 的简单实现（== / !=）"""

class FullExpressionEngine(ExpressionEngine):
    """Phase 2 的完整实现（支持 >, <, >=, <=, in, and, or, not）"""
```

## 八、错误类型

```python
# bpmn/errors.py

class CoreError(Exception):
    """core 错误基类"""

class ProcessDefinitionError(CoreError):
    """流程定义错误"""
    # 触发场景：
    #   - 没有 start 节点
    #   - 节点 ID 重复
    #   - 边引用不存在的节点
    #   - nodes 列表为空

class NoMatchingCondition(CoreError):
    """排他网关无匹配条件"""
    # 触发场景：
    #   - exclusive gateway 所有条件边都不匹配
    #   - 且没有 default 边
    #   - 且没有 default_route

class UnsupportedGatewayType(CoreError):
    """不支持的网关类型"""
    # 触发场景：
    #   - Phase 1 使用 parallel gateway
    #   - 使用 inclusive gateway

class InvalidCondition(CoreError):
    """条件表达式格式错误"""
    # 触发场景：
    #   - 条件字符串无法解析（不符合 "field op value" 格式）

class InvalidFlowMessage(CoreError):
    """FlowMessage 格式错误"""
    # 触发场景：
    #   - type 不在 FlowMessageType 枚举中
    #   - payload 缺少必填字段（由消费者校验，core 只提供类型定义）
```

ProcessDefinition 加载时的校验（在 `__init__` 或 validator 中）：

```python
@validator("nodes")
def validate_nodes(cls, v):
    ids = [n.id for n in v]
    if len(ids) != len(set(ids)):
        raise ProcessDefinitionError("节点 ID 重复")
    starts = [n for n in v if isinstance(n, EventNode) and n.event_position == EventPosition.START]
    if len(starts) == 0:
        raise ProcessDefinitionError("缺少 start 节点")
    if len(starts) > 1:
        raise ProcessDefinitionError("多个 start 节点")
    return v

@validator("edges")
def validate_edges(cls, v, values):
    node_ids = {n.id for n in values.get("nodes", [])}
    for edge in v:
        if edge.source not in node_ids:
            raise ProcessDefinitionError(f"边 {edge.id} 的 source '{edge.source}' 不存在")
        if edge.target not in node_ids:
            raise ProcessDefinitionError(f"边 {edge.id} 的 target '{edge.target}' 不存在")
    return v
```

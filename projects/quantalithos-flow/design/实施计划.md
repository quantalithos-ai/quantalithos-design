- 语言：Python 3.11+，代码全英文
- 依赖：quantalithos-core（本地）、httpx、pyyaml、pydantic
- 单线程 asyncio 事件循环（EventLoop 串行处理事件）
- 每个事件处理后立即持久化（崩溃恢复不丢状态）
- Commit scope：daemon | engine | business | infra | tests

## 二、技术风险评估

**结论：不需要 Spike。**

- 依赖 core 的 BPMNEngine（core 先验证）
- HTTP 调用 platform/runtime 是标准操作（httpx 成熟库）
- YAML 文件持久化是最简方案，无风险

**前置依赖：** core 阶段 3 完成（BPMNEngine 可用）后，flow 阶段 3 才能开始。

## 五、回退规则

| 阶段 | 回退触发条件 | 回退目标 |
|------|------------|---------|
| 阶段 2 | YAML 持久化性能不满足（单次 save > 100ms） | 详细设计，评估 SQLite 或 msgpack |
| 阶段 3 | core.BPMNEngine 策略回调无法满足异步需求 | core 详细设计，调整 strategy.execute() 返回值 |
| 阶段 4 | 门禁回退逻辑过于复杂（多层嵌套） | 详细设计 §三点五，Phase 1 只支持回退到前一节点 |
| 阶段 5 | platform 事件监听（SSE/轮询）不稳定 | platform 详细设计，评估 WebSocket 或 Redis Pub/Sub |

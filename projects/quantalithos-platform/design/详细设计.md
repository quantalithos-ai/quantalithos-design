### 3.1 workitem 状态机校验

```rust
// hub-workitem/src/state_machine.rs

/// 状态机校验 — 检查状态流转是否合法
pub fn validate_transition(item_type: &str, from: &str, to: &str) -> Result<(), String> {
    let allowed = match item_type {
        "task" => TASK_TRANSITIONS,
        "requirement" => REQUIREMENT_TRANSITIONS,
        "bug" => BUG_TRANSITIONS,
        _ => return Err(format!("Unknown item_type: {}", item_type)),
    };

    if allowed.contains(&(from, to)) {
        Ok(())
    } else {
        Err(format!("Invalid transition: {} → {} for {}", from, to, item_type))
    }
}

const TASK_TRANSITIONS: &[(&str, &str)] = &[
    ("created", "assigned"),
    ("assigned", "in_progress"),
    ("in_progress", "in_review"),
    ("in_review", "in_testing"),
    ("in_review", "review_rejected"),
    ("in_testing", "completed"),
    ("in_testing", "bug_found"),
    ("review_rejected", "in_progress"),
    ("bug_found", "in_progress"),
];

const BUG_TRANSITIONS: &[(&str, &str)] = &[
    ("open", "confirmed"),
    ("open", "rejected"),
    ("open", "cannot_reproduce"),
    ("confirmed", "fixing"),
    ("fixing", "fixed"),
    ("fixing", "blocked"),
    ("blocked", "fixing"),
    ("fixed", "verifying"),
    ("verifying", "closed"),
    ("verifying", "reopen"),
    ("reopen", "confirmed"),
];

const REQUIREMENT_TRANSITIONS: &[(&str, &str)] = &[
    ("draft", "reviewing"),
    ("reviewing", "approved"),
    ("reviewing", "needs_revision"),
    ("needs_revision", "reviewing"),
    ("approved", "in_progress"),
    ("in_progress", "implemented"),
    ("implemented", "verified"),
    ("implemented", "verify_failed"),
    ("verify_failed", "in_progress"),
    ("verified", "closed"),
];
```

## 四、事件总线

```rust
// hub-common/src/event_bus.rs

use tokio::sync::broadcast;

#[derive(Clone, Debug)]
pub struct PlatformEvent {
    pub event_type: String,           // "WorkItemCreated" | "WorkItemAssigned" | ...
    pub project_id: String,
    pub data: serde_json::Value,
    pub timestamp: chrono::DateTime<chrono::Utc>,
}

pub struct EventBus {
    sender: broadcast::Sender<PlatformEvent>,
}

impl EventBus {
    pub fn new() -> Self {
        let (sender, _) = broadcast::channel(1024);
        Self { sender }
    }

    pub fn publish(&self, event: PlatformEvent) {
        let _ = self.sender.send(event);
    }

    pub fn subscribe(&self) -> broadcast::Receiver<PlatformEvent> {
        self.sender.subscribe()
    }
}
```

## 五、三级覆盖实现

```rust
// hub-agent-config/src/scope_resolver.rs

/// 三级覆盖：project > company > system
pub async fn resolve_role(
    db: &PgPool,
    role_id: &str,
    project_id: Option<&str>,
) -> Result<RoleDefinition, Error> {
    // 1. 项目级（最高优先级）
    if let Some(pid) = project_id {
        if let Some(role) = find_role(db, role_id, "project", Some(pid)).await? {
            return Ok(role);
        }
    }

    // 2. 公司级
    if let Some(role) = find_role(db, role_id, "company", None).await? {
        return Ok(role);
    }

    // 3. 系统级（最低优先级）
    find_role(db, role_id, "system", None).await?
        .ok_or(Error::NotFound(format!("Role {} not found", role_id)))
}
```

## 六、Phase 分期

### Phase 1

| 模块 | 范围 |
|------|------|
| hub-api | axum server + 路由 + 多视图 |
| hub-project | CRUD + 成员管理 |
| hub-workitem | CRUD + 三种状态机 + 自动指派 + 评论 + 依赖 + 历史 |
| hub-artifact | CRUD + 版本管理（结构化产物，不含文件上传） |
| hub-agent-config | 角色/规则/流程模板 CRUD + 三级覆盖 |
| hub-snapshot | Agent 快照 + 工作流快照 CRUD |
| hub-common | 数据库连接池 + 事件总线（进程内）+ 错误类型 |
| migrations | 5 张核心表 |
| seeds | 系统角色 + 共享规则 + 标准流程模板 |

Phase 1 不实现：文件上传（MinIO）、知识库、Redis 事件总线、全文搜索

### Phase 2

| 模块 | 范围 |
|------|------|
| hub-artifact | 文件上传（MinIO/S3） |
| hub-knowledge | 知识库（文档索引、RAG） |
| hub-common | Redis Pub/Sub 事件总线 |
| 全文搜索 | 产物搜索、工单搜索 |

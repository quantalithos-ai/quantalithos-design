- 单线程 asyncio 事件循环（不使用多线程/多进程）
- Commit scope：engine | agent | llm | tools | api | infra | tests

## 二、技术风险评估

**需要 Spike：LLM function calling 验证**

| 风险 | 验证方式 | 通过标准 |
|------|---------|---------|
| Anthropic SDK function calling 返回格式 | 最简脚本调用 Claude API + 工具定义 | tool_calls 包含正确的 name + arguments |
| arguments 是否总是合法 JSON | 10 种工具定义测试 | 100% 可解析 |
| 多轮 think→act 循环稳定性 | 模拟 3 轮循环 | 无异常 |

Spike 代码位置：`spike/llm_function_calling.py`（不合并主干）

## 五、回退规则

| 阶段 | 回退触发条件 | 回退目标 |
|------|------------|---------|
| 阶段 0 | Anthropic function calling 不稳定 | 概要设计，评估换 OpenAI |
| 阶段 3 | LLM 频繁不调用 submit_step_result | 详细设计，调整 prompt 策略 |
| 阶段 4 | asyncio 单线程无法满足并发需求 | 详细设计 §九点八，评估多进程 |
| 阶段 5 | WorkflowEngine 与 core BPMNEngine 集成困难 | core 详细设计，调整策略接口 |

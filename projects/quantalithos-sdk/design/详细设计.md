### 1.1 crate 依赖关系

```
sdk-wasm → sdk-store → sdk-api → sdk-models
                     → sdk-ws  → sdk-models

sdk-models：零依赖（只有 serde/chrono）
sdk-api：依赖 sdk-models + reqwest
sdk-ws：依赖 sdk-models + tokio-tungstenite（Phase 2）
sdk-store：依赖 sdk-models + sdk-api + sdk-ws（Phase 2）
sdk-wasm：依赖 sdk-store + wasm-bindgen
```

## 二、数据模型 — sdk-models

> 对齐 core 的 schemas/ 目录，Rust struct 和 Python Pydantic 模型字段一一对应。
> sdk-models 不依赖网络库，纯 serde 序列化。

### 2.1 项目

```rust
// sdk-models/src/project.rs
//
// 项目数据模型 — 对齐 platform hub-project 的 API 返回格式。
// sdk-models 是纯数据定义（serde 序列化），不包含业务逻辑。
// 前端（chat/console）通过 sdk-wasm 获取这些类型的实例。

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Project {
    pub id: String,                      // 项目唯一标识（如 "blog"）
    pub name: String,                    // 显示名称（如 "博客系统"）
    pub description: String,             // 项目描述
    pub status: ProjectStatus,           // 项目状态
    pub pipeline_process_id: String,     // 关联的 Pipeline 流程模板 ID
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

/// 项目状态枚举 — 与 platform 的 ProjectStatus 一一对应
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum ProjectStatus {
    Active,       // 活跃 — 正在进行中
    Suspended,    // 暂停 — 用户下线或手动暂停
    Completed,    // 完成 — Pipeline 走完所有阶段
    Archived,     // 归档 — 不再显示在活跃列表中
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TeamMember {
    pub id: i64,
    pub project_id: String,
    pub agent_id: String,                // Agent 实例 ID（如 "be-1"）
    pub role_id: String,                 // 角色定义 ID（如 "backend_dev"）
    pub status: String,                  // active | suspended | removed
    pub joined_at: DateTime<Utc>,
}
```

### 2.2 工单

```rust
// sdk-models/src/workitem.rs
//
// 工单数据模型 — 对齐 platform hub-workitem 的 API 返回格式。
// 与 platform 的区别：sdk 用强类型 enum（WorkItemType/Priority），
// platform 用 String（灵活性优先）。sdk 在反序列化时自动转换。

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct WorkItem {
    pub id: String,                      // 工单标识（如 "TASK-003"）
    pub project_id: String,
    pub item_type: WorkItemType,         // 工单类型（强类型 enum）
    pub title: String,                   // 工单标题
    pub description: String,             // 详细描述
    pub status: String,                  // 状态（保持 String — 不同 item_type 状态集不同）
    pub priority: Priority,              // 优先级（强类型 enum）
    pub severity: Option<String>,        // bug 严重程度：critical | major | minor | trivial
    pub assignee_id: Option<String>,     // 当前负责人 Agent ID
    pub reporter_id: String,             // 创建者
    pub verifier_id: Option<String>,     // 验证者（bug 专用）
    pub parent_id: Option<String>,       // 父工单 ID（epic → task 拆分）
    pub labels: Vec<String>,             // 标签列表
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

/// 工单类型 — 三种类型各有独立的状态机
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum WorkItemType { Task, Requirement, Bug }

/// 优先级 — 影响调度顺序（同波次内高优先级先执行）
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum Priority { Critical, High, Medium, Low }

/// 工单状态变更记录 — 用于时间线视图展示
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct WorkItemTransition {
    pub id: i64,
    pub workitem_id: String,
    pub from_status: String,
    pub to_status: String,
    pub triggered_by: String,            // 触发者（Agent ID 或 "system"）
    pub reason: Option<String>,          // 变更原因
    pub created_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct WorkItemComment {
    pub id: i64,
    pub workitem_id: String,
    pub author_id: String,               // 评论者
    pub content: String,                 // 评论内容（Markdown）
    pub created_at: DateTime<Utc>,
}
```

### 2.5 消息与协议

```rust
// sdk-models/src/message.rs — 对齐 core protocol（7 种消息类型）
//
// FlowMessage 和 NodeResult 是 flow ↔ runtime 之间的通信协议。
// sdk 中定义这些类型是为了：
//   1. sync 工具需要读取 FlowMessage 做本地展示
//   2. console 的流程详情页需要展示 NodeResult 统计
//   3. 保持类型一致性（sdk-models 是所有 Rust 客户端的共享类型库）

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FlowMessage {
    pub message_id: String,              // 消息唯一标识（UUID）
    pub r#type: FlowMessageType,         // 消息类型
    pub agent_id: String,                // 目标 Agent ID
    pub project_id: String,              // 所属项目
    pub payload: serde_json::Value,      // 类型化负载（按 type 解析）
    pub created_at: DateTime<Utc>,
}

/// 消息类型枚举 — 与 core 的 FlowMessageType 一一对应
#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum FlowMessageType {
    AgentCreate,     // 创建 Agent 实例
    AgentDestroy,    // 销毁 Agent 实例
    AgentSuspend,    // 挂起 Agent
    AgentResume,     // 恢复 Agent
    NodeExecute,     // 执行 BPMN 节点
    NodeCancel,      // 取消节点执行
    ChatMessage,     // 聊天消息路由
}

/// 执行结果 — runtime 上报给 flow 的节点执行结果
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct NodeResult {
    pub message_id: String,              // 对应的 FlowMessage ID
    pub agent_id: String,                // 执行者
    pub result_type: NodeResultType,     // 结果类型
    pub output: Option<serde_json::Value>, // 执行产出（completed 时）
    pub reason: Option<String>,          // 原因（blocked/failed 时）
    pub reasoning_trace: Option<String>, // 推理链摘要
    pub duration_ms: i64,                // 总执行时长（毫秒）
    pub tool_call_count: i32,            // 工具调用次数
    pub llm_call_count: i32,             // LLM 调用次数
    pub total_tokens: i64,               // Token 总消耗
    pub created_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "snake_case")]
pub enum NodeResultType { Completed, Blocked, Failed }
```

### 2.6 BPMN 节点（流程图渲染用）

```rust
// sdk-models/src/bpmn.rs — 用于前端渲染流程图，不需要引擎逻辑
//
// 与 core 的 FlowNode 继承体系的区别：
//   core 用 Python 类继承（FlowNode → AbstractTask / UserTask / ...）
//   sdk 用 Rust tagged enum（#[serde(tag = "node_type")]）
//   两者 JSON 序列化格式完全一致，可以互相反序列化。
//
// 前端使用场景：
//   console 流程编辑器：读取 ProcessTemplate.definition → 解析为 Vec<FlowNode> + Vec<FlowEdge> → 渲染图
//   chat 进度页：读取 ProgressView.current_stage.nodes → 渲染当前阶段流程图

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(tag = "node_type")]
pub enum FlowNode {
    #[serde(rename = "start_event")]
    StartEvent { id: String, name: String, trigger: String },
    #[serde(rename = "end_event")]
    EndEvent { id: String, name: String, trigger: String },
    #[serde(rename = "abstract_task")]
    AbstractTask { id: String, name: String, actor: Option<String>, action: Option<String> },
    #[serde(rename = "user_task")]
    UserTask { id: String, name: String, gate_config: serde_json::Value },
    #[serde(rename = "ad_hoc_sub_process")]
    AdHocSubProcess { id: String, name: String, coordinator_id: Option<String>, participant_ids: Vec<String>, metadata: serde_json::Value },
    #[serde(rename = "exclusive_gateway")]
    ExclusiveGateway { id: String, name: String, direction: String },
    #[serde(rename = "parallel_gateway")]
    ParallelGateway { id: String, name: String, direction: String },
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FlowEdge {
    pub id: String,
    pub source: String,
    pub target: String,
    pub flow_type: String,
    pub condition: Option<String>,
    pub label: Option<String>,
}
```

### 2.7 视图模型

```rust
// sdk-models/src/views.rs — 对齐 platform 多视图 API 返回格式
//
// 三种视图类型：
```

### 3.1 PlatformClient

```rust
// sdk-api/src/client.rs
//
// Platform API 客户端 — 所有 HTTP 请求的统一入口。
//
// 设计意图：
//   PlatformClient 封装了 HTTP 请求的通用逻辑（认证、错误处理、序列化），
//   各模块 API（ProjectApi / WorkItemApi 等）通过引用 client 发送请求。
//   这样新增 API 只需要添加方法，不需要重复处理 HTTP 细节。
//
// 使用方式：
//   let client = PlatformClient::new("http://gate:8000", "jwt-token");
//   let project = client.projects().get("blog").await?;
//   let items = client.workitems().list("blog").await?;
//
// WASM 环境下的差异：
//   sdk-wasm 中 PlatformClient 使用 web-sys fetch（而非 reqwest），
//   通过 feature flag 切换实现。

pub struct PlatformClient {
    base_url: String,                    // gate 地址（如 "http://localhost:8000"）
    http: reqwest::Client,               // HTTP 客户端（连接池复用）
    token: String,                       // JWT token（每次请求携带 Bearer auth）
}

impl PlatformClient {
    pub fn new(base_url: &str, token: &str) -> Self {
        Self {
            base_url: base_url.to_string(),
            http: reqwest::Client::new(),
            token: token.to_string(),
        }
    }

    pub fn projects(&self) -> ProjectApi { ProjectApi { client: self } }
    pub fn workitems(&self) -> WorkItemApi { WorkItemApi { client: self } }
    pub fn artifacts(&self) -> ArtifactApi { ArtifactApi { client: self } }
    pub fn agent_config(&self) -> AgentConfigApi { AgentConfigApi { client: self } }
    pub fn snapshots(&self) -> SnapshotApi { SnapshotApi { client: self } }

    /// 内部：发送 GET 请求
    pub(crate) async fn get<T: DeserializeOwned>(&self, path: &str) -> Result<T, ApiError> {
        let resp = self.http.get(format!("{}{}", self.base_url, path))
            .bearer_auth(&self.token)
            .send().await?;
        Self::handle_response(resp).await
    }

    /// 内部：发送 POST 请求
    pub(crate) async fn post<T: DeserializeOwned, B: Serialize>(
        &self, path: &str, body: &B
    ) -> Result<T, ApiError> {
        let resp = self.http.post(format!("{}{}", self.base_url, path))
            .bearer_auth(&self.token)
            .json(body)
            .send().await?;
        Self::handle_response(resp).await
    }

    async fn handle_response<T: DeserializeOwned>(resp: reqwest::Response) -> Result<T, ApiError> {
        let status = resp.status();
        if status.is_success() {
            Ok(resp.json().await?)
        } else {
            let body = resp.text().await.unwrap_or_default();
            Err(ApiError::Server { status: status.as_u16(), body })
        }
    }
}
```

### 3.4 错误类型

```rust
// sdk-api/src/error.rs
//
// SDK 错误类型 — 客户端调用 API 时可能遇到的错误。
//
// 错误分类：
//   Http — 网络层错误（连接超时、DNS 解析失败等）
//   Server — 服务端返回非 2xx 状态码（含 status code 和 body）
//   Deserialize — 响应 JSON 解析失败（API 返回格式不符合预期）
//   NotFound — 资源不存在（404 的语义化封装）
//
// 前端处理策略：
//   Http → 提示"网络错误，请检查连接"
//   Server(401) → 跳转登录页
//   Server(429) → 提示"请求过于频繁"
//   Server(4xx) → 展示 body 中的错误信息
//   Server(5xx) → 提示"服务异常，请稍后重试"
//   NotFound → 提示"资源不存在"

#[derive(Debug, thiserror::Error)]
pub enum ApiError {
    #[error("HTTP error: {0}")]
    Http(#[from] reqwest::Error),        // 网络层错误

    #[error("Server error {status}: {body}")]
    Server { status: u16, body: String }, // 服务端错误（非 2xx）

    #[error("Deserialization error: {0}")]
    Deserialize(#[from] serde_json::Error),  // JSON 解析失败

    #[error("Not found: {0}")]
    NotFound(String),                    // 资源不存在（从 Server{404} 提取）
}
```

## 四、WASM 绑定 — sdk-wasm

### 4.1 桥接层设计

```rust
// sdk-wasm/src/lib.rs
//
// WASM 绑定入口 — 初始化 SDK 并提供全局 PlatformClient 实例。
//
// 设计意图：
//   Vue 3 前端通过 wasm-bindgen 调用 Rust SDK，获得类型安全的 API 访问。
//   OnceLock 保证全局只有一个 PlatformClient 实例（单例模式）。
//   init() 必须在所有 API 调用之前调用一次（通常在 Vue app 启动时）。
//
// 为什么用 WASM 而非直接 TypeScript：
//   1. sdk-models 的类型定义只维护一份（Rust），前端自动获得类型安全
//   2. 序列化/反序列化逻辑复用（serde），不需要手写 TS 类型转换
//   3. Phase 2 的 sdk-store（响应式状态管理）可以在 Rust 中实现，性能更好
//   4. Tauri 桌面端可以直接调用 sdk-api（不需要 WASM 层），代码复用

use wasm_bindgen::prelude::*;
use sdk_api::PlatformClient;
use std::sync::OnceLock;

static CLIENT: OnceLock<PlatformClient> = OnceLock::new();

/// 初始化 SDK — Vue app 启动时调用一次
#[wasm_bindgen]
pub fn init(base_url: &str, token: &str) {
    CLIENT.set(PlatformClient::new(base_url, token))
        .expect("SDK already initialized");
}

/// 获取全局 client 实例 — 内部使用
fn client() -> &'static PlatformClient {
    CLIENT.get().expect("SDK not initialized, call init() first")
}
```

## 五、Phase 分期

### Phase 1

| crate | 范围 |
|-------|------|

Phase 1 不实现：sdk-ws、sdk-store。chat 前端直接调用 sdk-wasm 的 API 方法。

### Phase 2

| crate | 范围 |
|-------|------|
| sdk-ws | WebSocket 连接 + 事件订阅 + 自动重连 |
| sdk-store | AppState + 各模块 store + 响应式更新 + 乐观更新 |

### 5.5.1 sdk-ws — WebSocket 连接管理（Phase 2）

```rust
// sdk-ws/src/connection.rs
//
// WebSocket 连接管理 — 与 gate 的 WebSocket 端点建立长连接。
//
// 设计意图：
//   chat/console 前端需要实时接收后端事件（Agent 执行过程、工单变更、门禁推送）。
//   sdk-ws 封装 WebSocket 连接的建立、心跳、自动重连、消息分发。
//
// 重连策略：
//   指数退避（1s → 2s → 4s → 8s → 16s → 30s max）
//   网络恢复后立即重连（监听 online 事件）
//   重连后自动重新订阅之前的 topic

pub struct WsConnection {
    url: String,                         // gate WebSocket 地址（如 "ws://gate:8000/ws"）
    token: String,                       // JWT token（连接时携带）
    reconnect_interval: Duration,        // 当前重连间隔（指数退避）
    max_reconnect_interval: Duration,    // 最大重连间隔（30s）
    heartbeat_interval: Duration,        // 心跳间隔（30s，防止连接被中间件断开）
    status: ConnectionStatus,            // connected | disconnected | reconnecting
}

pub enum ConnectionStatus {
    Connected,
    Disconnected,
    Reconnecting,
}

impl WsConnection {
    /// 建立 WebSocket 连接
    pub async fn connect(&mut self) -> Result<(), WsError> { ... }

    /// 断开连接（主动关闭，不触发重连）
    pub async fn disconnect(&mut self) -> Result<(), WsError> { ... }

    /// 注册消息回调 — 收到 ServerWsEvent 时触发
    pub fn on_message(&self, callback: impl Fn(ServerWsEvent) + Send + 'static) { ... }

    /// 注册断开回调 — 连接断开时触发（重连前）
    pub fn on_disconnect(&self, callback: impl Fn() + Send + 'static) { ... }
}
```

### 5.5.2 sdk-store — 状态管理（Phase 2）

```rust
// sdk-store/src/chat_store.rs
//
// 聊天状态管理 — 管理消息列表、群聊、门禁等实时状态。
//
// 设计意图：
//   Phase 1 中前端每次需要数据都调用 API（无缓存）。
//   Phase 2 引入 sdk-store 后，数据缓存在内存中，
//   WebSocket 事件到达时自动更新缓存，前端响应式刷新。
//
// 乐观更新：
//   用户发送消息时，先在本地 messages 中添加（乐观），
//   API 成功后确认，失败后回滚（标记为发送失败）。

pub struct ChatStore {
    api: PlatformClient,                 // HTTP API 客户端
    ws: WsConnection,                    // WebSocket 连接
    // ── 缓存状态 ──
    current_project: Option<Project>,    // 当前选中的项目
    chat_rooms: Vec<ChatRoom>,           // 聊天室列表（项目群聊 + Assistant 私聊）
    messages: HashMap<String, Vec<ChatMessage>>,  // room_id → 消息列表
    pending_gates: Vec<GateCard>,        // 待审批的门禁列表
}

impl ChatStore {
    /// 加载项目 — 拉取聊天室列表 + 订阅 WebSocket 事件
    pub async fn load_project(&mut self, project_id: &str) -> Result<(), StoreError> { ... }

    /// 发送消息 — 乐观更新 + API 调用 + 失败回滚
    pub async fn send_message(&mut self, room_id: &str, content: &str) -> Result<(), StoreError> { ... }

    /// 处理门禁审批 — 乐观更新状态 + 调用 gate API
    pub async fn respond_gate(&mut self, gate_id: &str, action: &str, comment: Option<&str>) -> Result<(), StoreError> { ... }

    /// 获取工单看板数据 — 优先从缓存读，缓存过期时刷新
    pub async fn get_kanban(&self, project_id: &str) -> Result<KanbanData, StoreError> { ... }

    /// 获取项目进度 — 优先从缓存读
    pub async fn get_progress(&self, project_id: &str) -> Result<ProgressView, StoreError> { ... }

    /// 处理 WebSocket 事件 — 自动更新缓存
    pub(crate) fn handle_ws_event(&mut self, event: ServerWsEvent) { ... }
}
```

# quantalithos-website 概要设计

> 官网 — 产品介绍、文档中心、市场入口、社区链接

---

## 一、项目定位

### 1.1 核心职责

quantalithos-website 是项目的公开门面，面向潜在用户和开发者。

**做的事：**
- 产品介绍和演示
- 文档中心（快速开始、API 文档、架构说明）
- 市场入口（跳转到 console）
- 社区入口（GitHub、Discord）
- 更新日志和路线图

**不做的事：**
- 不做用户认证（跳转到 console 登录）
- 不做业务功能（全部在 console/chat/runner 中）
- 不做付费/定价

### 1.2 在整体架构中的位置

```
公开访问（无需登录）              登录后
─────────────────              ──────
quantalithos-website            quantalithos-chat（协作）
├── 首页                        quantalithos-console（管理）
├── 产品介绍                    quantalithos-runner（体验）
├── 文档中心
├── 市场预览 → 跳转 console
├── GitHub → 跳转 github.com
└── 静态站点，CDN 部署
```

### 2.2 产品介绍页

- 六阶段流程可视化（交互式流程图）
- Agent 角色介绍（TL / 开发 / 测试 / Assistant）
- 三级控制说明（Free / Guided / Enforced）
- 截图展示（chat 界面、看板、进度图、门禁卡片）

### 2.3 文档中心

- 快速开始（5 分钟上手）
- 架构概览（13 个子项目关系）
- 部署指南（Docker Compose 一键部署）
- API 参考（platform API 文档，自动生成）
- 自定义工作流（如何创建和分享流程模板）
- 贡献指南（如何参与开发）

### 2.4 市场预览

- 热门流程模板 / 技能包 / 应用作品（从 platform API 拉取）
- 点击跳转到 console 的市场页面

### 2.5 社区页

- GitHub 链接（源码 + Issues + Discussions + PR）
- 更新日志（Changelog，从 GitHub Releases 拉取）
- 路线图（公开的 Roadmap）
- 交流群（Discord / 微信群）

## 三、技术栈

| 类别 | 选型 | 说明 |
|------|------|------|
| 框架 | VitePress | Vue 3 静态站点生成器，Markdown 驱动，适合文档 + 官网 |
| 部署 | Vercel / Cloudflare Pages | 静态站点 CDN 部署，免费 |
| 文档 | Markdown + Vue 组件 | VitePress 原生支持 |
| 搜索 | Algolia DocSearch | 文档全文搜索（免费开源项目） |
| 分析 | Plausible / Umami | 隐私友好的访问统计 |

## 五、Phase 分期

### Phase 1

| 模块 | 范围 |
|------|------|
| 首页 | Hero + 核心卖点 + 快速开始 |
| 文档 | 快速开始 + 部署指南 + 架构概览 |
| 部署 | Vercel 自动部署（push to main → 自动构建） |

Phase 1 不实现：产品演示视频、市场预览、API 自动生成文档、搜索

### Phase 2

| 模块 | 范围 |
|------|------|
| 产品介绍 | 完整的产品页面 + 截图 + 演示视频 |
| 文档 | API 参考（自动生成）+ 自定义工作流指南 |
| 市场预览 | 从 platform API 拉取热门资产 |
| 搜索 | Algolia DocSearch |

## 四、Phase 分期

### Phase 1

| 模块 | 范围 |
|------|------|
| 首页 | Hero + 核心卖点 + 快速开始 |
| 文档 | quickstart + deploy + architecture/overview |
| 部署 | Vercel 自动部署（push to main → 构建） |

### Phase 2

| 模块 | 范围 |
|------|------|
| 产品介绍 | 完整产品页 + 截图 + 演示视频 |
| 文档 | API 参考 + 自定义工作流/角色指南 |
| 市场预览 | 从 platform API 拉取热门资产 |
| 搜索 | Algolia DocSearch |

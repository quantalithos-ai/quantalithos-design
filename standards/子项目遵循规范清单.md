# 子项目遵循规范清单

> **文档定位**:26 个子项目(仓库)在**仓库侧**必须遵守的规范清单。按仓库展开,每仓列出**强制项**(Blocker)+ **推荐项**(Warning)。
>
> **与产品清单的分工**:
> - `产品遵循规范清单.md` = 产品层(10 产品的用户体验、发布、合规整体)
> - 本文 = **仓库层**(单个仓库内的代码、接口、文档、CI 约束)
>
> **上游依据**:
> - `standards/README.md` §一 三条横切红线(最高约束)
> - `architecture/仓库拆分方案.md` 26 仓定义
> - `architecture/标准对齐全景图.md` §一 每仓单独对齐
> - `standards/coding/` + `standards/document/` + `standards/diagram/` 具体规范
>
> **如何使用**:每个仓的 README 顶部引用本文对应章节;每次 PR 审核按本文清单逐条过。

---

以下 **13 条** 在每个仓库都适用,不在每仓章节重复。
